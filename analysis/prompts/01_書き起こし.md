# ①書き起こし:スクショ → posts.jsonl

## Claudeへの指示

指定されたフォルダのスクショを**指定された枚数だけ**読み、
1投稿を1行のJSONにして、指定された `posts.jsonl` に**追記**してください。

### 守ること

- **推測で埋めない。** 読み取れない項目は `null` にする。捏造は分析を壊す。
- **数字は正確に。** いいね数・返信数・リポスト数はスクショに表示されている数字をそのまま。
- **本文は原文のまま。** 要約・整形・誤字修正をしない。改行位置も `\n` で再現する。
  改行位置は分析対象なので、勝手に詰めない。
- **同じ投稿が複数のスクショにまたがっている場合**(スクロールで切れている等)は、
  1つの投稿として結合する。重複して2行にしない。
- **既に posts.jsonl にある投稿は飛ばす。** 追記の前に既存の `id` を確認する。
- 読み終わったら、**何枚目まで処理したか**を報告する。

### 出力する項目(1投稿1行)

```json
{
  "id": "koara_012",
  "account": "koara",
  "source_files": ["koara_012.png", "koara_013.png"],
  "posted_at": "26/7/28",
  "is_pinned": false,
  "is_thread": true,
  "thread_position": "1/2",
  "topic_tag": "引き寄せの法則",
  "text": "数年前は鬱で、仕事もできなくて、貧乏で、恋人もいなかったけど、叶ってる前提で過ごしてたら、本当に全ての願いが叶ったよ🐨 今どん底の人も、安心して。絶対大丈夫だから。",
  "char_count": 78,
  "line_count": 1,
  "hook": "数年前は鬱で、仕事もできなくて、貧乏で、恋人もいなかったけど、",
  "emojis": ["🐨"],
  "has_link": false,
  "link_destination": null,
  "has_image": false,
  "likes": 138,
  "replies": 6,
  "reposts": 1,
  "notes": "ピン留め投稿。どん底→全部叶った の体験談型。最後に読者への安心づけ。"
}
```

### 各項目の意味

| 項目 | 内容 |
|---|---|
| `id` | `アカウント名_連番`。重複しないように |
| `source_files` | 元になったスクショのファイル名(複数可) |
| `posted_at` | 表示されている日付・時刻表記をそのまま(`26/7/28` `16時間` など) |
| `is_pinned` | ピン留めされているか |
| `is_thread` | 連投(スレッド)の一部か |
| `thread_position` | `1/2` のような表示があればそのまま |
| `topic_tag` | 投稿に付いているトピック表示(`引き寄せの法則` など) |
| `text` | 本文の原文。改行は `\n` |
| `char_count` | 本文の文字数(改行・絵文字含む) |
| `line_count` | 改行で分けたときの行数 |
| `hook` | 本文の1行目(または最初の句点まで)。**ここが一番大事な分析対象** |
| `emojis` | 使われている絵文字のリスト |
| `has_link` / `link_destination` | 外部リンクの有無と行き先(note / Notion / オプチャ など) |
| `has_image` | 画像付き投稿か |
| `likes` / `replies` / `reposts` | 表示されている数字。見えなければ `null` |
| `notes` | 気づいたことを日本語で一言。型・狙い・違和感など |

### プロフィール画面のスクショだった場合

投稿ではなくプロフィール画面(アカウント名・bio・フォロワー数が写っているもの)の場合は、
`posts.jsonl` ではなく、同じフォルダの `profile.json` に以下の形で保存してください。

```json
{
  "account": "koara",
  "display_name": "コアラさん@脱力引き寄せ",
  "handle": "koarasan_hikiyose",
  "icon": "コアラの線画イラスト(白背景・手描き風)",
  "bio": "bioの原文そのまま",
  "bio_line_count": 4,
  "link": "note.com/koara_hikiyose/n/...",
  "link_label": "▼7日間で引き寄せ体質になれるワーク",
  "topic_tags": ["引き寄せの法則", "引き寄せのコツ"],
  "followers": 1015,
  "recent_views": 352000,
  "views_per_follower": 347,
  "captured_at": "スクショの時刻表示"
}
```
