# ②分析:posts.jsonl → analysis.md

## Claudeへの指示

指定された `posts.jsonl` と `profile.json` を読み、以下の11項目を分析して
同じフォルダの `analysis.md` に書いてください。

### 守ること

- **必ず実データを引用する。** 各主張には、根拠になる投稿の `id` と実際の本文を添える。
  一般論だけの分析は価値がない。
- **数えられるものは数える。** 「〜が多い」ではなく「95件中62件(65%)」と書く。
- **反応数との関係を必ず見る。** いいね数が上位20%の投稿と下位20%の投稿で、
  何が違うのかを具体的に指摘する。ここが一番お金になる情報。
- **分からないことは「データ不足」と書く。** それらしい結論を作らない。

## 分析する11項目

### 1. プロフィール設計
表示名の構造(名前＋@肩書き)、アイコン、bioの行数と流れ、リンク導線、トピックタグ。
フォロワー数に対する閲覧数の比率も出す(＝投稿の拡散力の指標)。

### 2. フック(1行目)のパターン
`hook` を全部並べて分類する。例:
- 自己開示型「数年前は鬱で〜」
- 否定型「〜してる人、損してるよ」
- 断言型「〜すれば絶対に叶う」
- 問いかけ型「〜って思ったことない?」
- 数字型「3日で〜」
- 常識破壊型「実は〜はやらなくていい」

**それぞれの型が何件あり、平均いいね数がいくつか**を表にする。

### 3. 投稿の型(本文の構造)
フックの後の展開を分類する。例:
- 体験談型(どん底 → 転機 → 今)
- リスト型(◯つのコツ)
- 対比型(before / after、やる人 / やらない人)
- 一言断言型(短文のみ)
- 手順型(◯◯して、△△するだけ)

型ごとの件数と平均反応を表にする。

### 4. 文字数と改行
文字数の分布(最短・最長・中央値)、改行の入れ方、
**反応が良い投稿の文字数帯**を特定する。

### 5. 語り口(文体)
- 一人称(わたし / 私 / 僕)
- 読者の呼び方(あなた / きみ / 〜な人)
- 語尾(〜だよ / 〜です / 〜よね)
- 敬語とタメ口の比率
- 断定の強さ

**実例を3つ以上引用する。**

### 6. 絵文字の使い方
使用頻度、どの位置に入れるか、種類(アイコンの動物と揃えているか)。

### 7. 扱っているテーマ
投稿内容をテーマ別に分類し、件数と平均反応を出す。
**「よく投稿しているテーマ」と「反応が良いテーマ」がズレていないか**を必ず見る。

### 8. 導線設計(マネタイズ)
- どこへ誘導しているか(note / Notion / オプチャ / DM)
- 誘導投稿の頻度(全体の何%か)
- 誘導投稿と通常投稿の反応差
- 誘導の言い回し(実例を引用)
- ピン留め投稿が何をしているか

### 9. 投稿の頻度とリズム
日付データから、1日あたりの投稿数、連投(スレッド)の使い方を出す。

### 10. 伸びた投稿 TOP10 / 伸びなかった投稿 TOP10
いいね数順に並べ、本文をそのまま載せる。
そのうえで **「上位に共通していて下位にないもの」を3つ**、断定的に指摘する。

### 11. このアカウントの再現可能な「勝ち筋」
1〜10をふまえて、**他のジャンルに移植できる部分**と
**このアカウント固有(移植できない)部分**を分けて書く。
これが次の④コンセプト設計で使う一番重要なパートです。
