## 3. 発信内容の中身

### 世界観 — ぽーちゃんが教えてくれたものと完全に同じ

```
「世界を作ってるのは自分」
「この世はあなたが作ったゲーム。叶うって設定したら、全てそうなるように宇宙はできてる」
「人生はあなたが主役！「この世界=あなた」なんだから」
「あなたの世界で、最優先されるのはあなた。すべてがあなたのために存在している」
「あなたが現実を変えるんじゃなくて、現実があなたに勝手に合わせてくる」
```

**自分＝世界。これが土台にある。** なまけろ子と同じ。

### 繰り返し出てくる概念(出現順に整理)

| 概念 | 言い方 |
|---|---|
| **決める / 設定** | 「決めたら叶う、あとはお任せ」「現実より先に『設定』変えるの大事」「設定に戻ってください」 |
| **宇宙に任せる(ルート手放し)** | 「願いを決める → ルートは宇宙にお任せ」「どうやって？のルートは100%宇宙に」「もっと他力本願でいい」 |
| **宇宙にサイズも難易度もない** | 「棚を1つ創るのもお城を創るのも同じ」「叶うのに簡単 or 難しいなんてない」 |
| **確認しない(時差を見ない)** | 翌日「まだ叶ってない」と確認する=叶わない人 /「現実を見てどうにかしなきゃって動くのをやめた瞬間に好転する」 |
| **既に叶っている側に居座る** | 「すでに叶ってる自分に『居座る』のがコツ」「叶う人は、叶う前に『叶う人』になってる」 |
| **全部を叶う証拠にする** | 「電車に乗ること。歯を磨くこと。今日雨なこと。全てに『これが起きたってことは叶うのか！』」 |
| **根拠のない確信** | 「宇宙は根拠のない確信が大好きです」 |
| **しんどい時期＝変わる前兆** | 「眠かった人、気分が落ち気味だった人、体調不良だった人、それ現実が変わるサインです」 |
| **執着は突然抜ける** | 「魔法が溶けるように『スンッ』てどうでもよくなる瞬間がくる」 |

### ★ ロジカル側の武器 — ここがはるの看板

アカウント名が **「ロジカル引き寄せ」**、プロフィールが **「"スピらない"ロジカルな引き寄せ」**。

```
「引き寄せって『スピリチュアル』じゃなくて『脳科学』だと思ってる。
 『叶ったあとの世界の脳』にするだけで、現実が勝手にそうなるだけ」      ♡313

「正直に言います。引き寄せの法則の本質は自己洗脳です。」               ♡34

「現実だと思っている不安は、脳が再生してる映像にすぎない」             ♡256

「現実を変えるのは『努力』じゃなくて『解釈』！」                      ♡25
```

note購入者の声も「**スピとロジカルが絶妙に組み合わさっていて、感覚派の頭でっかちの私にはピッタリ**」。
→ **「スピが苦手な人」を取りにいくポジショニングが、はるの差別化。**

### ❌ 恋愛・夫ネタは伸びていない(♡中央値94、全体最下位クラス)

一方、お金ネタは伸びる(♡1,069「10億円欲しいなら」/ ♡952「イージーモードの世界」)。

**つまり、はるの客層は夫婦仲ではない。** はるの夫婦ネタをそのまま持ってきても意味がない。
**なまけろ子が参考にすべきは「夫の話をどう書くか」ではなく「読者をどう名指しするか」。**

### ❌ ハウツー・リスト型も伸びていない(♡中央値85)

→ **告知の♡を気にしなくていい。** これは重要な実証。

### 使っている売り方

1. **部数限定(残り2部)** — note画面に「残り2」が常に出ている。売り切れたら追加販売し、そのたびに投稿1本。
2. **「売り切れました」が投稿ネタになる** — 「朝起きたら売り切れになってました！」で枠を1つ使う。
3. **値上げ予告** — 「価格を少しだけ上げます。今の価格は明日まで」+「既に買った方も新内容が読めます」
4. **募集停止** — 「想像以上にお申し込みをいただいたので一旦停止」→ 希少性を作って、2週間後に低価格版を出す。
5. **お客様の声を画像で貼る** — DMスクショ3枚並べ。頻度が高い(確認できただけで8回)。
6. **ピン留めは2段** — 1/2が自己紹介、**2/2がnoteリンク**。

## 7. いちばん効く1行は何か

はるの最大の投稿は、ノウハウでも実績でもない。

```
♡7,461  もうすぐ、両手で抱えきれないほどの幸福がやってくる💫 覚悟はいい？
```

**「あなたに、もうすぐ良いことが起きる」と言い切っただけ。** 35字。

これは **引き寄せの法則そのもの**。
読者は手順を知りたいのではなく、**「大丈夫だ」と誰かに言ってほしい**。

なまけろ子なら、こうなる(※案。検査未通過):

```
もうすぐ、
あのころには戻られへんくらい
ええ夫婦になるで。
覚悟はええか？
```
