**当初「連投は使わない」と結論したが、型を問わずに言ったのが誤り。**

```
コアラ    有益型をほぼ出さない  →  連投が要らない
ゆきぴー  有益型が主力          →  連投
```

**どちらも「有益型は連投で出す」という点では一致している。**
**なまけろ子が有益型(型9・ハウツー)を入れるなら、その型だけ連投にする。**

> **運用者の判断(2026-10-03):「有益情報は連投の型を使用する」**

## ★★ 連投の型(ゆきぴー11本の実測)

```
1/2  [言い切り or 定義]。[理由・続きの入口]、   ← 必ず読点で切る
2/2  [中身をぜんぶ]
```

| | |
|---|---|
| **1/2が読点「、」で終わる** | **10 / 11本** |
| **1/2のほうが♡が高い** | **9 / 10本** |

### 1/2の末尾は、全部「助詞 + 、」

```
…大事なことは、    ♡206 → 59
…というのも3って、  ♡ 65 → 19
…対の存在だから、   ♡ 42 → 19
…始まる相手は、     ♡ 39 → 52   ←唯一2/2が高い
…周波数っていうのは、♡ 30 → 17
…気持ちは、         ♡ 23 → 16
…通じ合うのも、     ♡ 18 →  5
```

**「は」「って」「から」「のも」で切る。文として完成させない。**

**1/2のほうが♡が高いのは、フィードに出るのが1/2だから。**
**2/2は、1/2を踏んだ人しか見ない。**

## なまけろ子に持ってこられるもの

| | 持ってくるか | 理由 |
|---|---|---|
| **有益型(型9)の連投** | **○** | **運用者の判断。ゆきぴーの型をそのまま使う** |
| **1/2を読点で切る** | **○** | 連投の本体。これが無いと連投の意味がない |
| 断言型・体験談の連投 | **✕** | コアラは単発。ここは変えない |
| 最後に小さい行動を1つ渡す | **✕** | 大原則①(行動を指示しない)と衝突 |

### ⚠ ただし、大原則①と衝突する

`knowledge/03_投稿の型.md` の**大原則①「行動を指示しない」**がある。

> スピリチュアルは検証不可能なので、「やったのに叶わない」が起きる。
> だから行動を指示しない。

**ゆきぴーの「紙に書いてみて」は、まさにその行動指示。**

**コアラも、ほぼ指示しない。**
「設定しよ〜」「決めたらそうなるだけ」程度で、物理的な動作は出てこない。

> **結論:行動は渡さない。この1点はコアラ側を採る。**
> **渡していいのは「〜せんでええ」という引き算だけ**(なまけろ子の実測でも
> 「考えんと寝てええよ」が4.11%で上位)。
