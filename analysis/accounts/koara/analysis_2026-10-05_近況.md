## 3. ★★★ 新しい最強型:読者が唱えられる宣言文

```
欲しいもの、ぜーーーんぶ来る。
結局、私はぜーーーんぶ手に入れる。

これ本気で設定すると、
宇宙がちゃんと仕事して、

```

**♡1,730 / 表示1.5万 / 返信4**

### ここで起きていること:返信欄が「唱和」になっている

```
smailu1413710   「欲しいものはぜーんぶ来る。結局、私はぜーんぶてに入れる。🎊🎉🙏 楽しい。嬉しい。」
benjamin_itou   「そう願いたい🙏!」
manay.freemama  「私はほしいもの全部手に入ります✨✨」
yasuhiroseki    「ありがとうございます」
```

**読者が、投稿の文をそのまま書き写している。**

### なぜそうなるか:一人称が「私」

| | 一人称 |
|---|---|
| コアラの従来 | **あなた**は / ぼくは |
| **この投稿** | **「結局、私はぜーーーんぶ手に入れる」** |

**「あなたは叶うよ」は、読者が受け取るだけ。**
**「私は手に入れる」は、読者が声に出せる。**
**読者のセリフを先に書いてある**ので、そのまま唱えられる。

> **これは予祝型(「もう決まってる」)のさらに先。**
> **予祝は宇宙が宣言する。この型は読者自身に宣言させる。**

### 書き方

```
[欲しいものの宣言]。
結局、私は[手に入れる]。

これ本気で[設定/決める]と、
宇宙がちゃんと仕事して、
[叶えてくれる]よ🌍
```

**前半が読者のセリフ、後半がコアラの解説。**
**「ぜーーーんぶ」「本っっっッツ気」と伸ばして、声に出す感じを作っている。**
