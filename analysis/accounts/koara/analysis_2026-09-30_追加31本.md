## ★★★ 2. 新しい型:予祝型(すでに叶ったこととして祝う)

**トップ2に共通するのは「もう起きたこと」として話しかけていること。**

```
おめでとう✨ 今日を境に、通帳のお金が増え続けるよ。
 ↑完了への祝い

あらら、また臨時収入だね。明日もあさってもあるよ。
 ↑目撃している口調。「また」で、前にもあった前提
```

**これは既存の予言型(型H)とは違う。**

| | 言っていること | 例 |
|---|---|---|
| 予言型(型H) | **これからそうなる** | もう決まってるよ。仲のええ夫婦になるって |
| **予祝型(新)** | **もう、そうなった** | **おめでとう / また臨時収入だね** |

**`knowledge/07_引き寄せの方針_701.md` の「もうすぐ叶う、ではなく、もう叶ってる」が、
実測で裏づけられた形。** コアラの最上位2本が、まさにそれ。

## ★★★ 3. コアラは、同じ語を繰り返していない

**今日、なまけろ子で「マンネリ」が問題になったので、コアラと並べた。**

| 語 | コアラ(31本) | **なまけろ子(49本)** |
|---|---|---|
| **決め・決ま** | **3/31 (10%)** | **31/49 (63%)** |
| 大丈夫 | 3/31 | 10/49 |
| もう仲がいい | ─ | 9/49 |

**6倍の偏り。**

**コアラは「決める」を核にしていない。** 代わりに、同じこと(もう叶ってる)を
**毎回ちがう入口から言っている。**

```
余白 / 運がいい / あたりまえ / 予想外の展開 / なりたい自分 / 世界を作ってる /
最高のタイミング / めでたしめでたし / 世界線 / 停滞期 / 予祝 / 奇跡 /
なんとかなる / 急に / よっこいしょ / 今日を境に / 天才 / カタログから選ぶゲーム /
前兆 / シンプル / 臨時収入 / グニャグニャ / 甘やかす / ワープ / 飽きたらやめていい
```

**31本で、入口が31通りある。**

> **「決める」を減らすのではない。入口を増やす。**
> なまけろ子は、同じ入口(決める)から毎日入っている。
