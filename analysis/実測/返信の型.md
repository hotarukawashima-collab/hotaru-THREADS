# 返信の型(コアラ・ゆきぴーの実物から抽出)

投稿と同じで、返信にも型がある。**5例すべてが同じ骨をしている。**

---

## 集めた実例

### ① そうだったんだね〜 → 相手の言葉を肯定 → 引き寄せに接続

```
相手  うん、ダメだしされた。頼もうと思っていたのに。
      でも、知らなかっただけ、気がつかなかっただけ。
      と落ち込み具合が軽いのよね。これも引き寄せだな。

コアラ そうだったんだね〜、でも言う通りで、知らなかっただけって
      思えるのも引き寄せなんだよ✨
      すこし落ち込んでもすぐ前を向けるのが引き寄せのいいところ〜🌿
```

**「言う通りで」= 相手が自分で出した答えを、そのまま正解にしている。**
こちらの解釈を足していない。

### ② 時期は答えない

```
相手  もうすぐって、いつですか? 今日? 明日? うれしー!!

コアラ いつだろうね〜🐨💦
      自分以外のひとを動かすのはけっこうコツがいるんだよね〜💦
```

**★ 予言型に「いつ?」と聞かれたときの、コアラ自身の答え。**
**謝らない。言い訳しない。「いつだろうね〜💦」でかわす。**
そして**「自分以外のひとを動かすのはコツがいる」**と、正直なことを軽く言う。

### ③ 重い相談 → そっか〜泣 → 状況を認める → 一手だけ渡す

```
相手  別れたい
      でも生活に困るの

コアラ そっか〜泣
      それは身動きとれないよね〜🐨💦
      そういうときは、なりたい結果だけ宇宙におまかせしてみるといいよ✨
```

**★ いちばん重い相談への返信が、いちばん短い。3行。**
**解決しようとしない。説教しない。「そういうときは」で一手だけ渡して終わる。**

### ④ 即答で肯定 → 自分の体験 → サインだと読み替える

```
相手  ほんとに? 失恋したばっかで...いいことありますか?

コアラ あるよー✨
      コアラも失恋した後から現実が動き始めたよ、
      自分ではうまくいかないって思ってても、
      それって実は現実が変わるサインなんだよ〜🐨
```

**「あるよー✨」と即答。** 条件をつけない。
**今の悪い状態を「サイン」に読み替える。**

### ⑤ 相手の言葉を引用して返す → 自己否定を先回りで否定(ゆきぴー)

```
相手   そしてツインレイに出会う前にカルマメイトに出会うらしいですね。
       もう思い出すこともないけど、辛かったな。

ゆきぴー もう思い出すこともないってところまで来たんだね。
       あの辛さって、自分の魅力とか努力が足りなかったからじゃないんだよ。
```

**★ 前半:相手の言葉をそっくり引用して「〜ところまで来たんだね」。**
**★ 後半:相手が言ってもいない自己否定を、先回りして否定している。**

## 共通する骨

| | |
|---|---|
| **長さ** | **2〜4行。** 重い相談ほど短い |
| **1行目** | **受ける。**「そうだったんだね〜」「そっか〜泣」「〜ってところまで来たんだね」 |
| **2行目** | 状況を認める。「それは〜だよね〜」 |
| **最後** | **言い切って終わる。**「〜なんだよ〜」「〜といいよ✨」 |
| **絵文字** | 🐨💦✨🌿。**「泣」「〜」で圧を下げる** |

### ★ 1行目は、相手の状況に「名前をつけ直す」

コアラは、相手の状況を**具体的な一言で言い直している。**

```
相手  別れたい / でも生活に困るの
コアラ それは身動きとれないよね〜🐨💦   ← 「身動きとれない」と名前をつけた
```

ゆきぴーは、**相手の言葉をそのまま引用している。**

```
相手   もう思い出すこともないけど、辛かったな。
ゆきぴー もう思い出すこともないってところまで来たんだね。  ← そのまま引用
```

**どちらかしかない。** 相手の言葉を使うか、具体的な一言で言い直すか。

### ✕ 指示語でぼかさない

```
✕  9ヶ月、ずっとその中にいたんだね〜
                    ↑「その中」が何なのか書いていない
```

**「その」「それ」「そこ」「この状況」で状況を指すと、急に他人行儀になる。**
本人は具体的に書いているのに、こちらが抽象語で受けると
**「読んでないな」と伝わる。**

**本人が使った名詞を、そのまま拾う。**

| 本人が書いたこと | 拾う言葉 |
|---|---|
| 私たちはほぼ無視されてる | **無視されてる** |
| 夫を大切で好きだった気持ちまで壊される | **好きだった気持ち** |
| やっと主人の優しさに気がついて | **「やっと」は拾わない**(後述) |

> **例外がある。** 相手が**自分を下げた言葉**(やっと/毒妻/ダメな)は拾わない。
> 詳しくは下の「★ ただし「やっと」は拾わない」。

### やっていないこと

| ✕ | |
|---|---|
| **説得しない** | 理由を並べない。投稿と同じ |
| **解決しない** | 「こうすれば直る」と言わない |
| **時期を言わない** | 「いつだろうね〜💦」 |
| **謝らない** | 「ごめんね」「わたしには言えない」と重くしない |
| **言い換えない** | **相手の言葉をそのまま使う** |
| **商品を出さない** | 5例とも一度も出てこない |

> **返信も「並べて、言い切る」。**
> 投稿で分かったことと、まったく同じ。

## なまけろ子の返信を、この型に直す

### A. 9ヶ月・不倫継続の人(→ 型③を使う)

```
そっか〜泣
9ヶ月もほぼ無視されてたら、そりゃしんどいよね〜🦥💦

何日かは、わたしにもわからないの。
自分以外のひとを動かすのは、けっこうコツがいるんだよね〜💦

そういうときは、なりたい結果だけ決めて、
あとは宇宙におまかせしちゃっていいよ✨
```

> **1行目を「ずっとその中にいたんだね」から直した。**
> **「その中」が何を指すのか書いていない。**
> 本人が「私たちはほぼ無視されてる」と書いているので、**その言葉を使う。**

**前に書いた案から変えたところ**

| 前の案 | 直した理由 |
|---|---|
| 「ごめんね」 | **コアラは謝らない。** 重くなる |
| 「そういう話じゃないよね」 | **自分の投稿の説明をしている。** コアラはしない |
| 「明け渡さなくていいからね」 | 良い行だが、**一手を渡すほうがコアラの形** |

「何日」には**型②の「自分以外のひとを動かすのはコツがいる」**をそのまま使う。
**コアラが同じ質問に実際に返した言葉。**

### B. 「自分の毒妻を認識しました」の人(→ 型⑤を使う)

```
優しさ、見えるようになったんだね〜✨

毒妻じゃないよ。
優しさって、こっちに余裕がないと見えないだけなんだよ〜🦥

見えたってことは、もう余裕が戻ってきてるってことだからね🌿
```

**ゆきぴーの型⑤そのまま。**

| ゆきぴー | なまけろ子 |
|---|---|
| もう思い出すこともないってところまで来たんだね | 優しさ、見えるようになったんだね〜✨ |
| あの辛さって、自分の魅力とか努力が足りなかったからじゃないんだよ | 毒妻じゃないよ。優しさって、こっちに余裕がないと見えないだけ |

**前の案は「毒妻じゃないよ〜」から始めていた。**
**受けるのが先。** 否定から入ると、話を聞いていないように読める。

### ★ ただし「やっと」は拾わない

本人は「**やっと**主人の優しさに気がついて」と書いている。
一度これを拾って「やっと気づけたんだね〜」と返す案を作ったが、**嫌味になる。**

| | 意味 |
|---|---|
| 本人が言う「やっと」 | **安堵**。「ようやく肩の荷が下りた」 |
| こちらが返す「やっと」 | **評価**。「ようやくか。遅かったね」 |

**同じ言葉でも、言う人が変わると意味が裏返る。**

> **相手が自分を下げた言葉は、拾わない。**
> 拾っていいのは、**ただの事実か、到達点**だけ。

| 本人の言葉 | 拾う | 理由 |
|---|---|---|
| 私たちはほぼ無視されてる | **○** | 事実 |
| もう思い出すこともない(ゆきぴー例) | **○** | 到達点 |
| **やっと**気がついて | **✕** | 自分を下げている |
| 自分の**毒妻**を認識 | **✕** | 自分を下げている |

**代わりに、その中にある事実だけを取り出す。**

```
やっと主人の優しさに気がついて  →  優しさ、見えるようになったんだね〜✨
                                    ↑「やっと」を落として、変化だけを言う
```

**「気づいた」ではなく「見えるようになった」にしたのも同じ理由。**
「気づいた」は**本人の手柄/怠慢**の話になるが、
「見えるようになった」は**条件が変わった**話になる。
次の行(余裕がないと見えない)にもそのままつながる。

## 2通目以降のルール(2026-09-24)

### 同じ一手を繰り返さない

```
1通目 何日経てば好転の兆しが見える?
返信  なりたい結果だけ決めて、あとは宇宙におまかせしちゃっていいよ✨
2通目 失いたくないのに、憎しみが募ってしまう
      ↑「それができない」と言っている
```

**ここで同じ一手(決める/おまかせ)を出すと、「聞いてない」になる。**

### 2通目は、たいてい質問ではない

| | 何が来るか | 何を求めているか |
|---|---|---|
| **1通目** | **質問** | 見通し・答え |
| **2通目** | **あふれたもの** | **そう思っていいという許可** |

**2通目に答えを出そうとしない。** 許可を出す。

### 「〜のに」を見つけたら、決めさせない

```
失いたくない「のに」、憎しみが募ってしまう
```

**「〜のに」は、本人が自分を矛盾していると思っているしるし。**
**どちらかに決めさせると、追い打ちになる。**

```
○ 憎いのと、失いたくないのは、どっちも持っといてええからね。
   ここだけは、決めんでええよ✨
```

**このアカウントの看板(決めていいんだよ)を、あえて裏返す場面がある。**
看板を守ることより、目の前の人を潰さないことが先。

## ★ 引き寄せを、相手の武器にさせない(2026-09-24)

> こんなふうに思えてしまって、もう夫婦おしまいだ。**宇宙にもそう捉えられてしまうね。**

**引き寄せ系アカウントが必ず抱えるリスク。**
「いい気分でいれば叶う」を裏返して、**「悪いことを思った自分のせいで叶わない」**
と受け取る人が出る。

### 放置するとどうなるか

1. 気持ちを押し殺す
2. それでも状況は変わらない
3. **押し殺し方が足りなかった自分のせいにする**

**いちばんしんどい人が、いちばん自分を責める形になる。**

### 言い方

```
憎んだくらいで、宇宙は動かへんよ。
思ったことで、罰されたりせんからね。
```

**はっきり言い切る。** ぼかすと、疑いが残る。

### これはコアラも言っている

> ♡575 信じられなくても、感情がぐちゃぐちゃでも
> とりあえず「決める」だけだよ。
> そうすると絶対叶うようになってるんだよ〜

**「感情がぐちゃぐちゃでも」= 気分は条件じゃない。**
**投稿としても出す価値がある。** 返信だけで済ませない。
