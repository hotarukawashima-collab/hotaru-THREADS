# 返信の型(コアラ・ゆきぴーの実物から抽出)

投稿と同じで、返信にも型がある。**5例すべてが同じ骨をしている。**

---

## 集めた実例

### ① そうだったんだね〜 → 相手の言葉を肯定 → 引き寄せに接続

```
相手  うん、ダメだしされた。頼もうと思っていたのに。
      でも、知らなかっただけ、気がつかなかっただけ。
      と落ち込み具合が軽いのよね。これも引き寄せだな。

コアラ そうだったんだね〜、でも言う通りで、知らなかっただけって
      思えるのも引き寄せなんだよ✨
      すこし落ち込んでもすぐ前を向けるのが引き寄せのいいところ〜🌿
```

**「言う通りで」= 相手が自分で出した答えを、そのまま正解にしている。**
こちらの解釈を足していない。

### ② 時期は答えない

```
相手  もうすぐって、いつですか? 今日? 明日? うれしー!!

コアラ いつだろうね〜🐨💦
      自分以外のひとを動かすのはけっこうコツがいるんだよね〜💦
```

**★ 予言型に「いつ?」と聞かれたときの、コアラ自身の答え。**
**謝らない。言い訳しない。「いつだろうね〜💦」でかわす。**
そして**「自分以外のひとを動かすのはコツがいる」**と、正直なことを軽く言う。

### ③ 重い相談 → そっか〜泣 → 状況を認める → 一手だけ渡す

```
相手  別れたい
      でも生活に困るの

コアラ そっか〜泣
      それは身動きとれないよね〜🐨💦
      そういうときは、なりたい結果だけ宇宙におまかせしてみるといいよ✨
```

**★ いちばん重い相談への返信が、いちばん短い。3行。**
**解決しようとしない。説教しない。「そういうときは」で一手だけ渡して終わる。**

### ④ 即答で肯定 → 自分の体験 → サインだと読み替える

```
相手  ほんとに? 失恋したばっかで...いいことありますか?

コアラ あるよー✨
      コアラも失恋した後から現実が動き始めたよ、
      自分ではうまくいかないって思ってても、
      それって実は現実が変わるサインなんだよ〜🐨
```

**「あるよー✨」と即答。** 条件をつけない。
**今の悪い状態を「サイン」に読み替える。**

### ⑤ 相手の言葉を引用して返す → 自己否定を先回りで否定(ゆきぴー)

```
相手   そしてツインレイに出会う前にカルマメイトに出会うらしいですね。
       もう思い出すこともないけど、辛かったな。

ゆきぴー もう思い出すこともないってところまで来たんだね。
       あの辛さって、自分の魅力とか努力が足りなかったからじゃないんだよ。
```

**★ 前半:相手の言葉をそっくり引用して「〜ところまで来たんだね」。**
**★ 後半:相手が言ってもいない自己否定を、先回りして否定している。**

## 共通する骨

| | |
|---|---|
| **長さ** | **2〜4行。** 重い相談ほど短い |
| **1行目** | **受ける。**「そうだったんだね〜」「そっか〜泣」「〜ってところまで来たんだね」 |
| **2行目** | 状況を認める。「それは〜だよね〜」 |
| **最後** | **言い切って終わる。**「〜なんだよ〜」「〜といいよ✨」 |
| **絵文字** | 🐨💦✨🌿。**「泣」「〜」で圧を下げる** |

### やっていないこと

| ✕ | |
|---|---|
| **説得しない** | 理由を並べない。投稿と同じ |
| **解決しない** | 「こうすれば直る」と言わない |
| **時期を言わない** | 「いつだろうね〜💦」 |
| **謝らない** | 「ごめんね」「わたしには言えない」と重くしない |
| **言い換えない** | **相手の言葉をそのまま使う** |
| **商品を出さない** | 5例とも一度も出てこない |

> **返信も「並べて、言い切る」。**
> 投稿で分かったことと、まったく同じ。

## なまけろ子の返信を、この型に直す

### A. 9ヶ月・不倫継続の人(→ 型③を使う)

```
そっか〜泣
9ヶ月、ずっとその中にいたんだね〜🦥💦

何日かは、わたしにもわからないの。
自分以外のひとを動かすのは、けっこうコツがいるんだよね〜💦

そういうときは、なりたい結果だけ決めて、
あとは宇宙におまかせしちゃっていいよ✨
```

**前に書いた案から変えたところ**

| 前の案 | 直した理由 |
|---|---|
| 「ごめんね」 | **コアラは謝らない。** 重くなる |
| 「そういう話じゃないよね」 | **自分の投稿の説明をしている。** コアラはしない |
| 「明け渡さなくていいからね」 | 良い行だが、**一手を渡すほうがコアラの形** |

「何日」には**型②の「自分以外のひとを動かすのはコツがいる」**をそのまま使う。
**コアラが同じ質問に実際に返した言葉。**

### B. 「自分の毒妻を認識しました」の人(→ 型⑤を使う)

```
優しさに気づけるところまで来たんだね〜✨

毒妻じゃないよ。
優しさって、こっちに余裕がないと見えないだけなんだよ〜🦥

気づけたってことは、もう余裕が戻ってきてるってことだからね🌿
```

**ゆきぴーの型⑤そのまま。**

| ゆきぴー | なまけろ子 |
|---|---|
| もう思い出すこともないってところまで来たんだね | 優しさに気づけるところまで来たんだね〜✨ |
| あの辛さって、自分の魅力とか努力が足りなかったからじゃないんだよ | 毒妻じゃないよ。優しさって、こっちに余裕がないと見えないだけ |

**前の案は「毒妻じゃないよ〜」から始めていた。**
**受けるのが先。** 否定から入ると、話を聞いていないように読める。
