## ⭕ 読者のビフォアを言い当てて、否定する

```
[はる] ♡1,333 → 再投稿 ♡1,777

**♡29 と ♡1,777 の差は61倍。両方とも「ビフォア」に触れている。**

| | 自分のビフォア | 読者のビフォア |
|---|---|---|
| 書く量 | **語る**(2〜4行) | **1行で済ます**(「前は全く信じられなかったけど」) |
| 主語 | 私 | **あんた/いま** |
| 落ち | 私はこうなった | **あんたはこうなる** |
| ♡ | 19〜68 | **285〜1,777** |

> **ビフォアは「見せる」ものではなく、「1行で触れて、すぐ断定に行く」もの。**

# なまけろ子の告知1本を、この物差しで見る

```
2026-10-06 19:00 型10
noteを買うてくれた人がおってな。ありがとうな🌿

| | 判定 |
|---|---|
| 購入があった事実を出した | ⭕ コアラの13本と同じ枠 |
| **「コツがあってん」「7ステップ」** | **✕ ①テクニック訴求。コアラの数字では♡6の側** |
| 購入者がどうなったか | **✕ 無い**。コアラは必ず「現実が変わりはじめてる」を入れる |
| 在庫・締切 | **✕ 無い** |

# やること(安い順)

| | | 根拠 |
|---|---|---|
| **1** | **noteに部数制限を入れる**(残り◯部) | はるの9本はこれが前提。**在庫は自分で作れる** |
| **2** | **購入者の成果報告を、枠として持つ**(5〜6日に1本) | コアラ13本。♡は狙わない |
| **3** | **告知の訴求を「コツ/ステップ」から「買った人がどうなったか」に変える** | ①は♡6の側 |
| 4 | 値上げ予告を1回打つ(内容を良くする理由をつけて) | コアラ2本。締切を作る |
| 5 | 商品を2段にする(安い入口 or 無料note) | コアラ4段・はる5段。1段はなまけろ子だけ |
| 6 | noteの無料部分に全力を注ぐ | コアラ本人の言葉。「知りたい」は無料部分が作る |

**⚠ ただし、1〜4の前に `有料noteのビュー数` を見る。**
**0〜5ビューなら導線の問題で、告知の文を直しても効かない。**(`投稿実績.md` 2026-10-04)
