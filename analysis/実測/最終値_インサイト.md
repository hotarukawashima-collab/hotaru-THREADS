### ① 構成H(もうすぐ〜になるよ)が、ぶっちぎりで最強

```
♡     1位 280  2位 110    ← 両方とも構成H。3位(85)の 3.3倍 / 1.3倍
表示   1位 5,594  2位 3,478  ← 両方とも構成H。3位(2,656)の 2.1倍 / 1.3倍
```

**♡でも表示でも、1位と2位を構成Hが占めている。**

> **コアラの構成パターン表に「★表示データでは最強」と書いてあったとおりだった。**
> **それを8回しか使っていなかった。**

```

```

**率だけ見ていたので、予祝を主力にしていた。**
