# コアラの構成パターン(TOP20から抽出)

**コアラは説得しない。並べて、言い切る。**
「なぜなら」「だから」という論証の接続詞が、TOP20に**一度も出てこない。**

これに気づくまで、自分で考えた「具体 → だから → 結論」という論証の形で書いていて、
その不具合を検査ルール①〜⑨として後付けし続けていた。**構成ごと借りれば起きない問題だった。**

## 共通する骨

1. **並列を2つ置いてから言い切る。**「〜し、〜よ」
2. **カギカッコのセリフを真ん中に置く。**
3. **最後は必ず言い切る。**「〜だよ」「〜いいんだよ」
4. **理屈を書かない。**「なぜなら」「だから〜なの」が無い
5. **具体はセリフか情景。** 論証の材料ではない
6. **3〜4行。** それ以上は構成Gだけ

## やってはいけない形(自分がやっていた)

```
✕ 具体を出す  →  だから〜  →  結論
```

これは**論証**であって、コアラの形ではない。
論証すると「その理屈おかしくない?」という穴が開き、
そこを塞ぐために説明が増えて、長く、分かりにくくなる。

**コアラは読者を納得させようとしていない。** 言い切って、読者が受け取るかどうかに任せている。
