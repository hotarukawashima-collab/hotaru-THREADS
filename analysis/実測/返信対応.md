# 返信への対応

## 2026-09-23 初めての返信(重いもの)

**どの投稿に付いたか**

```
🦥「うちは夫婦仲がいいって決めたのに、なんも変わらへん」
宇宙「何日目?」
🦥「…3日」
宇宙「はやいわ」
```
(9/23 09:00・型6 対話・表示762・♡4)

**返信の中身**

> じゃあ何日経てば良い?
> 転職を建前に、家族みんな反対したのに強引に決めて単身赴任。結局不倫してたからそこへ決めた。
> 今も続けて、私たちはほぼ無視されてる。もう9ヶ月経つ。
> 何日経てば、好転の兆しが見える?
> このままじゃ、恨みや憎しみが募ってしまう。夫を大切で好きだった気持ちまで壊されていく。

---

## 何が起きているか

**投稿の前提と、この人の状況が合っていない。**

| 投稿が想定していた人 | 実際に返信した人 |
|---|---|
| 決めて3日で焦っている | **9ヶ月** |
| まだ何も壊れていない | **不倫が継続中・家族が無視されている** |
| 待てば変わる | **待っても変わっていない** |

「はやいわ」は、**まだ何も壊れていない人に向けた冗談。**
この人に向けて言えば、ただの突き放しになる。

### これは対話型の構造的な性質

対話型は**読む人の悩みを軽く扱って落とす**形。
それがフォロー率2.54%(全型で最高)の理由でもある。

**だから、重い事情の人が読むと「わかってもらえない」になる。**
投稿を変える必要はない。**返信で受ける。**

---

## 返信するかどうか

**する。** 理由は3つ。

1. 762人が見ている投稿で、**返信がどう扱われるかも一緒に見られている**
2. 無視するのがいちばん印象が悪い
3. 実際につらい人が、実際に声を出している

---

## 言ってはいけないこと

| ✕ | なぜ |
|---|---|
| 「〇ヶ月くらいで変わるよ」 | **嘘になる。** 外れたときこの人はもっと落ちる |
| 「決めたら変わるよ」 | 「決め方が足りないあなたのせい」に聞こえる |
| 「ご主人も苦しいんだよ」 | 不倫を続けている相手をかばうことになる |
| 「離婚も選択肢」 | 公開の場で言うことではない |
| noteや商品の案内 | **痛みにつけこむ形になる。** 今はしない |

## 返信案A(推奨・約130字)

```
つらいね。9ヶ月、よく持ちこたえてるよ。

「何日」は、わたしには言えないの。ごめんね。

「3日ではやいわ」は、まだ何も壊れてない人に向けた話だったの。
あなたのは、そういう話じゃないよね。

「夫を好きだった気持ちまで壊される」って書いてたでしょ。
そこだけは、明け渡さなくていいからね🦥
```

**この案の考え方**

| 行 | 役割 |
|---|---|
| つらいね。9ヶ月、よく持ちこたえてるよ | まず認める。評価も助言もしない |
| 「何日」は言えないの。ごめんね | **答えられないことを、答えられないと言う** |
| 「はやいわ」はそういう話じゃない | **自分の投稿が刺さったことを認める** |
| そこだけは明け渡さなくていい | **この人が使った言葉をそのまま返す** |

**いちばん大事なのは最後の行。**
この人が自分で「夫を大切で好きだった気持ちまで壊されていく」と書いている。
**それがこの人のいちばん惜しいもの。**
夫がどうするかは決められないが、**自分の気持ちを誰のものにするかは決められる。**

これが、この状況で言える唯一の「決める」。
仲直りを約束せず、引き寄せの芯からも外れていない。

## 返信案B(短く・約80字)

```
つらいね。9ヶ月、よく持ちこたえてるよ。
「何日」は、わたしには言えないの。ごめんね。
ただ「夫を好きだった気持ちまで壊される」のだけは、
明け渡さなくていいからね🦥
```

Aより軽い。ただし**「自分の投稿が刺さったことを認める」行が消える**ので、
突き放した印象が少し残る。

## 返信案C(個別の入口をつくる)

Aの最後に1行足す。

```
ここに書ききれないことがあったら、DMでもいいからね。
```

**今はすすめない。** フォロワー30人の段階で、
**つらい話をした人にDMを促すと、集客に見える。**
この人が望めば向こうから来る。

---

## この先のために

- **重い返信は、今後も来る。** 夫婦仲というテーマ上、不倫・DV・別居は必ず出る
- **投稿は軽いままでいい。** 軽いから届く。**受けるのは返信で**
- **答えられないことは「言えない」と言う。** 時期を約束しない
- **商品案内は、相手から聞かれたときだけ**
