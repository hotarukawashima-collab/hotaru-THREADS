# 6. 教材の定義との照合 `[教材]`

## 基本型（STEP5-3）

```
①フック ②本文（価値ある情報や体験談・具体な体験や数字）③締め（読者の行動を促す／リプが残しやすい）
```

| | コアラの実物 | |
|---|---|---|
| ①フック | 1行目で断定、または読者の状態を言い当てる | **⭕一致** |
| ②本文 | 具体はセリフか情景。数字はほぼ無い | **△ 教材は「数字を入れる」** |
| ③締め | 言い切り。CTAは2.8% | **△ 教材は「CTAが入っていないこと‼」** |

> **★ この2つの不一致は `10_Threads運用方針_おきるママ.md` 7章が**
> **「両立しうる」として既に記録している矛盾点。新しい結論は足していない。**
> **★ 型1〜型12（`03_投稿の型.md`）に、このファイルから何も足していない。**

## 3つの軸は別に扱った

```
軸1 型    コアラのposts.jsonlに型番号は無い。構成A〜Hは実測からの観察
軸2 目的  2章の暫定分類
軸3 教育  ★当てていない
```

> **★ STEP9の6教育は、参考アカウントに当てていない。**
> `14_投稿目的と教育.md` が「STEP9の教材本体はリポジトリに無い。教材原文との直接照合は未実施」
> と記録しているため、定義文だけで他人の投稿を教育に割ると、根拠のない分類になる。

# 7. なまけろ子への応用 `[仮説]`

## 取り出した順番（文章はコピーしていない）

| 目的 | 順番 | 根拠 |
|---|---|---|
| **集客** | 読者の状態1行 → **読者に言わせたい言葉**をカギカッコ → 肯定で言い切る | ♡上位8本 |
| **ファン化** | 立場または過去を1〜2行 → **すぐ読者に返す** → 励まし・約束 | koara_104/140/277、yukipi_078/107 |
| **収益A** | 何を書いたか（量・誰のために）→ 公開と導線 | koara_209/216/218 |
| **収益B** | 購入の事実と感謝 → **買った人がどうなったか** → 導線 | koara_153/185/197/236/299/308 |
| **収益C** | 謝罪のフック → 値上げ → 理由（内容を良くする）→ 既存購入者の安心 → 締切 → 導線 | koara_186/290 |

## ★ ファン化・収益を作れるかどうかの判断基準

**型があるかどうかでは決めない（0章の3）。**
**★ A〜Cが使えないことを「収益は作れない」と読まない（0章の7）。**

| 構造 | 必要な材料 | 現状 |
|---|---|---|
| ファン化 | 立場 / 考え方 / キャラクター / 確認済みの方法 | **⭕ ある。新しい実話は要らない** |
| 収益A 公開告知 | 新しく公開するもの | 無い。**この構造が使えないだけ** |
| 収益B 購入後の報告 | **確認済みの購入者の成果報告** | **✕ 記録に無い。★創作はできない**（`05_NGリスト.md`） |
| 収益C 締切 | 在庫・締切・値上げの予定 | 無い。**この構造が使えないだけ** |
| **収益（教材側）** | **既存商品の価値 / 購入者が学べる具体的な内容** | **⭕ 設計できる。** 教材の③テンプレート前半 |

```
★ ファン化は、型5が無くても作れる。
  必要なのは「立場・考え方を1〜2行 → すぐ読者に返す」という順番で、
  これは特定の型番号に縛られない。

★ 収益も、A〜Cが無くても作れる。
  既存商品の価値や、購入者が学べる具体的な内容を伝える設計が、教材の③に含まれている。
  A〜Cは、参考アカウントがその3つに寄っていたという観察にすぎない。

★ ただし「買った人がどうなったか」(収益B)だけは、事実が無いと書けない。
  成果と購入者の声は創作しない。
```
