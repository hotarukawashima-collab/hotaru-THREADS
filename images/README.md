# 有料note用 章扉画像

## 何これ

有料本文(約14,000字)は章扉が無いと読み手が疲れるので、ステップの切り替わりに
挟む画像を8枚つくったもの。`node images/gen_cards.js` で再生成できる。

**コアラの有料noteに入っている画像は「お客様の声のスクショ4枚」だけで、章扉は無い。**
つまりこれはコアラに無い要素。実績が出たらお客様の声も追加するけど、
架空の声は作らない方針なので、それまではこの8枚だけで運用する。

## 挿入位置

**`contents/note用_有料部分.txt` に目印を入れ込み済み。**
`▼▼▼ 画像を挿入：ファイル名 ▼▼▼` という行が12箇所ある。
noteに貼り付けたあと、この行を画像に差し替えればいい(行ごと消して画像をアップする)。

目印は `▼` で検索すると全部出てくる。作業が終わったら、`▼` が残っていないか
確認すること。

## 仕様

- **2560×1440px (16:9 / 2倍解像度)**。noteは横620pxで表示するので、
  2倍で書き出しておくと高解像度ディスプレイでもボケない。
- 書体: **Zen Maru Gothic**(丸ゴシック / SIL Open Font License・商用可)。
  `images/fonts/` に同梱。ライセンスは `images/fonts/LICENSE_NOTE.md`。
- 配色: クリーム `#FBF8F1` / 濃い緑 `#7A9A6E` / 淡い緑 `#EAF1E5` / 文字 `#3F3C36`
- 絵文字は🦥と🌿の2種類だけ。💤🎮✨は青や黄色が強くてパレットから浮くため不使用
  (`knowledge/02`の絵文字パレットとは別の、画像専用ルール)。

## 作り直し方

```
node images/gen_cards.js
```

文言を変えるときは `gen_cards.js` 上部の `CARDS` 配列を編集する。
`title` の `\n` が改行位置。長いタイトルは2行に収まるところで切ること。

# 解説図 4枚

章扉と違って、**文章だけだと伝わりにくい箇所**に添える図。
`node images/gen_figures.js` で再生成できる(高さは内容に合わせて自動)。

## 貼る位置

| 画像 | 貼る場所(この見出しのすぐ下) | なぜ図が要るか |
|---|---|---|
| `fig1_時差.png` | 【見出し】これは「時差」があるから | **この商品の核。**「お金の引き寄せは時差の間が静か / 夫婦仲は時差の間に殴られる」という2本の時間軸の比較は、文章だと3〜4段落かかるが図なら一目 |
| `fig4_だったら.png` | 【見出し】だから「だったら」で入る | 「なれますように」と「だったら」の主語の違いが、左右に並べると一瞬でわかる |
| `fig3_証拠のハードル.png` | 【見出し】証拠のハードルを、下げる | ハードルの高さが「高すぎ / これでいい」の2段だと視覚的に理解できる。実行の精度が上がる箇所 |
| `fig2_手放す.png` | 【見出し】「望んでいい」まま、外せる | **いちばん誤解されやすい箇所。**「望みは残す / 条件だけ外す」を分離して見せる |

## 図にしなかったもの(検討済み)

| 箇所 | 見送った理由 |
|---|---|
| テレビのチャンネル(販売ページ) | 比喩そのものが既に明快で、図にしても情報が増えない |
| 追いかけると逃げられる | 同上。1行で伝わっている |
| ステップ6「サインは大きくならない」 | 比較対象が無く、図の形にならない |
| ステップ7「崩れても戻る」の波線 | 図にできるが、ステップ7は短く、図が本文より重くなる |

**図は多いほど良いものではない。** 4枚を超えると、どれが重要なのか分からなくなる。

## 図の作り方のルール(重要)

**「位置・高さ・距離」そのものに意味を持たせる。** これを満たさないものは、
図ではなく「装飾した文章」なので作らない。

初版は4枚中3枚が、角丸の箱に文を入れただけの縦積みだった。図に見えるだけで、
文章を読むのと手間が変わっていなかった。作り直して、それぞれ次の構造にした。

| 図 | 空間が表しているもの |
|---|---|
| fig1 時差 | **横軸＝時間。** 決めた→良くなる の途中に矢印が降ってくる位置が「時差のあいだ」 |
| fig2 手放す | **分岐。** ひとつの塊が2つに割れて、片方だけ色が薄くなる |
| fig3 証拠のハードル | **高さ。** ハードルの高低差そのものが主張 |
| fig4 だったら | **距離。** 円の外にいるか、中にいるか |

チェック方法: **図から文字を全部消しても、構造が残るか。**
残らなければ、それは図ではない。

## 仕様(解説図)

- 幅2560px(2倍解像度)、高さは内容に応じて可変
- 中身はインラインSVG。`images/gen_figures.js` の `svg:` を編集する
- `images/trim.py` が下端の余白を自動で切る(Pillowを使用)
- 配色・書体は章扉と共通。赤系 `#C08163`/`#F3E2DA` は
  **「外すもの・高すぎるもの・いままでのやり方」の合図としてのみ**使う

### はまりどころ: viewBoxのはみ出し

SVGは `viewBox` の外に出た部分が**黙って切り落とされる**。エラーも警告も出ない。
円は `cy + r`、矩形は `y + height` が下端になるので、viewBoxの高さがそれ未満だと
円が欠けた状態で書き出される(fig4で実際に起きた)。

図形を足したり動かしたりしたら、必ず下端を確認すること。
