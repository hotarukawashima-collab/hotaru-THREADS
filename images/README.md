# 有料note用 章扉画像

## 何これ

有料本文(約14,000字)は章扉が無いと読み手が疲れるので、ステップの切り替わりに
挟む画像を8枚つくったもの。`node images/gen_cards.js` で再生成できる。

**コアラの有料noteに入っている画像は「お客様の声のスクショ4枚」だけで、章扉は無い。**
つまりこれはコアラに無い要素。実績が出たらお客様の声も追加するけど、
架空の声は作らない方針なので、それまではこの8枚だけで運用する。

## 仕様

- **2560×1440px (16:9 / 2倍解像度)**。noteは横620pxで表示するので、
  2倍で書き出しておくと高解像度ディスプレイでもボケない。
- 書体: **Zen Maru Gothic**(丸ゴシック / SIL Open Font License・商用可)。
  `images/fonts/` に同梱。ライセンスは `images/fonts/LICENSE_NOTE.md`。
- 配色: クリーム `#FBF8F1` / 濃い緑 `#7A9A6E` / 淡い緑 `#EAF1E5` / 文字 `#3F3C36`
- 絵文字は🦥と🌿の2種類だけ。💤🎮✨は青や黄色が強くてパレットから浮くため不使用
  (`knowledge/02`の絵文字パレットとは別の、画像専用ルール)。

## 作り直し方

```
node images/gen_cards.js
```

文言を変えるときは `gen_cards.js` 上部の `CARDS` 配列を編集する。
`title` の `\n` が改行位置。長いタイトルは2行に収まるところで切ること。
