## 09:00 ／ 型6・対話 ◆ ／ 73字 ★差し替え


**コアラの対話型で最高(♡318)の構成を、そのまま使った。**

```
コアラ ♡318                    なまけろ子
🐨「月100万円欲しい」      →   🦥「夫と喧嘩しなくなればいいな」
宇宙「100で満足するの?」   →   宇宙「喧嘩がないだけでええの?」
🐨「…」                    →   🦥「…」
宇宙「で、いくら欲しいわけ?」→  宇宙「で、ほんまはどうなりたいん?」
🐨「500マン」              →   🦥「毎日笑ってたい」
宇宙「おっけ。用意するわ」  →   宇宙「おっけ。用意するわ」
```

**落ちは「上限を決めてたのは宇宙じゃなくて、こっち」。**
夫婦仲で言えば「喧嘩さえなければいい」が、自分で下げた天井。

### ボツにした版(お茶)と、なにが違うか

```
✕  🦥「夫が優しくしてくれない」
   宇宙「お茶は?」          ← 物の話にすり替わっている
   🦥「…置いてあった」
   宇宙「それや」            ← 「それ」が何を指すのか分からない
```

**コアラの宇宙は、言われた不満を無視して本人に返す。** 物の話はしない。

| | 宇宙の2行目 | 表示 |
|---|---|---|
| 9/20 12:00 | 「で、どうなってほしいん?」 | **1,252**(フォロー6人) |
| コアラ ♡318 | 「100で満足するの?」 | コアラ対話型の最高 |
| ボツ版 | 「お茶は?」 | ─ |

> **お茶のエピソードは今後使わない。** 「置いてあった」「電気が消してあった」は
> 3回とも伝わらなかった。証拠として弱い題材として`エピソード使用状況.md`に記録。
