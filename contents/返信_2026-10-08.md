### 引き寄せへの接続のしかた

| | |
|---|---|
| **「無理に許したり感謝したりせんでええ」** | **引き寄せの話。**はるの♡56「無理やり感謝しなくていい。毎日トイレ掃除しなくていい」と同じ |
| **「どうやって」は宇宙に放り投げる** | **ルートは手放す。**コアラ型③の核 |
| **決めるのは「わたしはどうなりたいか」だけ** | **夫ではなく自分。**世界観どおり(夫の世界には入れない) |

### 安全のために、やらなかったこと

| | |
|---|---|
| **「決めたら夫が戻る」と書かない** | **不倫が現在進行形。戻らなかったとき、本人が「決め方が足りなかった」と自分を責める** |
| **「なりたい結果」を夫の話にしない** | 「わたしはどうなりたいか」に限定した |
| **「優しくしなさい」と言わない** | 「優しくなんてできない」に、できなくていいと置いた |
| **時期を一切書かない** | |

> **⚠ `05_NGリスト.md` の「DV・モラハラなど今すぐ状況を変えるべきケース」に近い。**
> **「待ってたら戻る」と書いたら加害になる。**

### 返さないという選択もある

**重すぎると感じたら、返さなくていい。中途半端に返すほうが傷つけることがある。**
