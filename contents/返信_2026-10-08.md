### なぜこう書いたか

| | |
|---|---|
| **「許せず恨みが募る妻」を先回りで否定した** | 相手が自分を責めている箇所。型⑤(ゆきぴー)の形 |
| **「優しくしなさい」と言っていない** | 「優しくなんてできない」に対して、できなくていいと置いた |
| **「決めたら夫が戻る」と書いていない** | **不倫が現在進行形。戻らなかったとき、本人が「決め方が足りなかった」と自分を責める** |
| **「どうしたら打破できるの？」に、正直に答えた** | コアラも「いつ？」に「いつだろうね〜💦 自分以外のひとを動かすのはコツがいる」と正直に返している |
| **夫の話を一言も約束していない** | 世界観どおり。夫の世界には入れない |

> **⚠ このケースは `05_NGリスト.md` の「DV・モラハラなど今すぐ状況を変えるべきケース」に近い。**
> **「待ってたら戻る」と書いたら加害になる。**
> **過去に「宇宙にもそう捉えられてしまうね」という返信が来た記録がある(METHOD 9-2)。**

## ★ 気づいたこと

**返信6件のうち5件が、再投稿に付いている。**

```
10/7 21:00 ★再投稿(♡280の文)  → 返信5件
10/8 21:00 ★再投稿(♡110の文)  → 返信1件
```

**「もうすぐ〜になるよ」は、読者に声を出させる型。**
**♡だけでなく、返信を生む。**

**そして返信の中身が全部「本当に？」「私もそうなりたい」「戻ってきて欲しい」。**
**読者は手順を聞いていない。確かめたがっている。**
