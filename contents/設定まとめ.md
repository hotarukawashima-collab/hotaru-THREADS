# 3. ★★★ 身バレ防止

### ずらした設定 ── 1つだけ

| | 実際 | **設定** |
|---|---|---|
| **別居期間** | 5ヶ月(メインアカウントのbio) | **1年** |

**★ 設定であって、実体験ではない。** `本人の実体験_確認済み.md` には入れていない。
**★ ずらしても、投稿とnoteに数字は書かない。**

```
⭕ いちばん長かった時期 / 長いこと離れてた / 顔は合わせても用件だけやった
✕ 1年別居してた / 1年かかった / 1年で戻った
```

### 書かないこと ── ずらすのではなく、範囲を狭める

| 項目 | 扱い |
|---|---|
| 子どもの人数・年齢・性別・学年 | **一度も書かない**(「絵本を読む年齢」までで止める) |
| 夫の業種・役職・勤務形態 | **一度も書かない**(「出張がある」までで止める) |
| 地域 | **一度も書かない**(関西弁は維持。地名・細かい方言差も出さない) |
| **別居の理由** | **一度も書かない**(人物像を一点に絞り込むので、いちばん特定されやすい) |
| **再同居のきっかけ** | **一度も書かない** |
| 会わなかった期間 | **期間で言わない。質で言う** |
| 期間の数字(◯ヶ月・◯年) | **一切書かない** |

**→ 詳しくは `CHARACTER.md`「身バレ防止の設定」**

# 8. 実体験の扱い

**使えるのは、辿れる記録があるものだけ。**

```
⭕ contents/本人の実体験_確認済み.md     A〜Dの確認済みだけを使う
✕ 「過去のAI原稿に書いてある」は根拠にならない
✕ 廊下で深呼吸  ← 2026-10-12に本人が「実話ではない」と否定
```

**⚠ 素材が切れかけている。** 子ども角度は4つとも使用済み。
型12の署名に使える確認済みの事実が少ない。
