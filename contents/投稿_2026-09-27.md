## 07:00 ／ 型4・愛に浸る ／ 29字

```
夫のこと、諦められへんのやったら、
無理に諦めんでええからね🌿
```

**元:** 08・セリフあり

**原文にある、本人が自分に言った言葉をそのまま使った。**

> 彼のことは好きで自分の方を振り向いてほしい、それを諦めるってできないから、
> **無理に諦めないでいいや**

**「諦めなさい」でも「諦めるな」でもない。** どちらも指示になる。
**「無理に諦めんでええ」は、今そこにある気持ちを、そのまま置いておく許可。**

> 別居中・離婚を言われた人に、いちばん効く1本になるはず。

### ★ 一度こう書いて、差し戻した

```
✕ 夫にイラッとしても、
  「どうでもええわ」にはならへんやろ?🌿
```

**結論が書いていない。** 問いかけて終わっているので、読んだ人は「そやけど、で?」になる。
しかも**15:00と同じことを言おうとして、肝心の答えだけが抜けていた。**

```
07:00(ボツ) 夫にイラッとしても、「どうでもええわ」にはならへんやろ?  ← 問いだけ
15:00       夫が憎らしいのは、大事やからやで。どうでもよかったら、なんも思わん  ← 答えがある
```

**問いかけ自体は悪くない。コアラの問いかけ型は平均94.2ある。**
**ただしコアラは、問いかけを1行目(入口)に置いて、そのあと答えを書いている。**

```
コアラ koara_081「ねぇ、知ってた?」 ← 1行目。このあと本文が続く
```

> **問いかけは入口に使う。出口に使わない。**
