## 最重要の発見:入口に「無料note」がある

`analysis_コアラ7日間ワーク構造.md` で「無料配布物が存在しない」と書いたが、
**無料の読み物は存在していた。** 正しい導線は次の通り。

```
Threads(無料) → 無料note「はじめまして」 → 7日間ワーク ¥3,980 → 本商品 ¥8,900
```

ただし性質が違うので、前回の分析は否定されない。

- **無料note = 配布物ではなく「名刺」。** メール登録もLINE登録も要求しない。
  リストを取らない。リンクすら貼らない。**取引が一切発生しない。**
- 役割は1つだけ:**「この人は誰で、どういうスタンスなのか」を1本で分からせること。**
- 販売ページ(¥3,980)の冒頭ブロック2〜3と**内容が大きく重複している**。
  暮らしの描写も、Threadsのピン留め埋め込みも、同じものを再利用している。
  → **使い回しは正しい運用。** 毎回書き下ろす必要はない。

## 型として抜き出せる要素

### 1. 見出しは4つだけ。すべて「主張」で、「説明」がない
「〜とは」「〜の方法」「3つのコツ」のような解説型見出しがゼロ。
4つの見出しを並べるだけで主張が読める。

```
がんばる引き寄せは、していません   ← 常識破壊(差別化)
ちょっとずつを毎日やる             ← 先回りの否定(誤解を潰す)
力を抜いたほうが叶いやすい         ← 許可を出す
このnoteで伝えていくこと           ← 読者定義+締め
```

### 2. 比喩が4つ。すべて「力を抜く」の実演
ハンモック / 握りしめた手 / 亀 / 山の頂上。
**抽象語で説明せず、必ず物に置き換えて見せている。**
「潜在意識が」「波動が」といった専門語は**1回も出てこない**。

### 3. 権威づけが「肩書き」ではなく「暮らしの情景」
実績数値・資格・相談件数を一切書かない。代わりに生活を描く。
→ `knowledge/01` の経歴ルール(bioで1回、本文では引っ張らない)と整合。

### 4. 順番が「否定 → 許可」で固定
先に読者を縛っているものを外し(ブロック5・6)、そのあとに許可を出す(ブロック7)。
逆順にすると「ゆるくていいよ」が言い訳に聞こえる。

### 5. 売らない
価格・商品名・リンク・「詳しくは」が1つもない。
売り込みは販売ページに完全に隔離されている。

  `04_ネタ地図.md` の**予言型(主語が相手)=使えない断定**に該当する。
  → 主語を読者に寄せて処理した。
- 「戻る」は使わない(`knowledge/04`)。別居前はおままごと婚なので「良くなる」で通す。
