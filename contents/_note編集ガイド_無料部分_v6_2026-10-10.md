# note編集用ガイド（無料部分 v6）

> **貼り付け本文には、この情報を混ぜないこと。** これは作業用。
> **noteの編集画面で、手で設定していく。自動では反映されない。**

```
使う順番
  1. v6から作った貼り付け用の本文を、noteの本文欄にそのまま貼る
  2. このガイドを上から見て、見出し・太字・箇条書きを手で設定する
  3. 最後に、無料/有料の境界を設定する

★ 現在の contents/note用_無料部分_貼り付け用.txt は v4から作ったもの。
  v6を採用するなら、貼り付け用も作り直すこと。
```

★【タイトル】【サブタイトル】の2行は、本文に貼らない。目印として入れてあるだけ。

## 2. 枠で囲ってある3箇所（貼り付け用では ``` を外す）

```
① 「このnoteで整えるのは、そこへ向かう『土台』のほう」の中
     ・自分の前提の置き方
     ・うまくいかない日の、気持ちの戻し方
   → 箇条書きのままでいい

② 「7ステップで、なにをするのか」の7行
     1  望む未来を選ぶ 〜 7  不安な日も、望みを選び直す
   → 番号つきリスト、または引用枠にすると見やすい

③ 有料部分で手に入るものの6行
     ・ひとつめの、始め方 〜 ・もう全部やめようかなって日に、どこへ戻るか
   → 箇条書きのままでいい
```
