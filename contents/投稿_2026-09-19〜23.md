## 抽象語には、必ず具体のアンカーを付ける(2026-09-18 追加ルール)

初版には「ゆるむ」を単独で使った投稿が9/19だけで3本あり、
「意味をつける」「前提で暮らす」「設定しておく」も同じ状態だった。
**どれも、それ単体では絵が浮かばない。**

コアラを調べると、**抽象語を単独で使った投稿は1本も無い。** 必ず具体が付いている。

| コアラの投稿 | 付いている具体 |
|---|---|
| 「あったかい温泉に入るみたいに、体の力を抜いてみて〜♨️」 | 温泉 |
| 「今60%の力でできればそれでいいの〜」 | 数字 |
| 「変わる人は『もういいや〜』って力抜く人だよ」 | セリフ |
| 「相手が不機嫌でも、『私何か悪いことしたかな?』ってしない」(koara_188) | セリフ |

**アンカーになるもの:** 「」でくくったセリフ / 数字 / 目に見えるもの(絵本・膝・洗濯物)。
このうち1つも無い投稿は、書き直す。

初版から直した6本:

| 投稿 | 何が問題だったか |
|---|---|
| 9/19 12:00 | 「先に空気がゆるむほうが」── ゆるむが単独 |
| 9/19 15:00 | 「意味をつけてるのはこっち」── 抽象語「意味」を2回使って説明になっていない |
| 9/19 18:00 | 「どっちがゆるいか」── ゆるむが単独。しかも1行目と2行目が繋がっていない |
| 9/19 21:00 | 「あなたが先にゆるんでいい」── ゆるむが単独。しかも主力枠 |
| 9/20 07:00 | 「設定しておくだけでいい」── 設定が単独 |
| 9/21 07:00 | 「もう仲がいい前提で、暮らしてるだけ」── 前提が単独 |

9/19 15:00 の差し替え先は koara_162(♡335)「色々考えすぎるよりも『もう宇宙、
自動運転よろしく〜!』って丸投げでお任せしちゃった方が」と同じ型。
この題材でコアラが最も伸ばした形。
