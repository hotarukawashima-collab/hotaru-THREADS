# 追わない夫婦仲をつくる、7つのゆるレッスン

## まずは、ゆる〜い3つのお約束

ここから7つのゆるレッスンを始めるよ〜🦥

その前に、3つだけ約束してほしいことがあるんだけど……

**①がんばらないこと。**
できない日があっていいよ。むしろ、あって当たり前。
7つきっちりやらなきゃ、って思った時点で宿題になっちゃうからね〜。

**②夫に、何もさせようとしないこと。**
このワーク、ぜんぶ**あなたの中だけ**で完結するよ。
話しかけなくていいし、言い方を変えなくていいし、
何かしてもらう必要もないの。

**③確かめないこと。**
「効いてるかな」って相手を観察し始めると、
それはもう「追いかけてる」になっちゃう…💤
やったら、あとは放っておこ〜。

この3つだけ守れたら、あとはゆるっゆるで大丈夫だよ🌿
ナマケモノのペースでいこ〜🦥

---

### はじめる前に、ひとつだけ

このワークは、喧嘩が多いとか、会話が減ったとか、
そういう「よくある夫婦のしんどさ」のために書いてるよ。

もし今、暴言や暴力があったり、
お金を自由に使わせてもらえなかったり、
眠れないとか食べられないとか体に出てるなら、
このワークより先に、ちゃんと相談してね。
それは、力を抜いてどうにかする話じゃないから。
