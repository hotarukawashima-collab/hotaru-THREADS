### 「別居」を入れていい理由(¥1,980では外した語)

**¥1,980は「夫と会話が減ったあなたが」= 読者を名指している。**
だから別居はターゲット外なので外した。

**高額の「別居から」は、著者の過去の底であって、読者の現在地ではない。**
**コアラの「貯金0円から」も同じ。** 読者が貯金0円とは言っていない。

> **読者を名指す位置に、ターゲット外の語を置かない。**
> **自分の経歴を言う位置なら置ける。**

## 5. 各PHASEに何を書くか

**PHASEは著者の実話の進行で切る。**(コアラも貯金0円→セミリタイアの順)
**読者はどのPHASEにいてもいいので、PHASE8で現在地を選ばせる。**

| | 書くこと | ¥1,980と被らないか |
|---|---|---|
| **第０章** | 決めてるのに動かん理由。決めたあとに要る『あるもの』 | ○ 土台は「決め方」まで |
| **P1 目も合わせへん期** | 底にいる時点でもう出てるサイン。**「まだ気にしてる」こと自体がサイン**。目も合わせへんかった頃の話 | ○ |
| **P2 決めた直後期** | 決めた翌日に夫が冷たいのは正常。**ここでやめる人がいちばん多い**。やめなかった理由 | ○ |
| **P3 時差期** | いちばん長くてしんどい時期の過ごし方。**夫を見んで過ごす方法**。この時期にやったことがP6で効く(伏線) | ○ |
| **P4 ちょっと動き出した期** | 「ごはんいる?」が出た日。**嬉しくて確かめに行って、ぜんぶ戻した話**。ここが本商品の山 | ○ |
| **P5 揺り戻し期** | 戻ったときに手放さんもの。**戻ったように見えても前提は崩れてない** | ○ |
| **P6 ふつうに喋れる期** | P3でやってたことが効いてくる。**膝枕・くだらんテレビ・目尻が下がってる** | △ 体験談は投稿で既出。**使用済みエピソードは `contents/エピソード使用状況.md` で確認** |
| **P7 新婚以上期** | 良くなってから崩さへん方法。**「取り戻した」ではなく「良くなった」**(`01`) | ○ |
| **P8 あなたの現在地** | **診断 → 90日の順番。** どのPHASEにいるか選ばせて、そこから90日分の順番を渡す | ○ ここが高額の核 |
| **おまけ1** | 信じきれてないまま遊べる小ワザ | ○ |
| **おまけ2** | 布団の中2分。**体の感覚**で入れる(¥1,980ステップ2は映像の妄想なので別物) | △ **ステップ2と違うことを明記する** |

### 1つのPHASEの中の形(¥1,980と同じ形を使う)


## 6. 字数と価格

| | コアラ | なまけろ子 |
|---|---|---|
| 土台 | ¥4,980 / 7日間ワーク | ¥1,980 / 7ステップ **45,600字** |
| 本商品 | **¥8,900 / 約7万字** | **これ** |
| 倍率 | **1.79倍** | |

**目安:60,000〜70,000字。** 土台が45,600字あるので、下回ると値段がつかない。

### 価格 ★確定 ¥4,980(2026-10-03 運用者の判断)

```
土台 ¥1,980   →   高額 ¥4,980      2.51倍
コアラ ¥4,980 →   本商品 ¥8,900    1.79倍
```

**コアラより倍率が高い。** ただし¥4,980はコアラの土台価格でもあり、
このジャンルの価格帯には収まっている。

#### この価格が決めてしまうこと ★

**`knowledge/01_アカウント設計.md`では、土台の値上げ上限を¥4,980(コアラの現在価格)に
置いていた。高額を¥4,980にすると、そこがぶつかる。**

```
値上げの道筋(改)   ¥1,980 → ¥2,980 → ¥3,980 でいったん止める
                   高額が¥4,980なので、土台はそこまで上げられない
```

**土台の値上げ上限は ¥3,980 になる。** 2段の値段が同じになると、
**どちらを買えばいいか分からなくなる**(コアラも¥4,980と¥8,900で離してある)。

**順番はコアラと同じ:土台を値上げ → 高額を出す。**
コアラは7日間ワークを ¥3,980 → ¥4,980 に上げてから本商品を出している。

### 出す時期

**コアラは7日間ワーク(8/14)の13日後に本商品(8/27)を出している。**

> **ただし、なまけろ子の土台はまだ1件も売れていない。**
> **買う人がいない状態で2段目を出しても、売れるのは土台が売れたあと。**
> **作るのは今でいい。出すのは土台に実績が出てから。**
> (販売ページのブロック11「お客様の声」も、土台の購入者が出ないと埋まらない)
