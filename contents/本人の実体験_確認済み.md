## このファイルの使い方

```
・投稿やnoteで本人の体験を書くときは、必ずここから引く
・ここに無い体験は、運用者に確認してから足す

```

**確認の強さを4段階で分けてある。A が最も強い。**

# ★★★ 設定と、実体験を混ぜない（2026-10-16）

**別居期間は、身バレ防止のため実際とずらした設定になっている。**

```
実際    5ヶ月（メインアカウントのbio）
設定    1年
```

**★ これは設定であって、実体験ではない。だからこのファイルの表には入れない。**
**→ `CHARACTER.md`「身バレ防止の設定」**

**そもそも投稿・noteには数字を書かないので、この表に無くても困らない。**
