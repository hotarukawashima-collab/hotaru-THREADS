## 最重要の発見:リストを取る無料配布物が存在しない

> **【2026-09-17 訂正】** 当初「無料配布物が存在しない」と書いたが、無料の読み物
> (note 1本目「はじめまして。脱力引き寄せのコアラです」)は存在していた。
> ただし性質が違うため、下の結論そのものは変わらない。
> 詳細は `contents/analysis_コアラ無料note_はじめまして.md`。

コアラの導線は次の通り。

```
Threads(無料) → 無料note「はじめまして」 → 7日間ワーク ¥4,980 → 本商品 ¥8,900
              ※7日間ワークは公開時¥3,980。2026-09-28時点で¥4,980
```

**bioのリンクを踏むと、いきなり有料の販売ページ。** メール登録もLINE登録も無料PDFも挟まない。
無料noteは挟まるが、**そこでも何も要求せず、リンクすら貼らない**(自己紹介のみ)。
一般的な「無料配布でリストを取ってから売る」型ではなく、
**SNSの投稿量そのものを集客装置にして、直接低単価商品へ落とす**設計。

(ゆきぴーは逆に、Notion→オプチャの無料導線を取っている。この点は2アカウントで方針が違う)

## ★★ 2026-10-01 改訂版との差分(重要)

**コアラは販売ページを書き換えている。** 9/18に取った版と、10/1の実物は別物。
新しい版は `reference/koara/7日間ワーク_無料部分_2026-10-01版.txt`。

### 足されたもの

**① タイトル直下に、限定部数と完売の履歴**

```
引き寄せ体質をつくる、7日間ワーク

9/25 限定部数 100部 → 完売
8/16 限定部数  50部 → 完売
今が最安値だよ〜✨
```

**3行で、社会的証明・希少性・値上げ予告を全部やっている。**
しかも**過去の完売を2回ぶん並べて、部数が50→100に増えている**ので、
「売れている」と「次はもっと高い」が同時に伝わる。

> **実績ゼロでも「限定部数」だけは使える。**
> コアラも8/16の50部から始めている。売れたら「→完売」を足していく。

**② 読者の疑問を挟んでから商品を出す**

```
これ以上、がんばる引き寄せはおしまい!
だからもう、これ以上がんばらなくて大丈夫だよ。
でも「がんばらない引き寄せって、具体的に何をすればいいの〜?」って思うよね。
そこで、コアラの出番です。
```

**旧版は「そこで、コアラの出番です」が唐突だった。** 1行はさんで橋を架けている。

**③ お客様の声に「1ヶ月で効果があった読者さん」を追加**

### ★ 削られたもの

**ラジオの周波数のたとえ話が、丸ごと消えている。**

```
旧版  ラジオの周波数を合わせるときって、最初は「ザーッ」て雑音しか聞こえないよね。
      でも、つまみをほんの少し動かすと、急に音楽が聞こえてくる瞬間がある。
      現実も、それとよく似てるよ。
      ↓
新版  最初に変えるのは、今いるあなたのチャンネルだけでいいの。
```

**たとえ話を捨てて、結論だけ残した。**
`knowledge/03_投稿の型.md` の「比喩を使わない」と同じ方向。
**コアラ本人が、自分の販売ページから比喩を削っている。**

## 夫婦仲アカウントへの移植

### そのまま使えるもの

- **ブロック6「あなたのせいじゃないよ」を見出しで立てる。** 夫婦仲では特に効く。
  ターゲット(喧嘩が多い女性)はすでに「私が悪いのかも」と思っているため。
  `05_NGリスト.md`の「関係悪化を本人のせいにしない」とも完全に一致する。
- **ブロック2の「生活の情景で権威を作る」。** 夫婦仲では数字が出しにくいので、
  情景のほうが移植しやすい(例:週末に一緒にごはんを食べている、など)。
- **ブロック11の伏せ字目次。** 文字数まで見せる形式を踏襲する。
- **ブロック3のピン留め投稿の埋め込み。** 確定済みのピン留め1本目をそのまま貼る。

### 変更が必要なもの

- **ブロック13の二者択一。** 「このまま半年」という煽りは、夫婦仲では
  「早くしないと手遅れ」という**結果の脅し**になりうる(`05_NGリスト.md`の結果保証の裏返し)。
  時間で煽らず、「今日から力を抜いてみる」という提案に置き換える。
- **お客様の声(ブロック9)は、実績が出てから。** 架空の声は作らない。
  初期は省略し、実際の感想が集まってから追加する。
