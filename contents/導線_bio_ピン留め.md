## 2. ピン留め ── 2連投にする

**コアラの実物**

```
1/2  数年前は鬱で、仕事もできなくて、貧乏で、恋人もいなかったけど、
     叶ってる前提で過ごしてたら、本当に全ての願いが叶ったよ🐨
     今どん底の人も、安心して。絶対大丈夫だから。        ← ♡152

2/2  7日間で引き寄せ体質になれる方法は
     ここで詳しく書いてるよ〜🌿
     note.com/koara...                                ← ♡9
```

**1本目で人を集めて、2本目に流す。2本目は♡9でいい。役割が違う。**

### 1/2 ── 今のピン留めをそのまま使う

```
別居してたころは、会話もなくて、笑い方も忘れて、正解ばっかり探して
へとへとだったけど、頑張るのをやめたら新婚のころよりいい夫婦に
なっちゃったよ🦥
今しんどい人も、大丈夫。頑張りすぎてるだけだから。
```

**実績:表示686・♡4・返信1。** 体験談の4要素がそろっている唯一の投稿。

### 2/2 ── コアラの型をそのまま埋め替える

**コアラの型**

```
[期間]で[○○]になれる方法は
ここで詳しく書いてるよ〜🌿
[URL]
```

```
コアラ    7日間で 引き寄せ体質 になれる方法は
なまけろ子  7ステップで のほほん夫婦体質 になれる方法は
```

### A案(推奨)

```
7ステップでのほほん夫婦体質になれる方法は、
ここで詳しく書いてるよ〜🌿

▼
https://note.com/〜
```

**「のほほん」はbioにも販売ページのタイトルにも入っている、このアカウントの看板ワード。**

| | |
|---|---|
| bio | ゆる〜く、頑張らない、**のほほん**引き寄せで |
| 販売ページ | 頑張らないほど、引き寄せる。夫婦仲が良くなる**のほほん**7ステップ |

**コアラの「引き寄せ体質」と同じ位置に、同じ役割の言葉を置ける。**

### B案 ── 変化を名指す

```
7ステップで追わんでええ妻になれる方法は、
ここで詳しく書いてるよ〜🌿

▼
https://note.com/〜
```

**有料noteのタイトルが「追わない夫婦仲をつくる、7つのゆるレッスン」。**
「追わない」は本文の中心でもある。**中身との一致はこちらが上。**

### C案 ── 結果を名指す

```
7ステップで勝手に仲が良くなる体質になれる方法は、
ここで詳しく書いてるよ〜🌿

▼
https://note.com/〜
```

**いちばん分かりやすいが、いちばん長い。**
コアラの2/2は3行で、これも3行に収まる。

### どれを選ぶか

| | 強み | 弱み |
|---|---|---|
| **A のほほん夫婦体質** | **看板ワードが入る。ブランドが積み上がる** | 初見だと意味が取りにくい |
| **B 追わんでええ妻** | **noteの中身と一致。変化が具体的** | 「妻」で読者を限定する |
| C 勝手に仲が良くなる体質 | いちばん分かりやすい | ブランドワードが入らない |

**A推奨。** ただし**ピン留めは初見の人が見る場所**なので、
分かりやすさを優先するならC。

## 5. まだ使えないもの(購入者が出てから)

コアラの告知4型のうち、3つは購入者がいないと使えない。

| 型 | コアラの実例 | ♡ |
|---|---|---|
| 値上げ予告 | ノートの値段を、明日から値上げすることにしました | 8 |
| 購入者の報告 | 買ってくれた方からこんな報告が来た…! 全文載せちゃうね | 7 |
| 買ってくれてありがと | みんな昨日もノート買ってくれてありがと〜 | 6 |

**最初の購入者が出たら、この3つが使えるようになる。**
**とくに「購入者の報告」は、販売ページの空いている「お客様の声」も埋められる。**
