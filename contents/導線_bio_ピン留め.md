#### なぜ「土台」なのか ★この判断が本体

**「体質」は借りられない。** コアラ固有の看板ワードであり、
`06_パクリ防止.md` の「コアラ固有の言い回しを捨てる」に当たる。

そのうえで、「土台」が他の候補に勝った理由は**高額noteとの関係**。

```
体質　→　その人がそうなる　　　　（そこで完結する）
土台　→　その上に、まだ何か建つ　（続きがある)
```

**「土台」と言った時点で、上物の存在が前提になる。**
2段構えの商品ラインを持つなら、「体質」より向いている。
(商品ラインは `knowledge/01_アカウント設計.md`「価格と商品ラインの方針」)

#### 「が整う」であって「をつくる」ではない

コアラの商品タイトルは「引き寄せ体質を**つくる**、7日間ワーク」。
**動詞を揃えるならこちらだが、採らない。**

「つくる」は他動詞で、作業になる。このアカウントの約束は**頑張らない**なので、
自動詞の「整う」にして「やってたら勝手にそうなってた」の側に寄せる。

> **完全再現の対象は型であって、アカウントの芯を裏切ってまで動詞を揃えない。**

#### 落ちた案と、その理由

| 案 | 落ちた理由 |
|---|---|
| A のほほん夫婦体質になれる | 「体質」がコアラ固有の造語 |
| B 追わんでええ妻になれる | 同上。加えて「妻」で読者を限定する |
| C 勝手に仲が良くなる体質になれる | 同上。24字で最長 |
| ① 夫婦円満を引き寄せる | **結果を名指している。高額noteの場所を潰す** |
| イ 「もう仲がいい」って思える | **引き寄せの言葉も夫婦の言葉も入っていない** |
| ロ 夫婦円満グセがつく | 「グセ」が結果に寄りすぎ |
| ハ 夫の機嫌が気にならなくなる | 7ステップ全体より狭い |

**①の失敗が最重要。** 「夫婦円満を引き寄せる方法」は、
コアラの商品ラインでいうと**¥8,900側のタイトル**にあたる。
入口の商品で結果を約束すると、上の商品の必要性が消える。

**イの失敗も記録に残す。** 通常投稿には
「引き寄せの言葉が1つも無い投稿は出さない」(`CORE_WORDS`)と
「夫が出てこない投稿は出さない」(大原則④)を掛けているのに、
**いちばん人目につくピン留めでどちらも抜けていた。**
確定稿は「引き寄せる」と「夫婦仲」の両方を含む。

#### 2行目について

**「ここで詳しく書いてるよ〜🌿」はコアラと12字一致する。**
`06_パクリ防止.md` はThreads投稿を対象外にしているため、このまま通す。
気になる場合の振り先: 「中身はぜんぶここに置いといたよ〜🦥」
