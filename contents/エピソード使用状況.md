## ★まず結論:エピソードを分けても、たぶんバレる

エピソードより強く紐づくものが先にある。

| 紐づく強さ | 何が | 分けられるか |
|---|---|---|
| **最強** | **「離婚寸前の別居から、新婚よりいい夫婦になった」という経歴の核** | **分けられない**。両方のbioに書くことになる |
| 強 | note・リンク先(同じnoteアカウント、同じ決済) | 分けられるが手間 |
| 強 | 投稿時間帯(両方が同じ7枠で回っていれば同じ人だと分かる) | 分けられる |
| 中 | 文体(「〜だよ〜」「〜なんだよね」) | 分けられるが、ジャンルが違うので自然に分かれる |
| 中 | **特徴的すぎるエピソード**(下の★印) | **分けられる。ここだけ管理すればいい** |
| 弱 | ありふれたエピソード | 分ける必要なし |

**つまり「分ける」のではなく「★印だけ片方に寄せる」が現実解。**

**論点の事前突き合わせは不要。** 管理するのは下のエピソードだけでいい。

### 4要素にしたときの形

**Beforeは「別居していたのでひとりでやっていた」で統一できる。**
これは別居という事実から導けるので、作り話にならない。

```
A  別居してたころは、子どものことはぜんぶひとりで抱えてたの。      ←①
   「うちはもう仲がいい」って決めて、がんばるのをやめたら、        ←②
   今はわたしが仕事の日、夫が朝から家事も育児もやってる。          ←③
   今ひとりで抱えてる人も、大丈夫だからね🌿                       ←④

B  別居してたころは、公園に連れて行くのもわたしだけだったの。      ←①
   …                                                          ←②
   今は夫が全力で走り回って、わたしより頼りにされてる。            ←③
   …                                                          ←④

C  別居してたころは、子どもの「なんで?」に答えるのも、ぜんぶわたしだったの。←①
   …                                                          ←②
   今は夫が本気で答えてる。わたしより詳しいし、説明もうまい。       ←③
   …                                                          ←④
```

**Cがいちばん強い。** 「なんで?」という**具体的なセリフ**が入っていて、
**Before(わたしが答えていた)とAfter(夫が答えている)が同じ軸**で並ぶ。

> **メインアカウントには回さない。** 夫婦仲の話として強すぎるので、
> なまけろ子で使い切る。3つとも特徴度は低く(Cだけ★)、紐づきの危険も小さい。

## ✕ 使用禁止:「お茶が置いてあった」「電気が消してあった」

**3回書き直して、3回とも「意味がわからない」と言われた。**
**さらにnoteからも撤去(2026-09-28)。**「愛されてる証拠としては程度が低すぎる」。

| 回 | 形 | 指摘 |
|---|---|---|
| 1 | 断定型 | 「お茶が置いてあった、電気を消してくれてた…これもいみわからん」 |
| 2 | 断定型(書き直し) | 「まじで意味わからん。やらなくていいことわざとやってるから何なのよ」 |
| 3 | **対話型** | 「これいみわからん」 |

### なぜ伝わらないか

**お茶を置く・電気を消すは、愛情の証拠として読まれない。**
やる人はなんとなくやるし、やらない人も別に嫌っているわけではない。
**読む側に「これは愛情のしるし」という前提が無いと通じない。**

出す側は「こんな小さなことにも気持ちが表れている」と言いたいが、
**受け取る側には、ただ物が置いてあるだけに見える。**

### 通じる体験談との違い

| | 題材 | なぜ通じるか |
|---|---|---|
| ○ | 絵本を読む声(表示1,284) | **別居していた人が、今は隣の部屋にいる**。距離が変わったことが分かる |
| ○ | 飲み物を買ってくる | **顔色を見る側だった人が、気にかけられる側になった**。立場が逆転している |
| ✕ | お茶が置いてあった | **前と後で何が変わったのか分からない** |

**「前はこうだった」と対にできない題材は使わない。**
お茶は、別居していたころの対になる姿が描けない。だから使えない。

### noteからも撤去した(2026-09-28)

**Threadsで禁止にしたあとも、有料noteのステップ3に残っていた。**

```
✕ お茶が置いてあったこと。
  先に電気を消してくれてたこと。
  わたしが好きそうなお菓子が、なんとなく買ってあったこと。

○ わたしを見るときの目尻が、いつも下がってること。
  たぶん、冷めてると思ってた時期も、ずっとそうだったんだよ。
```

**判断:「愛されてる証拠としては程度が低すぎる」。**
長文で前振りがあっても、**証拠の格が上がるわけではなかった。**

> **Threadsで禁止にした題材は、noteからも抜く。**
> 媒体が変わっても、題材の弱さは変わらない。
