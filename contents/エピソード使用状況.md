# エピソード使用状況(なまけろ子)

メインアカウントと**同じ人の同じ体験談**を使うため、重複を管理する台帳。
新しく使ったら、ここに追記する。

---

## ★まず結論:エピソードを分けても、たぶんバレる

エピソードより強く紐づくものが先にある。

| 紐づく強さ | 何が | 分けられるか |
|---|---|---|
| **最強** | **「離婚寸前の別居から、新婚よりいい夫婦になった」という経歴の核** | **分けられない**。両方のbioに書くことになる |
| 強 | note・リンク先(同じnoteアカウント、同じ決済) | 分けられるが手間 |
| 強 | 投稿時間帯(両方が同じ7枠で回っていれば同じ人だと分かる) | 分けられる |
| 中 | 文体(「〜だよ〜」「〜なんだよね」) | 分けられるが、ジャンルが違うので自然に分かれる |
| 中 | **特徴的すぎるエピソード**(下の★印) | **分けられる。ここだけ管理すればいい** |
| 弱 | ありふれたエピソード | 分ける必要なし |

**つまり「分ける」のではなく「★印だけ片方に寄せる」が現実解。**

## 主張の矛盾は、気にしなくていい(検討済み)

当初「なまけろ子は引き寄せ、メインは現実的テクニックなので、同一人物と分かったとき
主張が食い違うのでは」と懸念したが、**これは的外れだった。**

- 「話し合おうとすると悪化する」「まず自分の機嫌から」「相手を変えようとしない」は、
  **夫婦仲ジャンルの定番**。逆張りではなく、ほぼどのアカウントも言っている。
- そもそも `knowledge/04_ネタ地図.md` の語彙変換表で、
  **同じ内容を引き寄せの言葉に置き換える**設計にしてある。
  (夫への執着を手放す ←→ 追わない / 自分の機嫌を自分で戻す ←→ まず自分が機嫌よく)
  中身が同じなのだから、構造的に矛盾しにくい。

**論点の事前突き合わせは不要。** 管理するのは下のエピソードだけでいい。

## 運用ルール

1. **★★★の2つ(パンツ・目尻)は、メインでは使わない。** これだけは守る。
2. **★★・★は、表現を変えれば使ってよい。** 同じ場面でも切り取り方を変える。
3. **無印はどちらで使ってもよい。** ありふれているので紐づかない。
4. **未使用の2つは、メインに温存する。**
5. 新しく使ったら、この表に追記する。
6. 論点の矛盾は気にしなくていい(上記)。管理するのはエピソードだけ。
