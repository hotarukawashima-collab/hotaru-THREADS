# knowledge — 新アカウントの設計図

「引き寄せ × 夫婦仲」アカウントの、投稿を作るときの判断基準をまとめた場所です。
`analysis/` の分析が終わったら、ここが本格的に埋まります。

| ファイル | 中身 |
|---|---|
| `01_アカウント設計.md` | 表示名・アイコン・bio・リンク導線 |
| `02_文体ルール.md` | 一人称・語尾・読者の呼び方・絵文字 |
| `03_投稿の型.md` | フックと展開のテンプレート集 |
| `04_ネタ地図.md` | 投稿テーマの一覧と優先順位 |
| `05_NGリスト.md` | 書かないこと・言わないこと |

**現在の状態:** `analysis/accounts/koara/analysis.md` と `analysis/accounts/yukipi/analysis.md`
の分析が完了し、`01`〜`05` すべての `(要分析)` 箇所を実データの根拠つきで埋め終えています。
`generate_posts.py` の `SYSTEM_PROMPT` にも、この内容を反映済みです。

今後投稿を運用しながら、`04_ネタ地図.md` のテーマ優先度や `03_投稿の型.md` の型の反応を
実際のThreads投稿結果で検証し、必要に応じてこのknowledge/を更新していくフェーズに入ります。
