# knowledge — 新アカウントの設計図

「引き寄せ × 夫婦仲」アカウントの、投稿を作るときの判断基準をまとめた場所です。
`analysis/` の分析が終わったら、ここが本格的に埋まります。

| ファイル | 中身 |
|---|---|
| `01_アカウント設計.md` | 表示名・アイコン・bio・リンク導線・運用ルール(頻度/時間帯/連投) |
| `02_文体ルール.md` | 一人称・語尾・読者の呼び方・絵文字 |
| `03_投稿の型.md` | フックと展開のテンプレート集 |
| `04_ネタ地図.md` | 投稿テーマの一覧と優先順位 |
| `05_NGリスト.md` | 書かないこと・言わないこと |
| `07_引き寄せの方針_701.md` | **引き寄せの立場。「もうすぐ叶う」ではなく「もう叶ってる」** |
| `06_パクリ防止.md` | コアラ原文との一致チェック。公開前に `tools/check_similarity.py` を通す |

## ★ 引き寄せの立場は701(2026-09-26)

**`07_引き寄せの方針_701.md` を追加した。**
コアラの型は使い続けるが、**中身の引き寄せ観は701さんの考え方に統一する。**

> **「もうすぐ叶う」ではなく「もう叶ってる」。**

**これで予言型(もうすぐ戻ってくるよ)が `05_NGリスト` と衝突していた問題が解ける。**
未来を約束しなければ、外れようがない。

## 現在の方針:「コアラの完全再現」

このknowledge/は `analysis/accounts/koara/analysis.md`(コアラさん@脱力引き寄せ)の
**完全再現**を設計方針にしている。変えているのは次の3点だけ:

1. **テーマ**(引き寄せ全般 → 夫婦仲)
2. **ターゲット**(`01_アカウント設計.md`のターゲット設定)
3. **アカウント設定の固有名部分**(表示名「なまけろ子」・アイコン「ナマケモノ」・bioの文言・
   キャラ語尾「…💤」)

この3点以外――**型・文字数・投稿頻度・投稿時間・連投の使い方・絵文字の使い方・導線設計**――は、
すべて `analysis/accounts/koara/analysis.md` の実測値をそのまま採用している。
ただし**投稿時間帯だけは例外**で、コアラ analysis.md に時刻(hour)データの記載が無いため
「データ不足」として扱っている(詳細は `01_アカウント設計.md` の運用ルール参照)。
無いデータを埋めるために憶測で決め打ちはしない。

`05_NGリスト.md` は夫婦仲という領域固有の安全ルールであり、上記の「完全再現」の対象外
(唯一の例外)として全項目をそのまま維持している。

## `analysis/accounts/yukipi/analysis.md` について

このファイルは**削除せず参考資料として残す**が、上記の方針変更(コアラの完全再現)により、
**`01`〜`05` の設計には一切使用していない。** ゆきぴー固有の型(尻切れ/クリフハンガー型など)・
語り口(絵文字ゼロ、一人称多用、スレッド前提の2部構成)・運用リズム(バースト型の不規則投稿)は、
過去のバージョンでは移植候補として参照していたが、今後もこのアカウントの設計根拠としては
採用しない。読みたい場合は資料としてそのまま残っているので参照は可能。

## 今後の運用

`generate_posts.py` の `SYSTEM_PROMPT` は、今回の方針変更(コアラ実測値ベースへの統一・
クリフハンガー型の削除・🦥と…💤の役割分担・05_NGリストの反映)に同期済み。
`knowledge/`側を更新した場合は、その都度 `SYSTEM_PROMPT` も揃えること。

今後投稿を運用しながら、`04_ネタ地図.md` のテーマ優先度や `03_投稿の型.md` の型の反応を
実際のThreads投稿結果で検証し、必要に応じてこのknowledge/を更新していくフェーズに入る。
