# 03 投稿の型

`analysis/accounts/koara/analysis.md`(2章フック・3章本文展開・8章ピン留め・10章伸びた投稿)の
**実測値だけ**を根拠にする(`00_README.md`の方針:コアラの完全再現)。

**ゆきぴー由来の型は全て削除した。** 前バージョンにあった「尻切れ(クリフハンガー)導入型」は
`analysis/accounts/yukipi/analysis.md` 2〜3章(件数25〜33件・平均25.5〜32.0)の実測に基づく型で、
コアラの投稿には存在しない。コアラの連投(is_thread)使用率は326件中**6件(1.8%)**のみ
(9章)で、クリフハンガーが前提とする「スレッド1本目を意図的に尻切れで終わらせる」という
運用そのものがコアラには見られない。今回の方針変更(コアラの完全再現)に伴い、この型は
削除し、以後の候補からも外す。

## 大原則:行動を指示しない(全ての型に優先する)

**この原則は全ての型に優先する。型の構造と衝突したら、こちらを取る。**

### 実測

326件を「読者に何かをさせる/やめさせる語を含むもの」と「世界観の断定だけのもの」で
分けると、差が決定的に出る。

| | 件数 | 平均いいね | 中央値 |
|---|---|---|---|
| **行動指示を含む** | 37 | **51.2** | 23 |
| **世界観の断定のみ** | 192 | **138.8** | 62 |

平均で2.7倍、中央値でも2.7倍。さらに**コアラのTOP30に行動指示型は実質1件も無い**
(1件だけ語句が引っかかるkoara_191(♡556)「ふつうは『結果が出たら安心』するけど、
『先に安心したら結果が出る』のが宇宙だよ🌍」も、中身は世界観の断定)。

### 選択肢は2つではなく3つある

`05_NGリスト.md`の「結果保証の断言禁止」を守ろうとすると、
**「結果を保証する」か「行動を指示する」かの二択**に見えてしまう。これが誤り。
コアラが実際に使っているのは**三番目**であり、それが引き寄せ発信の本体。

| | 例 | 可否 |
|---|---|---|
| ✗ 結果を保証する | 「夫は必ず戻ってくるよ」 | `05_NGリスト.md`違反(予言型) |
| ✗ 行動を指示する | 「顔色うかがうの、やめてみよ〜」 | **平均51.2。コーチングであって引き寄せではない** |
| ○ **読者が決める・許可する** | 「今、決めていいんだよ✨」(koara_097 ♡1184)<br>「許可していいんだよ〜✨」(koara_285 ♡698) | 主語は読者。保証でも指示でもない |
| ○ **世界の側を断定する** | 「先に安心したら結果が出るのが宇宙だよ🌍」(koara_191 ♡556)<br>「現実は後からついてくるもの」(koara_126) | 相手の行動に触れない |
| ○ **ただ安心させる** | 「大丈夫〜！予想外の展開でぜんぶ上手くいくよ✨」(koara_312 ♡630)<br>「大丈夫、大丈夫！」(koara_199 ♡626) | 結論を出さない |

### チェック方法

投稿を書いたら、**述語を見る**。

- 述語が「決める・許可する・設定する・選ぶ」→ **○**(主語が読者)
- 述語が「〜なんだよ・〜のが宇宙だよ・〜ものだよ」→ **○**(世界の説明)
- 述語が「大丈夫・〜だよ〜」→ **○**(安心)
- 述語が「〜してみよ・〜やめよう・〜するだけにして」→ **✗ 書き直す**
- 述語の主語が夫・現実・未来で「戻る・変わる・良くなる」→ **✗**(`04_ネタ地図.md`予言型)

## 採用する型

以下7つを、件数・平均いいねの両面で裏付けのある型として採用する。

### 型1:気づき・安心づけ断定型(主力・キャッチオール)

**参考元:** フック2章235件・72.1%・平均110.8 / 本文3章239件・73.3%・平均101.0。
コアラの**投稿の7割超がこの型**で、量産の主力フォーマット。

**構造:**
1. 誰にでも当てはまる一般化した断定文を短く言い切る
2. 場面説明は最小限。理由づけや比喩を軽く添えてもよい

**参考投稿の実例(koara_097、TOP1・♡1184):**
> 人生は思ったより短いよ。「最っっ高に幸せな人生になる!」って今、決めていいんだよ✨

**夫婦仲に置き換えるとき:**
- 「〇〇な人って、実は〇〇なだけだよ」という一般化した気づきの断定文にする
- 理由づけや裏付けを毎回足さない。コアラの気づき断定型(73.3%)も理由づけをほぼ伴わない、
  素の断定文だけの構文(`04_ネタ地図.md`「【最重要】使える断定と、使えない断定」参照)

**テンプレート:**
```
〔一般化した気づき〕、〔断定の一言〕だよ。
```

### 型2:一手集中・手順型(「〜するだけ」)

**参考元:** 本文3章「手順・一手型」平均190.0(6類型中最高)。
フック2章「断言・呼びかけ型」平均209.8(9類型中最高)とも重なる、コアラで最も反応の良い構文。

**構造:**
1. 読者がやりがちな「頑張りすぎ」や「複雑な対処法」を軽く否定する
2. 代わりにやることを1つだけ提示する(「決めるだけ」「〜するだけ」)
3. 理由の説明ではなく、引き寄せの断定を一言添える

**参考投稿の実例(koara_189、♡906):**
> 決めるんだよ〜。自分を極上に甘やかして、好きなことだけしてたら、周りから感謝されて、
> お金がなだれ込む人生、って決めるの。そしたらそうなるだけなんだよ🌿

> **【2026-09-17 訂正】** 前バージョンはここに
> 「『決めるだけ』→ 夫婦仲では『結果を決める』ではなく**『自分の行動を1つ変えるだけ』に
> 言い換える**(結果の保証をしないため)」「例:『話し合おうとするのをやめて、まず自分の
> 機嫌を自分で取るだけにしてみて』」と書いていた。**これが誤りで、型2を丸ごと
> コーチングに変質させていた。**
> 結果保証を避けるための逃げ道を「行動の指示」に取ったのが間違いで、正しい逃げ道は
> 上の**大原則**にある「読者が決める/世界を断定する/ただ安心させる」の3つ。
> 行動指示型はコアラで平均51.2(世界観断定型は138.8)であり、避けるべき側だった。

**夫婦仲に置き換えるとき:**
- **「決めるだけ」は「決めるだけ」のまま使う。** 行動に言い換えない。
  決める主体は読者なので、これは結果保証にならない。
  koara_114(♡575)「信じられなくても、感情がぐちゃぐちゃでも とりあえず『決める』だけだよ」、
  koara_189(♡906)「〜って決めるの。そしたらそうなるだけなんだよ🌿」がそのまま使える形。
- 避けるのは**述語の主語が夫になる文**(「そしたら絶対戻ってくる」)であって、
  「決める」という動詞ではない。ここを取り違えない。
- 補足の一言は、専門家としての裏付けではなく`04_ネタ地図.md`「語彙の変換表」の
  引き寄せの断定にする(主語は読者、動詞は「決める・設定する・許可する」に留める)。

**テンプレート:**
```
〔読者がやりがちな複雑な対処〕、それ実はいらないよ。
やることは1つだけ。〔具体的な行動〕。
〔理由ではなく、引き寄せの断定で一言〕。
```

### 型3:常識破壊・逆張り型(対比を含む)

**参考元:** フック2章「常識破壊・逆張り型」平均186.1(9類型中2位)。「普通は〜だけど実は〜」
というbefore/after・対比の要素もこの型に含む(コアラ analysis.md 3章では独立した「対比型」は
測定されていないため、実測データがあるこの型に統合した)。

**構造:**
1. 世間で言われがちな「常識」や「頑張り方」を提示する
2. 「実は逆」ということを言い切る
3. 引き寄せの断定を一言添える(理由の解説はしない)

**参考投稿の実例(koara_205、♡124):**
> 「現実はフル無視」
> これを本気で言い切って体に落とし込むと、願いは「なんか知らんけど」叶い始めるよ🐨

**参考投稿の実例(koara_172、同一テンプレの再投稿で♡285):**
> しつこいけど言うね。いまがどんな最悪な状態だろうが、関係ないんだよ。
> どうせ幸せになるし、お金もたくさん巡ってくるよ。遠慮なんか捨てて宇宙におまかせしよ🍀

**夫婦仲に置き換えるとき:**
- 「現実を無視していい」は夫婦仲にそのまま使うと無責任になるため避け、
  「今の相手の態度を無視していい」ではなく「今の相手の態度で自分の価値を決めなくていい」
  のように、**現実否定ではなく解釈の否定**に絞って置き換える(`05_NGリスト.md`参照)
- 「絶対」「必ず」の断言部分は使わない(`05_NGリスト.md`)。代わりに
  `04_ネタ地図.md`「語彙の変換表」の引き寄せの断定(「向こうから来る」「証拠を集める」等)で
  説得力を出す。専門家としての権威づけ(相談件数・実務での傾向)はしない

**テンプレート:**
```
〔世間で言われがちな頑張り方〕、それ実は逆だよ。
〔本当はこうという言い切り〕。
〔理由ではなく、引き寄せの断定〕。だから〔行動提案〕。
```

### 型4:一言断言型(短文の言い切り)

**参考元:** 本文3章「一言断言型」44件・13.5%・平均121.4(6類型中2位)。型1(気づき断定型)より
さらに短く、1〜2行で言い切って終わる点が違い。

**構造:**
1. 前置きなしで、1〜2行の短い断定を置く
2. 理由づけや展開はほぼ入れない(型1より潔く短い)

**参考投稿の実例(koara_312、♡630):**
> 大丈夫〜!予想外の展開でぜんぶ上手くいくよ✨

**夫婦仲に置き換えるとき:**
- 「大丈夫」を軸にした一言の安心づけにする。ただし結果保証にならないよう、
  「大丈夫、あなたのせいじゃないよ」のように**責任の所在**に触れる形にすると
  `05_NGリスト.md`と両立しやすい
- 型1より短いぶん、理由づけを足す余地がほぼない。素の一言で完結させる回として使う
  (理由づけをするとしても`04_ネタ地図.md`の引き寄せの断定のみで、専門家としての
  裏付けは足さない)

**テンプレート:**
```
〔一言の呼びかけ〕。〔短い安心づけ〕だよ。
```

### 型5:体験談型(どん底 → 転機 → 今)

**参考元:** フック2章「自己開示・体験談型」5件・1.5%・平均111.6 / 本文3章「体験談型」2件・
0.6%・平均78.5(いずれも件数は少ないが、8章のピン留め投稿koara_325・♡138で最重要ポジションに
置かれている)。

**構造:**
1. 過去のどん底を具体的に列挙する(2〜3つ、抽象語ではなく場面で)
2. 何をやったか・何が変わったかを一言で
3. 今どうなったか
4. 読者への安心づけ(※`05_NGリスト.md`の制約に従う)

**参考投稿の実例(koara_325、プロフィール固定投稿):**
> 数年前は鬱で、仕事もできなくて、貧乏で、恋人もいなかったけど、
> 叶ってる前提で過ごしてたら、本当に全ての願いが叶ったよ🐨
> 今どん底の人も、安心して。絶対大丈夫だから。

**夫婦仲に置き換えるとき:**
- どん底の列挙 → 会話ゼロ / 寝室別 / 離婚届を出された / LINEが既読無視される、など
  具体的な場面に置換する(抽象的な「辛かった」で終わらせない)
- 「叶ってる前提」→「もう仲がいい前提」に言い換える(`04_ネタ地図.md`「語彙の変換表」)。
  専門知識に触れた経緯ではなく、コアラと同じ態度・機嫌の転換として語る
  (実在しない話を「体験談」として書くと信頼を毀損する点は変わらない)
- 安心づけ → 「絶対大丈夫」「必ず戻る」は使わない。「変わる人はたくさん見てきたよ」など
  事実の範囲の言い方に置き換える(`05_NGリスト.md`)
- どん底の描写は運用者自身の状態に限定し、疲れ・脱力の描写には
  `02_文体ルール.md`のキャラ語尾「…💤」を結果ではなく描写の直後に使ってよい

**テンプレート:**
```
〔具体的などん底の場面1〕、〔場面2〕、〔場面3〕だったけど…💤
〔小さな行動や視点の転換〕をしたら、〔今の状態〕になったよ🦥
今つらい人も、〔事実の範囲の安心づけ〕。
```

### 型6:対話型(自分の内なる声との掛け合い)

**参考元:** 本文3章「対話型」5件・1.5%・平均120.4(6類型中3位)。件数は少ないが平均は
気づき断定型(101.0)より高い。

**構造:**
1. 自分の弱気な問いかけ・願望を「」で置く
2. それに対する答え・気づきを「」で返す
3. 短い掛け合いで完結させる

**参考投稿の実例(全3件。同一投稿の再投稿を含む):**
```
koara_078(♡175) / koara_215(♡318)
🐨「月100万円欲しい」
宇宙「100で満足するの?」
🐨「...」
宇宙「で、いくら欲しいわけ?」
🐨「500マン」
宇宙「おっけ。用意するわ」

koara_109(♡29)
🐨「毎日入金あるんだけど」
宇宙「設定したやん」
🐨「忘れてた...」
宇宙「設定したからそうなってるの」
```

> **【2026-09-17 訂正】** 前バージョンは「『宇宙』は世界観がずれるため使えない。
> 自分の弱気な内なる声 vs もう一つの前向きな内なる声に置き換える」としていたが、**これは誤り。**
> ①「宇宙」はコアラの造語ではなく引き寄せの共通語彙であり、通常投稿でも使われている
> (koara_192/255 ♡703/♡626「どうせ叶う、って設定するだけで宇宙はあなたを甘やかしてくれる」、
> koara_127/191 ♡179/♡556「先に安心したら結果が出るのが宇宙だよ🌍」)。
> テーマ・ターゲット・設定以外は変えないという原則からも、外す理由がない。
> ②「わたし」vs「わたし」は自問自答であって対話ではなく、**自分で自分を励ます**構図になる。
> これは「まともな人はそんなことを言わない」という非現実性に直結する。

**この型の要件(実例3件から抽出):**
1. **話者は2人。片方は自分ではない。** 🦥(自分) vs 宇宙。
2. **宇宙は励まさない。** タメ口・ぶっきらぼう・やや呆れ気味。
   「設定したやん」「で、いくら欲しいわけ?」「おっけ。用意するわ」。
   慰め・共感・アドバイスを一切しないことが、この型の面白さの源。
3. **2往復する。** 1往復で終わらせない(4〜6行)。
4. **自分側の1行目は「願望」または「報告」。弱音や絶望ではない。**
5. **オチは宇宙の雑な即答。** 高反応版(♡318)は、宇宙が願いを**上方修正させる**構造。

**夫婦仲に置き換えるとき:**
- 宇宙の結びは「用意するわ」型をそのまま使わない。夫婦仲の場合、
  結果＝配偶者の行動になるため、`04_ネタ地図.md` の**予言型(主語が相手)=使えない断定**
  に該当してしまう。**「そっちにしとこ」など、世界線の選択**(koara_110/227
  「隣の部屋に移動するかんじで世界線を移動」)**に寄せる**と、主語が読者側に残る。
- 件数が少ない型のため、量産の主力にはせず、たまに変化をつける回として使う

**テンプレート:**
```
🦥「〔ささやかな願望〕」
宇宙「〔それで満足するの? と煽る〕」
🦥「…」
宇宙「〔で、どうしたいわけ? と促す〕」
🦥「〔上方修正した本音〕」
宇宙「〔雑に即答〕」
```

### 型7:ピン留め型(実績 + 安心づけ + 導線)

**参考元:** コアラ analysis.md 1章・8章。プロフィール固定の1本目(koara_325、自己開示型、
♡138)+ 返信2本目(koara_326、リンク付き)という2段構成。

**構造:**
1. 1本目:体験談型(型5)をベースにした自己開示+安心づけ。プロフィールを開いた人が最初に読む文
2. 2本目:1本目への返信として、無料配布物へのリンクを添える

**参考投稿の実例(koara_325、ピン留め1本目):**
> 数年前は鬱で、仕事もできなくて、貧乏で、恋人もいなかったけど、
> 叶ってる前提で過ごしてたら、本当に全ての願いが叶ったよ🐨
> 今どん底の人も、安心して。絶対大丈夫だから。

**夫婦仲に置き換えるとき:**
- 1本目は型5(体験談型)のテンプレートをそのまま使う
- 2本目は「具体的な方法はここに書いてるよ」+ リンク、というコアラ koara_326の形式を踏襲
- ピン留めは唯一「積極的にリンクを貼ってよい」場所と位置づける(8章の分析に基づき、
  通常投稿本文にはリンクを貼らない方針との整合を取るため。詳細は`01_アカウント設計.md`の
  リンク導線を参照)
- コアラの連投使用率は326件中6件(1.8%、9章)のみで、その3スレッドのうち1つがこのピン留めに

## 型5(体験談)の鉄則:BeforeとAfterを同じ軸で対にする(2026-09-21)

体験談は「別居してたころは〜/今は〜」の2行。
**この2行が、同じ1つの軸の話になっていないと、ただの無関係な2文になる。**

```
✕  別居してたころは、夫の顔色ばっかり見てたの。      ← 軸:わたしの緊張
   今は買い物のついでに、わたしの好きそうな飲み物を買ってくる ← 軸:夫の気遣い
```

**主語を足しても直らない。** 前半と後半が別の話だから。

```
○  別居してたころは、夫はわたしの好きな飲み物も知らなかったの。
   今は買い物のついでに、わたしの好きそうな飲み物を買ってくる🌿
   → 軸:夫が、わたしの好みを知っているか
```

### 書き方の手順

1. **Afterを先に決める**(実際に起きた具体的な場面)
2. **そのAfterの軸は何かを言う**(誰の、何についての話か)
3. **同じ軸のまま、別居してたころの姿を書く**

飲み物の例なら、軸は「夫が、わたしの好みを知っているか」。
だからBeforeは**「知らなかった」**になる。「顔色を伺ってた」ではない。

### 軸は「人」でなくてもいい

**伸びた1本(表示1,284)は、主語が切り替わっているのに成立している。**

```
別居してたころは、家に帰るのが重かったの。        ← わたし
今はとなりの部屋から、夫が子どもに絵本読んでる声がする。 ← 夫
→ 軸:「家」。どちらも家の中の話
```

**揃えるのは主語ではなく軸。** 人・場所・物、どれでもいいが、1つに絞る。

### 実測

| 体験談 | 軸 | 表示 |
|---|---|---|
| 9/19 絵本 | **家**(重い→声がする) | **1,284** |
| 9/20 家事 | **がんばること**(正解探し→サボる) | 155 |
| 9/21 膝枕 | 笑い(忘れてた→フフ) ※主語が曖昧 | (要確認) |

### チェック手順

1. 前半と後半を読んで、**「これは何についての話?」に一言で答える**
2. **答えが2つ出てきたら、その投稿は壊れている**
3. Afterを残して、Beforeを書き直す

## 型5の追加ルール:Beforeは「思っていたこと」ではなく「していたこと」(2026-09-22)

```

**「知らなかった」「思ってた」は、読む側から見えない。**

## 大原則③「何もするな」と言わない(2026-09-22 追加)

大原則①は「**行動を指示しない**」だった。
これを**「行動を止めさせる」**と取り違えると、noteと矛盾する。

### やってしまった例

```
✕  ふつうは「決めたら何かしなきゃ」と思うけど、
   決めたあとは、何もしないのが正解だよ🌍
   動きたくなったら、それは焦りのほうだからね
```

**「動きたくなったら焦り」は、引き寄せの仕組みそのものを止めている。**

コアラの無料note(原文):

> さすがに、ずっと寝ていたわけではありませんっ🐨
> 今日はこれをやってみようかな〜。なんとなく、こっちへ行ってみようかな〜。
> この人に連絡してみたいな〜。
> **そういうほんのちょっとの行動を亀みたいなペースで続けてたの🐢**

なまけろ子の無料note(`contents/note_はじめまして.md`):

> ## でも、寝てただけじゃないよ
> 「じゃあ寝てれば夫が優しくなるの?」って思われそうだけど、
> さすがにそこまでナマケてないよ🦥
> **このくらいのことを、とんでもなく遅いペースでやってただけ。**

**「なんとなくこっちへ行ってみようかな」は、止めるものではなく、
乗るもの。** それを「焦り」と呼んだら、読んだ人は動けなくなる。

### 正しい言い方

| ✕ 言わない | ○ 言う |
|---|---|
| 何もしないのが正解 | 力を入れなくていい |
| 動きたくなったら焦り | 亀のペースでいい |
| 決めたら待つだけ | **決めるのは行き先だけ。やり方は宇宙が用意する** |

```
○  ふつうは「どうやって仲直りしよう」って考えるけど、
   決めるのは「もう仲がいい」だけでいいんだよ🌍
   やり方は、宇宙が用意してくれるからね
```

**「やり方を考えなくていい」と「動くな」は違う。**
前者は荷物を下ろす話。後者は足を止めさせる話。

### 投稿を出す前の確認

**noteに書いてあることと、逆のことを言っていないか。**
noteは売り物なので、投稿と食い違うと買った人が気づく。
とくに次の3つは、noteで明確に立場を決めてある。

| 論点 | noteの立場 |
|---|---|
| 行動するのか | **ほんの少しだけ、亀のペースでする** |
| がんばるのか | 力は入れない。抜けたときに入ってくる |
| 待つだけか | 行き先だけ決めて、道草しながら進む |

## 繰り返している失敗:指示語・抽象語で中身をぼかす(2026-09-23)

**同じ失敗を4回している。** 投稿でも返信でも出る。

| 出したもの | 何がなかったか |
|---|---|
| 「急に大きい証拠だよ」 | **「大きい」が何のことか書いていない** |
| 「テレビのチャンネルを変えたら」 | 何の話か説明がない比喩 |
| 「もう仲がいい顔して過ごしてる」 | **「仲がいい顔」が見えない** |
| 「ずっとその中にいたんだね」 | **「その中」が何なのか書いていない** |

### 共通する形

**中身の代わりに、指し示す言葉を置いている。**

「その」「それ」「そこ」「この状況」「大きい」「ちゃんとした」
── これらは**中身を言ったことにならない。**

### 直し方

**本人(または読む人)が使う具体的な名詞に置き換える。**

```
✕ ずっとその中にいたんだね      → ○ 9ヶ月もほぼ無視されてたら
✕ 急に大きい証拠だよ            → ○ (その証拠が何かを書く)

## 返信:相手が自分を下げた言葉は拾わない(2026-09-23)

相手の言葉をそのまま返すのが基本だが、**例外がある。**

```
本人   やっと主人の優しさに気がついて、自分の毒妻を認識しました
✕ 返信 やっと気づけたんだね〜✨
```

**嫌味になる。**

| | 意味 |
|---|---|
| **本人が言う**「やっと」 | 安堵。「ようやく肩の荷が下りた」 |
| **こちらが返す**「やっと」 | 評価。「ようやくか。遅かったね」 |

**同じ言葉でも、言う人が変わると意味が裏返る。**

### 拾っていい言葉・いけない言葉

| 種類 | 例 | |
|---|---|---|
| 事実 | 「ほぼ無視されてる」「9ヶ月」 | **○** |
| 到達点 | 「もう思い出すこともない」 | **○** |
| **自己卑下** | 「やっと」「毒妻」「ダメな母親」 | **✕** |

**自己卑下の言葉からは、中にある事実だけを取り出す。**

```
やっと主人の優しさに気がついて  →  優しさ、見えるようになったんだね
```

### 「気づいた」より「見えるようになった」

| | 誰の話になるか |
|---|---|
| 気づいた | **本人の手柄、または怠慢** |
| **見えるようになった** | **条件が変わった** |

**相手の努力や人格の話にしない。** 状態が変わった話にする。
これはこのアカウントの立場(**悪かったのではなく、余裕がなかった**)とも合う。

## 対話型:宇宙の問いは、答えが誰にとっても同じものに限る(2026-09-25)

対話型の骨は「不満 → 宇宙が問う → 🦥が認める → 突き放す」。
**🦥が認める行が成立するのは、問いの答えが1つしかないときだけ。**

```
✕  🦥「夫が何考えてるか分からへん」
   宇宙「分かったら、仲良くなるん?」   ← 読者は「なる」と思っている
   🦥「…ならんかも」                  ← ここで嘘になる
```

**読者が「いや、なるでしょ」と思った瞬間、次の行が読めなくなる。**

### 実測で成立した問い

| 問い | 読者の答え | 結果 |
|---|---|---|
| 気にして、夫帰って来る時間**変わるん?** | 変わらない | **表示630・フォロー16人** |
| 思われ方、**こっちで決められる?** | 決められない | 表示451 |
| 昔のこと考えて、今日の夫は**変わるん?** | 変わらない | (9/25) |

**共通点:「自分の外にあるものを、自分の思考で動かせるか」を聞いている。**
**答えは必ず「動かせない」になる。**

### 使えない問い

| 問い | なぜ |
|---|---|
| 分かったら、仲良くなるん? | **「なる」と思っている人が大半** |
| 謝ってもらったら、全部チャラ? | **人によって割れる** |
| 原因が分かったら、戻るん? | **「戻る」と思っている人が多い** |

### 作るときの手順

1. 不満を1つ置く
2. **「それを〇〇したら、△△は変わるか」の形にする**
3. **△△は、相手の行動や気持ち(自分の外にあるもの)にする**
4. **声に出して答えてみる。割れたら使わない**

## 抽象的な感情語は、頭の中で鳴っている文に置き換える(2026-09-25)

```
✕  夫を憎んでる日があっても、
   気持ちがぐちゃぐちゃでも、

○  「もう無理かも」って思った日も、
   「夫の顔も見たくない」って思った日も、
```

**「憎んでる」「ぐちゃぐちゃ」は、状態の名前。**
**読む人は、自分がそれに当てはまるか判定してから読むことになる。**

**かぎ括弧に入れて、実際に頭の中で鳴っている文をそのまま置くと、
判定がいらなくなって、いきなり自分の話になる。**

### 感情を「気分」と呼ばない

```
✕ ぜんぶ、気分の話やからね
○ ちゃんと感じてるだけやからね
```

**不倫・無視・別居の渦中にいる人にとって、その感情は「気分」ではない。**
**気分と呼んだ時点で、軽く扱われたことになる。**

認めてから切り離す。切り離すために軽く扱わない。

### 「詳しく書く」の中身

長くするときに足すものは、2つしかない。

| 足すもの | 例 |
|---|---|
| **具体(どんな場面か)** | 「もう無理かも」「夫の顔も見たくない」 |
| **仕組み(なぜそうなるのか)** | 「感じることと、決めたことは、別」 |

**形容詞や強調語を足すのは「詳しく」ではない。**

## 1文の中で主語を変えない(2026-09-25)

```
✕ 公園にもカフェにも連れて行くから、安心して預けられる。
         ↑ 主語は夫          ↑ 主語はわたし
```

**「〜から、〜」で2つをつなぐとき、主語が変わると読めなくなる。**
読む人は前の主語を引きずるので、「わたしが連れて行く」と読んでしまう。

```
○ 今は夫が朝から家事も育児もやってる。ふたりで公園にもカフェにも出かけていく。
```

**主語を夫に揃えて、2文に切る。**

### 因果を無理につながない

```
✕ 公園とカフェに行く → だから → 安心して預けられる
```

**本当は「夫が子どもとちゃんと過ごせる → だから安心」なのに、
公園とカフェという例だけでは、そこまで届かない。**

> **結論(安心して預けられる)は、書かないほうが伝わることが多い。**
> **①Before(頼める人がいなかった)と並べれば、読む人が自分でそう受け取る。**

### もらったエピソードは、そのまま使えない

本人が話し言葉で説明してくれた文は、**長い説明の中の一文**として成立している。
**投稿に詰めると、前後の文脈が無いので成立しなくなる。**

**もらった内容は使う。言い回しは作り直す。**

| | 件数 | 平均いいね |

```

```

結論が消えて問いかけだけが残った。**

> **同じ日に同じ主張を2本入れない。** 1本にして、別の角度を探す。
