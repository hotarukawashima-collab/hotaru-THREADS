# 03 投稿の型

`analysis/accounts/*/analysis.md` の「2.フック」「3.投稿の型」「10.伸びた投稿TOP10」から、
**反応が良かった型だけ**を移植した。**5つに絞った。**

以下の型は分析の結果、採用を見送った:

- **リスト型(◯つのコツ)**:コアラ analysis.md 3章で平均30.7(6類型中最下位)、
  ゆきぴー analysis.md 3章でも平均12.1(6類型中下から2番目)と、**両アカウントで一貫して
  最下位クラス**だったため不採用。当初案(`00_README.md`時点の記入予定リスト)には
  入っていたが、データを見た結果、優先度を落とす。
- **問いかけ型**:コアラ analysis.md 2章で平均94.2、ゆきぴー analysis.md 2章で平均4.5(n=2)と、
  一貫した強さが確認できなかったため、独立した型としては採用せず、他の型の締めの一文
  (例:体験談型の最後に軽い問いかけを添える)として部分的に使う。

## 型1:体験談型(どん底 → 転機 → 今)

**参考元:** コアラ analysis.md 2章・8章(自己開示・体験談型、平均111.6〜138) /
ゆきぴー analysis.md 2〜3章(自己開示型、平均41.3〜210 ※n=7と少なく1件の外れ値の影響が大きい点に注意)

**構造:**
1. 過去のどん底を具体的に列挙する(2〜3つ、抽象語ではなく場面で)
2. 何をやったか・何が変わったかを一言で
3. 今どうなったか
4. 読者への安心づけ(※`05_NGリスト.md`の制約に従う)

**参考投稿の実例(コアラ koara_325、プロフィール固定投稿):**
> 数年前は鬱で、仕事もできなくて、貧乏で、恋人もいなかったけど、
> 叶ってる前提で過ごしてたら、本当に全ての願いが叶ったよ🐨
> 今どん底の人も、安心して。絶対大丈夫だから。

**参考投稿の実例(ゆきぴー yukipi_078、TOP1・♡210):**
> 引き寄せのアカウントってたくさんあるけど、間違いなく言えるのは、わたしがいちばん
> わかりやすく発信してる。わたし自身、どん底のときに師匠に出会って、教わったことを
> 片っ端から自分で試してきたの。ここで発信してるのも、その中で本当に効いたやり方だけ。

**夫婦仲に置き換えるとき:**
- どん底の列挙 → 会話ゼロ / 寝室別 / 離婚届を出された / LINEが既読無視される、など
  具体的な場面に置換する(抽象的な「辛かった」で終わらせない)
- 「叶ってる前提」「師匠に出会って」→ 運用者自身の実務経験・専門知識に触れた経緯に言い換える
  (架空の恩師は作らない。実在しない話を「体験談」として書くと信頼を毀損する)
- 安心づけ → 「絶対大丈夫」「必ず戻る」は使わない。「変わる人はたくさん見てきたよ」など
  事実の範囲の言い方に置き換える(`05_NGリスト.md`)

**テンプレート:**
```
〔具体的などん底の場面1〕、〔場面2〕、〔場面3〕だったけど、
〔小さな行動や視点の転換〕をしたら、〔今の状態〕になったよ。
〔専門家としての一言:相談を受けてても多いパターンだと添える〕
今つらい人も、〔事実の範囲の安心づけ〕。
```

## 型2:尻切れ(クリフハンガー)導入型

**参考元:** ゆきぴー analysis.md 2〜3章。フック単体で平均25.5、スレッド1本目としての
構造平均は32.0で、解説・気づき型(16.5)の約2倍。ゆきぴーのデータの中で最も裏付けが
強い型(件数25〜33件と十分なサンプルサイズがある)。

**構造:**
1. スレッド1本目を、文の途中(読点)で意図的に切って投稿する(15〜50字程度)
2. 「実は」「それは、」「でも、」の直前で止め、続きが気になる形にする
3. スレッド2本目で、結論と具体的な行動を回収する

**参考投稿の実例(ゆきぴー yukipi_156/157、1本目♡81・2本目♡79):**
> (1本目)ツインレイと出会った男の人って、
> (2本目)生きる意欲そのものが変わっていくんだよね。魂で繋がる相手との時間って、
> 生命力を与え合うようなものだから、一緒にいるだけで人生への活力が湧いてくる。(以下略)

**夫婦仲に置き換えるとき:**
- 「ツインレイと出会った男の人って、」のようなスピリチュアル固有ワードは使えないため、
  「夫婦仲がうまくいってる人って、実は、」のように、専門家として言える一般化した気づきに置換する
- 2本目の回収は、コアラの「手順・一手型」(型3)と組み合わせて、具体的な行動1つに絞る
- 引きの強さだけで中身が薄いと逆効果(ゆきぴー analysis.md 10章:伸びなかった投稿にも
  クリフハンガー構造はあるが、2本目が抽象論で終わると反応しない、という反例が複数ある)。
  **引きと同じくらい、2本目の具体性が重要。**

**テンプレート:**
```
(1本目/フック)
〔一般化した気づきの書き出し〕、実は、

(2本目/回収)
〔理由の説明〕。だから、〔具体的な行動1つ〕してみて。
〔専門家としての一言〕。
```

## 型3:一手集中・手順型(「〜するだけ」)

**参考元:** コアラ analysis.md 3章。「手順・一手型」が平均190.0で6類型中最高
(全体平均約108の1.8倍)。

**構造:**
1. 読者がやりがちな「頑張りすぎ」や「複雑な対処法」を軽く否定する
2. 代わりにやることを1つだけ提示する(「決めるだけ」「〜するだけ」)
3. なぜそれだけでいいのかを一言で補足する

**参考投稿の実例(コアラ koara_189、♡906):**
> 決めるんだよ〜。自分を極上に甘やかして、好きなことだけしてたら、周りから感謝されて、
> お金がなだれ込む人生、って決めるの。そしたらそうなるだけなんだよ🌿

**夫婦仲に置き換えるとき:**
- 「決めるだけ」→ 夫婦仲では「結果を決める」ではなく「自分の行動を1つ変えるだけ」に言い換える
  (結果の保証をしないため。`05_NGリスト.md`)
- 例:「話し合おうとするのをやめて、まず自分の機嫌を自分で取るだけにしてみて」
- 断定は「〜するだけだよ」という**行動の提案**に留め、「そしたら絶対戻ってくる」という
  **結果の保証**にはしない。行動提案と結果保証を混同しないことが、このアカウントの一線。

**テンプレート:**
```
〔読者がやりがちな複雑な対処〕、それ実はいらないよ。
やることは1つだけ。〔具体的な行動〕。
〔専門家としての一言で理由を補足〕。
```

## 型4:常識破壊・逆張り型(対比を含む)

**参考元:** コアラ analysis.md 2章。「常識破壊・逆張り型」が平均186.1で2番目に高い
(全体平均の約1.7倍)。「普通は〜だけど実は〜」というbefore/after・対比の要素もこの型に含む
(コアラ analysis.md 3章では独立した「対比型」は測定されていないため、実測データがある
この型に統合した)。

**構造:**
1. 世間で言われがちな「常識」や「頑張り方」を提示する
2. 「実は逆」ということを言い切る
3. 専門家としての裏付けを一言添える

**参考投稿の実例(コアラ koara_205、♡124):**
> 「現実はフル無視」
> これを本気で言い切って体に落とし込むと、願いは「なんか知らんけど」叶い始めるよ🐨

**参考投稿の実例(コアラ koara_172、同一テンプレの再投稿で♡285):**
> しつこいけど言うね。いまがどんな最悪な状態だろうが、関係ないんだよ。
> どうせ幸せになるし、お金もたくさん巡ってくるよ。遠慮なんか捨てて宇宙におまかせしよ🍀

**夫婦仲に置き換えるとき:**
- 「現実を無視していい」は夫婦仲にそのまま使うと無責任になるため避け、
  「今の相手の態度を無視していい」ではなく「今の相手の態度で自分の価値を決めなくていい」
  のように、**現実否定ではなく解釈の否定**に絞って置き換える
- 「絶対」「必ず」の断言部分は使わない(`05_NGリスト.md`)。代わりに
  「相談を受けてて分かったこと」という実務の裏付けで説得力を出す

**テンプレート:**
```
〔世間で言われがちな頑張り方〕、それ実は逆だよ。
〔本当はこうという言い切り〕。
相談を受けてても、〔実務での裏付け〕。だから〔行動提案〕。
```

## 型5:ピン留め型(実績 + 安心づけ + 導線)

**参考元:** コアラ analysis.md 1章・8章。プロフィール固定の1本目(koara_325、自己開示型、
♡138)+ 返信2本目(koara_326、リンク付き)という2段構成。ゆきぴー analysis.md 1章でも
同様の2段ピン留め構成が確認されている(1本目=無料配布の告知、2本目=Notionリンク)。

**構造:**
1. 1本目:体験談型(型1)をベースにした自己開示+安心づけ。プロフィールを開いた人が最初に読む文
2. 2本目:1本目への返信として、無料配布物へのリンクを添える

**参考投稿の実例(コアラ koara_325、ピン留め1本目):**
> 数年前は鬱で、仕事もできなくて、貧乏で、恋人もいなかったけど、
> 叶ってる前提で過ごしてたら、本当に全ての願いが叶ったよ🐨
> 今どん底の人も、安心して。絶対大丈夫だから。

**夫婦仲に置き換えるとき:**
- 1本目は型1(体験談型)のテンプレートをそのまま使う
- 2本目は「具体的な方法はここに書いてるよ」+ リンク、というコアラ koara_326の形式を踏襲
- ピン留めは唯一「積極的にリンクを貼ってよい」場所と位置づける(8章の分析に基づき、
  通常投稿本文にはリンクを貼らない方針との整合を取るため)

### 1本目・本文(確定)

コアラのピン留め投稿(koara_325)の構造をそのまま移植したもの。

> 別居してたころは、会話もなくて、笑い方も忘れて、毎日正解ばっかり探してへとへとだったけど、
> 頑張るのをやめたら、するっと戻ってきたよ🦥
> 今しんどい人も、大丈夫。頑張りすぎてるだけだから。

(実際の投稿は改行なしの一続きで投稿する。文字数92字・koara analysis.md 4章の
「71〜100字」帯=平均いいね115.2〈全6帯中2位〉に該当し、反応の良い帯に収まっている)

**構造(確定・6ステップ):**
1. どん底を読点で4つ並べる(「別居してたころは、」「会話もなくて、」「笑い方も忘れて、」
   「毎日正解ばっかり探してへとへとだった」)
2. 「〜だったけど、」で折り返す(コアラ koara_325の「〜いなかったけど、」と同じ、
   どん底→転機をつなぐ蝶番の言葉)
3. 転機を一言で入れる(「頑張るのをやめたら、」)
4. 結果を言い、**直後に🦥を置く**(「するっと戻ってきたよ🦥」)。文末ではなく、
   結果を言い切った直後にすぐ絵文字を置く点が、文末に置きがちな一般的な使い方との違い
5. 読者への安心づけで締める(「今しんどい人も、大丈夫。頑張りすぎてるだけだから。」)
6. 改行を入れず、一続きの文章として投稿する(コアラ koara_325も改行なしの1文)

**方針:どん底の列挙は自分の状態のみにする。**
「会話もなくて」「笑い方も忘れて」はいずれも運用者自身の状態を表す表現であり、
配偶者の言動・態度は一切書かない。`01_アカウント設計.md`の bio 運用ルール2
(「配偶者や具体的な出来事の詳細には踏み込まない」)と同じ原則を、ピン留め本文にも適用している。

**テンプレート(汎用形):**
```
(1本目/ピン留め)
〔運用者自身の状態を表す語句1〕、〔状態2〕、〔状態3〕だったけど、
〔転機を一言〕、〔結果〕🦥
今しんどい人も、大丈夫。〔安心づけの一言〕。

(2本目/返信)
具体的な方法はここに書いてるよ〜
〔リンク〕
```
