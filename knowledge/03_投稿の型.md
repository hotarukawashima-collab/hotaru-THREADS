# 03 投稿の型

`analysis/accounts/*/analysis.md` の「2.フック」「3.投稿の型」「10.伸びた投稿TOP10」から、
**反応が良かった型だけ**をここに移植する。全部の型は要らない。

各型は以下の形式で記録する。

```markdown
## 型名:体験談型(どん底 → 転機 → 今)

**参考元:** コアラ analysis.md / 平均いいね ◯◯(全体平均の◯倍)

**構造:**
1. 過去のどん底を具体的に列挙する(3つ以上並べる)
2. 何を変えたかを一言で
3. 今どうなったか
4. 読者への安心づけ

**参考投稿の実例:**
> 数年前は鬱で、仕事もできなくて、貧乏で、恋人もいなかったけど、
> 叶ってる前提で過ごしてたら、本当に全ての願いが叶ったよ🐨
> 今どん底の人も、安心して。絶対大丈夫だから。

**夫婦仲に置き換えるとき:**
- どん底の列挙 → 会話ゼロ / 寝室別 / 離婚届を出された など、具体的な場面に置換
- 「叶ってる前提」→ 夫婦仲の文脈での言い換えを当てる
- 安心づけ → `05_NGリスト.md` の制約に注意(無条件の「絶対大丈夫」は使わない)

**テンプレート:**
（要分析後に記入）
```

---

## 記入予定の型(分析後に確定)

- [ ] 体験談型
- [ ] 否定・常識破壊型(「〜はやらなくていい」)
- [ ] 対比型(やる人/やらない人、before/after)
- [ ] リスト型(◯つのコツ)
- [ ] 一言断言型(短文のみ)
- [ ] 導線型(無料配布への誘導)
- [ ] ピン留め型(実績 + 安心づけ)

※ 型は**5〜6個に絞る**。多いと運用時に迷って手が止まる。
