# 07 引き寄せの方針 ── 701さんの考え方

**このアカウントの引き寄せの立場は、これに統一する。**
出典: YouTube「701さんが叶った私になる方法」

---

## 1行でいうと

> **「もうすぐ叶う」ではなく「もう叶ってる」。**

---

## 701の骨(原文の要約)

| # | |
|---|---|
| 1 | **望んだ瞬間に、もうなっている。** 現象化を待つ必要がない |
| 2 | **叶っていない私は、叶っている私が作り出したもの。** 別々ではない |
| 3 | **決めたあとに出てくるものは、全部その世界のもの。** 風景も思考も感情も相手も |
| 4 | **ネガティブになっても、叶った私が味わっているだけ。** 条件を外していない |
| 5 | **普通に生活する。** 叶った私が叶った世界で生きているので、不都合はない |

### 原文でいちばん効くところ

> 嫉妬が起きたとしてもそれはそれで**妻になった私の反応**なのです。
> 私が彼の妻になったからこういう現象が起きたのね、と思っておけばいい。

> ネガティブになっても、**叶った私が生み出したものなので安心していい。**

> 妻だけど別居中の私とかにならないか → **なりませんでした。**
> 実家に住んでいたので傍から見れば帰省中の妻。
> **一見何も変化がないように見えても、実際は別物です。**

---

## ★ これで、抱えていた矛盾が解ける

### 問題だったこと

| | 何が起きていたか |
|---|---|
| **予言型** | 「もうすぐ夫婦仲が戻るよ」= **未来の約束。外れる。** `05_NGリスト`違反 |
| **相談者の反応** | 「憎んでしまったから、宇宙にもそう捉えられてしまうね」= **感情を条件にしている** |

### 701での答え

| | これまで | **701** |
|---|---|---|
| **時制** | 未来「もうすぐ戻る」 | **現在「もう仲がいい」** |
| **外れるか** | **外れる** | **外れようがない**(今の話だから) |
| **ネガティブ感情** | いい気分でいないと叶わない、と読まれる | **叶った私が味わっているだけ。条件にならない** |
| **夫の行動** | 夫が変わるのを待つ | **夫が何をしても、仲がいい私の世界のもの** |
| **別居中** | 「まだ叶っていない」状態 | **別居中でも「もう仲がいい」は成立する**(原文にそのまま書いてある) |

> **「もうすぐ戻る」を「もう仲がいい」に変えるだけで、結果の保証の問題が消える。**

**しかもこのアカウントは最初から「うちはもう仲がいい」と決める、と言っている。**
**701と同じ立場だった。予言型のほうが外れていた。**

---

## 書き方のルール

### ✕ 使わない(未来形)

```
✕ もうすぐ、夫婦仲が戻ってくるよ
✕ もうすぐ、夫のほうから話しかけてくるよ
✕ そのうち「あれ、前より話せてるかも」って日が来るよ
```

**「もうすぐ」「〜する日が来る」は、今はまだ叶っていないことを前提にしている。**
**701では、それ自体が「叶ってない私」を強化する。**

### ○ 使う(現在形)

```
○ 「うちは仲がいい」って決めた瞬間から、もう仲がいい世界にいるの
○ 夫が今日どんな顔してても、それは仲がいい世界の夫だよ
○ イラッとした日も、決めたあとに出てきたものだから、その世界のもの
```

### 言い換え表

| 未来形(✕) | 現在形(○) |
|---|---|
| もうすぐ良くなるよ | **もう良くなってる世界にいるよ** |
| いつか戻ってくるよ | **戻ってる世界の、途中の景色だよ** |
| 待ってたら叶うよ | **待つ必要ないよ。もう叶ってる** |
| 夫が変わるよ | **夫が何しても、その世界の夫だよ** |
| ネガティブでも大丈夫 | **ネガティブも、決めたあとに出てきたもの** |

## ネガティブ感情の扱い(いちばん大事)

**これが701の中心で、このアカウントがいちばん必要としていたもの。**

```
相談者「こんなふうに思えてしまって、もう夫婦おしまいだ。
　　　　宇宙にもそう捉えられてしまうね。」
```

**701の答え:**

> **ネガティブになっても、叶った私が生み出したものなので安心していい。**

**「いい気分でいないと叶わない」の逆。**
**決めたあとに出てくるものは、全部その世界のもの。だから何が出てきてもいい。**

> **これを言えるかどうかで、いちばんしんどい人が救われるか、追い詰められるかが決まる。**

## 実務上の注意

| | |
|---|---|
| **「決める」は既存の言葉と同じ** | このアカウントは最初から「うちはもう仲がいい」って決める、と言っている。**言い換えは不要** |
| **体験談とも合う** | 「決めて、がんばるのをやめたら」= 決めたあとの世界の話。そのまま使える |
| **05_NGリストとも合う** | 未来の結果を保証しないので、**そもそも違反しなくなる** |
| **メインアカウントにも効く** | 原文に**「別居中でも成立する」**が直接書いてある |
