# 04 ネタ地図(引き寄せ × 夫婦仲)

## 大前提:このアカウントは「引き寄せアカウント」である

| | 法則 | 引き寄せる対象 |
|---|---|---|
| コアラ | 引き寄せの法則 | **お金** |
| なまけろ子 | 引き寄せの法則 | **夫婦仲** |

**主軸は引き寄せの法則。** 夫婦仲は、引き寄せる対象であって主題ではない。
コアラが「お金の引き寄せ」を語るのと同じ位置に、「夫婦仲の引き寄せ」を置く。

### これは夫婦仲コーチングのアカウントではない

`01_アカウント設計.md`の方針(A案)により、**実務・専門家としての権威づけは出さない。**
コアラは一般人として「脱力引き寄せを見つけた人」の立場だけで語っており、
専門家の看板を一切出していない。これを完全再現する。

- × 「相談を受けてても、いちばん多いパターンだよ」(実務の権威づけ。**使わない**)
- × 「"なんで"は詰問になるから、"どうしたら"に言い換えて」(コミュニケーション指導。**使わない**)
- ○ 「もう仲直りしてる、って決めるだけなんだよ〜🦥」(引き寄せの断定)

運用者の「別居から戻した」経験も、**夫婦仲修復の実績ではなく引き寄せの体験談**として扱う
(`01_アカウント設計.md`のbio運用ルール)。

## 【最重要】使える断定と、使えない断定

コアラの伸びた投稿TOP10(コアラ analysis.md 10章)は、**すべて断定と許可**で構成されている。
平均49.5文字、アドバイスはゼロ。この型がこのアカウントの主力になる。

ただし`05_NGリスト.md`により、**結果を保証する断定だけは使えない。**
両者を分ける線は、その文が**読者の内面**の話か、**現実の予言**かにある。

| 分類 | 使える | コアラの実例(analysis.md 10章) | 夫婦仲への翻訳 |
|---|---|---|---|
| **決める型** | ○ | 「最っっ高に幸せな人生になる!」って今、決めていいんだよ✨(♡1184・1位) | 「うちは仲のいい夫婦」って今、決めていいんだよ✨ |
| **設定する型** | ○ | どうせ叶う、って設定するだけで宇宙はあなたを甘やかしてくれる。(♡703・4位) | どうせ戻る、って設定しておくだけでいいんだよ〜 |
| **許可する型** | ○ | もうそろそろ「お金持ちになる」って許可していいんだよ〜✨(♡698・5位) | もうそろそろ「愛されていい」って許可していいんだよ〜✨ |
| **安心づけ型** | ○ | 大丈夫〜!予想外の展開でぜんぶ上手くいくよ✨(♡630・6位) | ※「大丈夫」の対象を**読者の状態**に限定すれば可。関係の結果に掛けると予言型になる |
| **予言型** | **×** | もうすぐ、一度手放したお金が、増えて戻ってくるよ〜✨(♡868・3位) | 「もうすぐ夫の気持ちが戻ってくるよ」は**使わない**(`05_NGリスト.md`) |
| **言霊型** | **×** | 【言霊】あなたの財布はまもなく、福であふれてパツパツになるよ。(♡597・10位) | 未来の状態を断言する型のため**使わない** |

**判定のしかた:** 主語が「あなた(読者)」で、動詞が「決める・設定する・許可する・思う」なら使える。
主語が「相手・現実・未来」で「戻ってくる・変わる・良くなる」なら使えない。

> **注意:** この線引きにより、コアラのTOP10のうち2件(3位・10位)の型が落ちる。
> 反応は落ちる可能性があるが、`05_NGリスト.md`は分析結果に優先する(例外B)。

## 語彙の変換表

コアラの引き寄せ語彙を、夫婦仲の文脈に一対一で置き換える。**新しい概念は足さない。**

| コアラ(お金) | なまけろ子(夫婦仲) |
|---|---|
| 叶ってる前提で過ごす | **もう仲がいい前提**で過ごす |
| どうせ叶う | **どうせ戻る** |
| 執着を手放す | **夫への執着を手放す(=追わない)** |
| 潜在意識に覚えさせる | 「仲のいい夫婦」を**体に覚えさせる** |
| チャンネルを合わせる | 「うちは冷めてる」から「うちは仲がいい」へ**チャンネルを変える** |
| 宇宙からのサイン | **小さなサイン**(今日は目が合った、お茶を淹れてくれた) |
| 叶った証拠を集める | **もう仲がいい証拠**を集める |
| お金持ちごっこ | **もう仲良し夫婦ごっこ** |
| 波動・エネルギー | **家の空気・機嫌の伝染** |
| いい気分でいる | **自分の機嫌を自分で戻す** |
| 受け取る許可を出す | **愛される許可を出す** |
| 財布・口座残高 | **会話の量・空気の重さ** |

## ネタの作り方(基本フォーマット)

コアラ analysis.md 10章の「上位に共通していて下位にないもの」3点を踏襲する。

1. **普遍性。** 特定の状況説明を必要としない、誰にでも当てはまる断定にする。
   (TOP10はすべてこれ。逆に発信者側の事情を語った投稿は最下位層に沈んでいる)
2. **短さ。** TOP10の平均は**49.5文字**。伸びなかった10件は69.0文字で1.4倍長い。
3. **箇条書きを使わない。** TOP10でリスト形式は**0件**。リスト型は全体でも最低(平均30.7)。

```
```

```
```
もうそろそろ、愛されていいって許可を出していいんだよ✨
```
```

```

```

## テーマ一覧

`03_投稿の型.md`の6型と組み合わせて使う。優先度は平均いいねの高さで決める。

| テーマ | 中身 | 根拠(コアラ analysis.md) | 優先度 |
|---|---|---|---|
| **決める・設定する** | 「うちは仲がいい」と先に決める | 10章TOP10のうち3件(1位♡1184、2位♡906、8位♡622)がこの型 | **最高** |
| **許可を出す** | 愛されていい、幸せでいい、と自分に許可する | 10章5位(♡698) | **高** |
| **執着を手放す** | 追いかけない、期待を下ろす | 3章:手順・一手型 平均190.0(全型1位) | **高** |
| **証拠を集める** | もう仲がいい証拠を数える | 2章:気づき・安心づけ断定型 平均110.8 | 中 |
| **前提を変える** | 「どうせ分かってくれない」の前提を降ろす | 2章:常識破壊・逆張り型 平均186.1 | **高** |
| **自分の機嫌** | 家の空気は自分の機嫌から | データ不足(コアラに直接対応するテーマなし) | 中 |
| **小さなサイン** | 目が合った、お茶を淹れてくれた | データ不足 | 低 |

> **テーマ細分化についての注記:** コアラのトピックタグは「引き寄せ」がほぼ全て
> (7章、69.9%・平均130.7)で、サブテーマへの細分化はされていない。
> 上記のテーマ分けはコアラのタグ分類ではなく、10章のTOP10本文と2〜3章の型から
> 逆算したものである。テーマ単体の反応データがコアラに存在しないものは「データ不足」と明記した。

## 扱わないもの

- **コミュニケーションの技術指導**(言い方、伝え方、聞き方)。コアラは一切やっていない
- **夫婦関係の仕組みの解説**(なぜすれ違うか、など)。同上
- **実務・相談事例の引用**。A案により使わない
- **箇条書きのtips**。コアラで最も反応が低い型(3章・平均30.7、10章でもTOP10に0件)
- **発信者側の事情**(note書いてます、買ってくれてありがとう)。コアラの最下位層がこれ(10章)
- モラハラ・DV・離婚係争中(`01_アカウント設計.md`ターゲット外・`05_NGリスト.md`)
