# 08 引き寄せの方針 ── 愛に浸る

`07_引き寄せの方針_701.md` と**セットで使う。**
出典: YouTube「愛に浸る」(`reference/愛に浸る.txt`)

---

## 1行でいうと

> **状況を変えるために愛を送るのではなく、ただただ愛を送る。**

---

## 骨(原文の要約)

| # | |
|---|---|
| 1 | **状況を変えるためではない。** ただ好きという気持ちに浸る。それ自体が心地いい |
| 2 | **好きな人がいるなら、それは誇っていい。** その人を好きなだけで、すでに幸せ |
| 3 | **相手をコントロールしようとしない。** 自分の「好き」だけを感じる |
| 4 | **条件付けを外す。**「連絡くれない彼」ではなく「ただの彼」を見る |
| 5 | **諦められないなら、無理に諦めなくていい。** 認めたうえで、今を楽しむ |
| 6 | **ネガティブより、愛のほうが強い。** それに気づくとネガティブは消える |

### 原文でいちばん効くところ

> **イラつくても好き、許せない、絶対許せない、でもやっぱり好き。**
> そんなこんなしてるうちに、自分がいかに相手のことを思ってるか見えてくる。
> **恨みや憎しみよりも、私のあなたへの愛のほうが強いよね。**
> そうすると**ネガティブな感情はすっと消えちゃう。**

> 連絡をしない彼、なんて**条件付け捨てて、ただの彼を愛して。**
> すると最後に残るのは、**本当の気持ち。**

> 状況を変えるために愛を送るのではなく、**ただただ愛を送り続ける**と、
> なんか状況変わってきます。**この2つのニュアンスの違いは伝えにくいけど。**

---

## ★ 701との関係 ── 役割が違う

| | **701** | **愛に浸る** |
|---|---|---|
| **何をするか** | **決める**(もう仲がいい) | **感じる**(好きに浸る) |
| **ネガティブ感情** | **叶った私が味わっているもの。だからOK** | **愛のほうが強い。だから消える** |
| **相手** | 何をしても、その世界の相手 | **コントロールしない。条件付けを外す** |
| **向いている人** | 考えすぎる人・理屈が要る人 | **感情がぐちゃぐちゃな人** |

**2つで、ネガティブ感情の扱いを両側から挟んでいる。**

```
701     ネガティブでもいい。叶った私が味わってるだけやから
愛に浸る 憎しみより、好きのほうが強い。だから憎しみは消える
```

> **どちらも「いい気分でいないと叶わない」を否定している。**
> **このアカウントがいちばん必要としていたもの。**

---

## ★ この方針が、相談者への答えになる

**9ヶ月・不倫の相談者の言葉:**

> **失いたくないのに、憎しみが募ってしまう。**
> こんなにも粗末に扱われる事に怒りと悲しみと苦しさと憎しみと…
> **大切にされたかった。**

**「〜のに」で、本人は自分を矛盾していると思っている。**

**愛に浸るの答え:**

> 憎しみより、**失いたくないほうが強い。**
> **順番が逆。** 憎しみがあるのに好き、ではなく、
> **好きだから憎い。**

**これは矛盾ではない。** 憎しみは、愛があるところにしか生まれない。

## ⚠ 夫婦仲で使うときの注意

**このまま持ってくると、`05_NGリスト` の一線を越える。**

| 原文 | 夫婦仲でそのまま言うと |
|---|---|
| 条件付けを外して、ただの彼を愛して | **「何をされても愛しなさい」に読める。** DV・モラハラで危険 |
| 諦めなくていい | **「離れてはいけない」に読める** |

### 線の引き方

| ○ 言っていい | ✕ 言わない |
|---|---|
| **好きな気持ちがあること自体は、責めなくていい** | 何をされても好きでいなさい |
| **憎しみより好きのほうが強いなら、それが本当** | 憎しみは消さなければいけない |
| **好きでいるのは、状況を変えるためじゃない** | 好きでいれば夫は変わる |
| **諦められないなら、無理に諦めなくていい** | 諦めてはいけない |

> **「愛せ」と言わない。「もう愛してるよね」と言う。**
> **指示ではなく、確認。** これなら、離れる選択をした人も否定しない。

## 使える言い方

```
○ 夫にイラッとする日もあるやんな。
  でも「もうどうでもいい」にはならへんやろ?
  そっちのほうが、たぶん本当やで🌿

○ 好きな人がおるだけで、もう幸せやねんで。
  仲がいいかどうかは、その次の話🦥

○ 憎らしいのも、大事やからやんな。
  どうでもよかったら、憎らしくもならへんよ🌿

○ 好きでいるのは、夫を変えるためちゃうよ。
  そのほうが、こっちが楽なだけ✨
```

### ✕ 使わない

```
✕ 何があっても愛し続けて
✕ 許してあげて
✕ 好きでいれば、夫は戻ってくるよ   ← 結果の保証。07の未来形禁止にも触れる
```
