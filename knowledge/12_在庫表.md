## ★ 投稿を作るときの順番

```
1. この在庫表を見る          ← 未使用・手薄なものから引く
2. 型の比率を確認する        ← 型4に寄りすぎていないか
3. 枠ごとの直近10本を見る    ← 同じ形が続いていないか
4. 昨日の結果を見る          ← ここで初めて見る
5. 3つのチェックを通す       ← 宿題 / 否定の相手 / 良い絵
6. inspect.py と check_similarity.py
```

**4を1番目にやると、1日8点のサンプルで局所最適化する。**
