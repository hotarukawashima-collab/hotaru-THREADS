# 09 ネタ在庫 ── 701の原文から、まだ使っていないもの

**2026-09-30 作成。マンネリの原因は、ここを掘っていなかったこと。**

コアラから取っているのは**型**。中身は701から**「決める」1つだけ**を繰り返し使っていた。

```
コアラ      31本で、入口が31通り
なまけろ子  49本中31本が「決め」(63%)
```

**原文 `reference/701_叶った私になる方法.txt` には、まだ使っていない骨が20以上ある。**
以下、**夫婦仲に翻訳した形**で並べる。上から強い順ではなく、原文の順。

## ★★★ 特に強いもの(先に使う)

### 1. 別居していても、決めた世界の中にいる

> **原文:**「妻だけど別居中の私とかにならないか」
> →「なりませんでした。実家に住んでいたので、傍から見れば帰省中の妻でしょうか。
> とはいえ妻になった私になった時から、妻になった私の世界になってるので、
> **未婚の私の実家&家族から、妻になった私の実家&家族に変わっちゃってるんですよね。**
> **一見何も変化がないように見えても、実際は別物です。**」

**701本人が、別居に相当する状況を語っている。** このアカウントの運用者の経歴と重なる。

```
夫婦仲に翻訳
  家はそのままでも、あなたはもう「仲がいい夫婦の家」におるんよ。
  外から見て何も変わってへんだけ。
```

> **注意:** 読者を別居中と想定しない(`01_アカウント設計.md` ターゲット)。
> **「外から見て変わらなくても、別物」**という一般形で使う。

### 2. 仲がいい夫婦にも、会話がない日はある

> **原文:**「恋人ができるが叶った世界でも、24時間365日デートするわけでも、
> 連絡が来るわけでもありません。**ない時だってある。何も問題は起きてない**」

**これは読者がいちばん折れる場所への答え。**「決めたのに今日も会話がない」に直接効く。

```
夫婦仲に翻訳
  仲のええ夫婦でも、喋らん日はあるよ。
  今日喋らんかったのは、なんも問題ちゃう。
```

### 3. 不安になるたび、何度でも戻っていい

> **原文:**「不安になるたびにこれを繰り返しました。**いつの間にか叶った私視点が
> デフォルトになり、不安は起きなくなりました**」

**1回で決めきらなくていい、という許し。**「決めたのにブレる」への答え。

```
夫婦仲に翻訳
  ブレてもええねん。ブレるたびに戻ったらええだけ。
  そのうち、戻るのがふつうになるよ。
```

### 4. 「たまたま」

> **原文:**「**不安や心配が起きたのは、たまたまです。**
> 気に入らない現象が起きたとしても、気にしなくていいんですよ」

**「たまたま」という語が、いちばん軽い。** なまけろ子の語彙に無い。

```
夫婦仲に翻訳
  今日きつかったんは、たまたまやで。
```

### 5. 探さないほうがいい

> **原文:**「**見つけようとすると、見つける世界になっちゃうんで、探さない方がいいですよ**」

**「夫が変わったか確かめる」をやめる理由。**
⚠ ただし note のステップ3「もう仲がいい証拠を集めよう」と緊張関係にある
(`07_引き寄せの方針_701.md` に既記)。**投稿で使うときは「悪いほうを探さない」に限定する。**

## ★★ 使えるもの

### 6. 気づくだけでいい

> **原文:**「**叶っていない私を維持していたことに気づく。これだけです。**
> これに気づいた瞬間、私と一体化していた叶っていない私が剥がれます」

```
夫婦仲に翻訳
  「うちは仲が悪い」って思ってたことに気づくだけでええねん。
  そこからやることは、なんもない。
```

### 7. 望んだ瞬間に、もうなっている

> **原文:**「**皆さんの望みはすでに叶っているんです。望んだ瞬間になっています**」

```
夫婦仲に翻訳
  仲良くなりたいって思った瞬間に、もうそっち側におるんよ。
```

### 8. 身のまわり全部が、その世界のもの

> **原文:**「**空が青いのも、オリンピックがロンドンで開催されているのも、
> 叶っている世界だからです**」
> 「考えること、見聞きすること、食べるもの、飲み物、全てが叶ってる世界のものです」

```
夫婦仲に翻訳
  今日のごはんも、洗濯物も、ぜんぶ仲のええ夫婦の家のもんやで。
```

### 9. 悪いほうも、自分が作っている

> **原文:**「**叶っていない私を作ってるのも、叶えている私。**
> ネガティブになる自分を作っているのも叶えている私。全部叶えている私が出したものです」

```
夫婦仲に翻訳
  「もうあかん」って思うのも、決めたあなたが出してるもんやで。
```

### 10. 現象の読み替え

> **原文:** 好きな人のブログに他の女性との2ショット写真 →
> 「**私に報告するために書いてくれたのね。今度Bさんに会ったらお礼言わないと**」
> と自然に思えた。嫉妬は起きなかった

```
夫婦仲に翻訳

```

### 11. 理由を考えない

> **原文:**「起きた理由を考えたい場合、**なっちゃったもんは仕方ない、で片付けます**」

```

  「まあ、そうなったんやな」で終わり。
```

### 12. 日常の小さいネガティブもOK

> **原文:**「ネガティブなことを考えたとしても、**ゴミ出しめんどくさいわー**とか、
> 妻な私が考えたことなので問題はありません」

### 13. いくつ決めてもいい

## 使い方のルール

1. **1つのネタは、1回しか使わない。** 使ったらこのファイルに使用日を書く
2. **入口を毎日変える。** 同じ骨でも、入口の言葉を変える
3. **「決める」を核にしない。** コアラは31本中3本(10%)
4. **原文の語り手は701(片思い→結婚)。** 夫婦に合わない部分は翻訳するか捨てる
   (`08_引き寄せの方針_愛に浸る.md` の「原文の語り手が誰かを見る」と同じ)
