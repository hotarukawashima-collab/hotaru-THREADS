# 06 パクリ防止(コアラ原文との一致チェック)

## なぜ要るか

このアカウントは「コアラの完全再現」が方針なので、**構成・型・字数・絵文字の比率までは
そっくりでいい。** ただし**文そのものが一致するのは別問題**で、公開物としてまずい。

実際に起きたこと(2026-09-18):
note販売ページが、コアラの「7日間ワーク」無料部分と**27箇所・合計557字・最長51字**
一致していた(本文の約13%)。見出しに至っては「まずは、ゆる〜い3つのお約束」など
複数が完全一致していた。構造分析をもとに書いたため、1文ずつ対応してしまっていた。

## 線引き

| | 真似していい | 真似してはいけない |
|---|---|---|
| 構成・ブロックの並び | ○ | |
| 型(決める型・許可型など) | ○ | |
| 字数・改行・絵文字の比率 | ○ | |
| 投稿頻度・時間帯 | ○ | |
| **文・言い回し** | | **✕** |
| **見出しの文言** | | **✕** |

## チェックのしかた

```
python3 tools/check_similarity.py <自分のファイル> [しきい値]
```

- 参照元は `reference/koara/*.txt`(コアラのPDFから抽出したテキスト3本)
- しきい値は既定12文字。何文字以上の連続一致を報告するか
- **20字以上の一致が1つでもある、または本文の3%超が一致 → 要修正**
- 12字前後の一致は、一般的な日本語表現(「アファメーションもした。」等)なので許容

## 公開前に必ず通すファイル

- `contents/note用_無料部分.txt`(販売ページ)
- `contents/note用_有料部分.txt`(有料本文)
- `contents/note_はじめまして.md`(無料note)

**Threads投稿は対象外。** 1投稿50字前後で、12字の一致は偶然起こりうるため。
ただし型をなぞるとき、コアラの投稿文をそのまま翻訳しないこと
(例: koara_285「お金持ちになる」→「愛されていい」は語の差し替えなので可。
文全体を写すのは不可)。

## 現状(2026-09-18時点)

| ファイル | 12字以上の一致 | 判定 |
|---|---|---|
| note用_有料部分.txt | 0箇所 | OK |
| note_はじめまして.md | 0箇所 | OK |
| note用_無料部分.txt | 3箇所36字(0.9%)・最長12字 | 許容範囲 |

## 直し方(実際にやったこと)

**構成・内容・字数は変えず、言い回しだけを入れ替える。**

- 見出しは全部つけ直す(いちばん目立つので最優先)
- コアラ固有の言い回し(「腹を括って」「なんだか不思議だよね〜」「案外こんな感じ」)を捨てる
- キャラクターの言葉に置き換える(「ずるずる進んで」「そこまでナマケてないよ」
  「どうせ良くなるっしょ〜」)
- 罫線などの装飾記号も変える(コアラは `❁ . ｡ .:*:. ｡ . ✽` を使っている)
