# 06 パクリ防止(コアラ原文との一致チェック)

## なぜ要るか

このアカウントは「コアラの完全再現」が方針なので、**構成・型・字数・絵文字の比率までは
そっくりでいい。** ただし**文そのものが一致するのは別問題**で、公開物としてまずい。

実際に起きたこと(2026-09-18):
note販売ページが、コアラの「7日間ワーク」無料部分と**27箇所・合計557字・最長51字**
一致していた(本文の約13%)。見出しに至っては「まずは、ゆる〜い3つのお約束」など
複数が完全一致していた。構造分析をもとに書いたため、1文ずつ対応してしまっていた。

## 線引き

| | 真似していい | 真似してはいけない |
|---|---|---|
| 構成・ブロックの並び | ○ | |
| 型(決める型・許可型など) | ○ | |
| 字数・改行・絵文字の比率 | ○ | |
| 投稿頻度・時間帯 | ○ | |
| **文・言い回し** | | **✕** |
| **見出しの文言** | | **✕** |

## チェックのしかた

```
python3 tools/check_similarity.py <自分のファイル> [しきい値]
```

- 参照元は `reference/koara/*.txt`(コアラのPDFから抽出したテキスト3本)
- しきい値は既定12文字。何文字以上の連続一致を報告するか
- **20字以上の一致が1つでもある、または本文の3%超が一致 → 要修正**
- 12字前後の一致は、一般的な日本語表現(「アファメーションもした。」等)なので許容

## 公開前に必ず通すファイル

**【2026-10-10 更新】版が増えたので、どれを指すかを書き分けた。**

- `contents/note用_無料部分.txt`
  **＝ v4（2026-10-10作成・リポジトリの正本）。note.comの公開本文とは別物**
- `contents/note用_無料部分_貼り付け用.txt`
  **＝ v4からMarkdown記法を外した公開用。本文はv4と同じ**
- `contents/note用_有料部分.txt`
  **＝ 最新版の有料部分（2026-10-09取得のPDFに準拠）**
- `contents/note_はじめまして.md`(無料note)

> **★ `contents/_旧型_2026-10/` は検査しない。** 販売していない旧型なので対象外。
> **どの版がどれかは `contents/note_最新版_README.md` の冒頭の表を見る。**

**Threads投稿は対象外。** 1投稿50字前後で、12字の一致は偶然起こりうるため。
ただし型をなぞるとき、コアラの投稿文をそのまま翻訳しないこと
(例: koara_285「お金持ちになる」→「愛されていい」は語の差し替えなので可。
文全体を写すのは不可)。

## ★★ 伏せ字は、コアラの型ではなく自分の本文から作る(2026-10-02)

**無料部分の伏せ字目次を、コアラの7日間に1対1で合わせて作った。**
**ところが、公開版の本文はコアラの構成から離れていたので、噛み合っていなかった。**

| 作った伏せ字 | 実際の本文 | |
|---|---|---|
| 3つの〇〇〇〇**ゲーム**🎮 | 寝る前のイメージング | **✕** |
| 〇〇〇〇**証拠を集めよう**✨ | 今日の幸せ、なんかあった? | **✕** |
| 夫が優しくなる〇〇〇〇**ごっこ** | 決めたあとは、いつもの暮らしでいい | **✕** |
| 小さな**サイン**を拾って〇秒の〇〇 | 「これ、話したい」が出てきたら | **✕** |

**7つ中4つが完全に別物。** 合っていたのは1つだけ。

### なぜ起きたか

**「コアラの型に合わせる」を、目次にまで適用してしまった。**

```
構成・ブロックの並び   型を真似ていい
見出し・文言           真似てはいけない(06の線引き)
目次の中身             ★本文の要約なので、真似る対象ですらない
```

**伏せ字は、中身を隠すもの。中身を変えるものではない。**

> **伏せ字は、本文から作る。** 参照元は自分の本文であって、コアラではない。
> **隠す言葉は、本文に実在する語にする。** 〇の数も、その語の字数に合わせる。

### 直した版の作り方

| ステップ | 隠した語 | 字数 |
|---|---|---|
| 1 | うちは仲がいい | 7 |
| 2 | 妄想 | 2 |
| 3 | 夫と関係ないこと | 8 |
| 4 | いっぱい話しかける | 9 |
| 5 | 条件 | 2 |
| 6 | お、きた | 4 |
| 7 | それでも叶う | 6 |

**全部、本文に実在する言葉。** 読んだ人が「あ、これか」と見つけられる。

## ★ 同じ失敗を2回やった(2026-10-01)

**構造分析をもとに書くと、1文ずつ対応してしまう。** 9/18とまったく同じ。

```
1回目 2026-09-18  note販売ページ      27箇所・557字(13%)
2回目 2026-10-01  無料部分の追加ブロック  44箇所・873字(23.9%)
```

**2回目のほうがひどい。** 構造分析が精密になったぶん、文の対応も細かくなった。

### 書く手順を変える

| ✕ これまで | ○ これから |
|---|---|
| 構造分析を見ながら書く | **構造分析で「何を書くか」だけ決めて、分析を閉じる** |
| | **原文も分析も見ずに、自分の言葉で書く** |
| | 書き終わってから `check_similarity.py` を通す |

**原文が目に入っている状態で書くと、必ず引きずられる。**

### 直すときのコツ(今回やったこと)

**語尾と接続詞から変える。** 内容は変えなくていい。

| コアラ | なまけろ子 |
|---|---|
| だからもう、これ以上がんばらなくて大丈夫だよ | もう、これ以上ふんばらんでええよ |
| 力を入れない。がんばらない。なのに、 | 力を入れへん。ふんばらへん。それでも |
| 7日でできるようにぎゅぎゅっ!とまとめた | 7日ぶんに畳んで入れといた |
| 現実が大きく動き始める前に、必ず先に変わるものがあるの | 夫が動くより先に、変わるもんがあるんよ |

**関西弁にするだけで、かなり離れる。** 標準語のまま直そうとすると戻ってくる。

> **★★ 連続一致が無いことを、独自性の保証として扱わない。**
>
> このツールが見ているのは**「12字以上つながって同じか」だけ**。
> 語を差し替えた模倣、語順を変えた模倣、構成の踏襲は**検出できない**。
> 実際、2026-10-10の分析では、**10/1公開版がコアラの無料部分と同じ順番で**
> **14箇所並んでいた**(語を差し替えた文と見出し)。
> 12字では4箇所しか出ていなかったのに、である。
>
> **数値が通っても、前後を人が読んで判断する。**

## 直し方(実際にやったこと)

**構成・内容・字数は変えず、言い回しだけを入れ替える。**

- 見出しは全部つけ直す(いちばん目立つので最優先)
- コアラ固有の言い回し(「腹を括って」「なんだか不思議だよね〜」「案外こんな感じ」)を捨てる
- キャラクターの言葉に置き換える(「ずるずる進んで」「そこまでナマケてないよ」
  「どうせ良くなるっしょ〜」)
- 罫線などの装飾記号も変える(コアラは `❁ . ｡ .:*:. ｡ . ✽` を使っている)
