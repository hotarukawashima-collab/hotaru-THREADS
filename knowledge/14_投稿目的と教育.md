## ★★★ 判定のルール ── ここがこのファイルの本体

**印(しるし)で機械的に割らない。本文がその投稿で何をしようとしているかで見る。**

| # | 禁止 |
|---|---|
| **1** | **フォローCTAがある投稿だけを集客と判定しない** |
| **2** | **URLがある投稿だけを収益と判定しない** |
| **3** | **CTAがない投稿を自動的にファン化と判定しない** |
| **4** | **型番号だけで投稿目的を確定しない** |
| **5** | **判定が難しい投稿は「要確認」として残す** |

### 「判定保留(要確認)」の扱い

> **★ 投稿目的は「集客・ファン化・収益」の3つだけ。**
> **判定保留は4番目の投稿目的ではない。分類作業のあいだ、保留しておくための置き場。**

```
3つのどれかに無理に割り当てない
判定が難しいものは、判定保留に置いて先に進む
      ↓
集計上は   集客 + ファン化 + 収益 + 判定保留 = 全本数
```

| | |
|---|---|
| 判定保留に置くもの | 目的が2つ以上にまたがる / 本文だけでは目的が読み取れない / 判定が人によって割れる |
| 判定保留から動かすとき | **運用者が判断したときだけ。** こちらの推測で埋めない |
| 判定保留の本数 | **減らすことを目的にしない。** 無理に割ると、分類そのものが信用できなくなる |
| **書き方** | **投稿目的を並べて書くときは、3つだけ書く。判定保留を目的の一覧に混ぜない** |

### ★★ 判定の細則(2026-10-10 追記 ── 20本の分類テストから)

**2026-10-06・10-09 の20本を分類して、基準の穴が出たところ。**
**投稿目的は「集客 / ファン化 / 収益」の3つだけ。判定保留は、そのどれでもなく別扱い。**

| # | 細則 |
|---|---|
| **1** | **型11は、型番号やフォローCTAだけで集客と決めない。**<br>★**ただし 2026-10-06 10:00 と 2026-10-09 10:00 の2本は、本文の狙いから「集客」と判断する**(2026-10-10 運用者の判断) |
| **2** | **型9a・型9bの連投は、セットで全文を読んで目的を判定する。**<br>**投稿数は、それぞれ1本として記録する。** 2本を1件にまとめない |
| **3** | **投稿前の目的と、投稿後の成果は区別する。**<br>表示数・♡・反応・フォローは**成果**。目的の判定に混ぜない。<br>**「伸びたから集客だった」「伸びなかったからファン化だった」と後から読み替えない** |
| **4** | **投稿時間帯だけで目的を決めない。**<br>枠の役目(例:23:00は寝る前に安心して終われること)は、**枠の設計の話であって目的の判定根拠ではない** |
| **5** | **本人の実体験が含まれていても、自動的にファン化へ変更しない。**<br>実体験は信頼の材料だが、**その投稿が何をしようとしているかは別に見る** |
| **6** | **教育は、主な教育と補助的な教育を区別する。** → 2章「主な教育 / 補助的な教育」 |
| **7** | **再投稿は、元本文の目的を基本的に引き継ぐ。**<br>**再投稿であることは運用情報として別に扱う**(→ `11_再投稿.md`)。目的の欄には出さない |

```
細則1〜5・7  目的の判定に関するもの
細則6       教育の記録に関するもの
```

**細則で判定できないものは、判定保留に置く。** 無理に3つへ割らない。

## 主な教育 / 補助的な教育(2026-10-10 追記)

**1本に複数の教育が入る。全部を同じ重さで数えると、その投稿が何を伝えようとしたのか分からなくなる。**

| | |
|---|---|
| **主な教育** | **その投稿が、いちばん伝えようとしているもの。**<br>落ちと本文の大半が、そこに向いている |
| **補助的な教育** | **入ってはいるが、本体ではないもの。**<br>1行だけ / 末尾の付け足し / 例示の材料として出てくるもの |

**書き方**

```
主 手段・目的  /  補 信頼        主と補を分けて書く
集計も、主と補を分けて数える      足して1本にまとめない
```

> **★ 名称・順番・定義文は、2章の表のまま。** 主/補は「重さ」の区別で、6つの教育の定義は変えない。

### 判定例 ── 2026-10-09 12:00(細則5とセットで読む)

```
決めてまうねん。
夫からのLINEがどうでもええ話ばっかりで、
夜は同じ部屋でテレビ見て笑ってる家、って決めるねん。
そしたら、そうなるだけやで🌿
```

| | |
|---|---|
| **本人確認(2026-10-10)** | **この描写は、本人の実体験。** 創作ではない |
| **ただし** | **投稿内では「望む夫婦の状態を決める」という例示が中心** |
| **判定** | **主 手段・目的  /  補 信頼** |

```
実体験が入っている  →  だから信頼の教育が「主」になる、ではない
本文の中心が例示なら、信頼は「補」
```

**これが細則5の実例。** 実体験の有無で目的・主教育を自動で動かさない。

# 3. 型・目的・教育は、別の軸として扱う

**1本の投稿は、3つの軸を同時に持つ。**

```
軸1  型      文章の形      型1〜型12
軸2  目的    何のために出すか   集客 / ファン化 / 収益   (※未判定は判定保留に置く)
軸3  教育    読者に何が伝わるか  信頼 / 目的 / 問題 / 手段 / 行動 / 投資
```

| | |
|---|---|
| **型から目的は決まらない** | 同じ型1でも、目的は投稿によって変わる |
| **目的から教育は決まらない** | 同じファン化でも、伝わる教育は投稿によって変わる |
| **教育は複数入ることがある** | 1本に複数の教育が入っていてよい。1本1つに絞らない |

## 型番号は変更しない

**既存の型番号(型1〜型12)は、そのまま使う。** 振り直さない。統合しない。

