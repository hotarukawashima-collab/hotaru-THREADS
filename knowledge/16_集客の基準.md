## 3. ★★★ 集客投稿の基本構造

```
① 読者が欲しい未来・結果を、先に見せる
② 「え、本当に?」「そんなことあるの?」と期待を持たせる
③ 必要に応じて、簡単な行動や考え方を見せる
④ 読者が試したくなる／続きを読みたくなる形で終える
```

### ★ 不十分な終わり方（ここが今までいちばん外していたところ）

```
✕ 専門的な説明や精神論だけで終わる
✕ 「想像すると楽しいよ」だけ
✕ 「わたしはこの考え方が好き」だけ

→ どれも、★読者が欲しい結果を示せていない
→ 「自分にも何か起きるかも」が残らない
```

**①が抜けると、集客ではなく独り言になる。**
**出す前に「この投稿で、読者が欲しい未来は何か」を1行で言えるか確かめる。**

## 4. 入口の作り方 A〜D

**★ これは投稿目的の名前ではない。目的は 集客 / ファン化 / 収益 の3つのまま。**

| | 入口 | 中身 | 対応する既存の型 |
|---|---|---|---|
| **A** | **もうすぐ型** | 読者が望む具体的な未来を短く見せる | 構成H（`03_投稿の型.md`） |
| **B** | **大丈夫型・おめでとう型** | 安心と希望を先に届ける | 予祝・許可（同上） |
| **C** | **宇宙との会話型** | 望む未来を決めることを、短い掛け合いで伝える | 型6 対話（同上 1312行） |
| **D** | **小さな行動 → 思いがけない展開型** | 「嘘みたいな話」から始め、簡単な行動を出し、続きで理由を説明 | `analysis/実測/参考構造_入口の作り方_2026-10-15.md` のA・B |

### Dについて

```
★ 参考投稿の文章構造だけを借りる

→ 詳しい禁止事項は 参考構造_入口の作り方_2026-10-15.md を見る
```

### ★ 使い方の制約

```
✕ 集客の高反応型を、全投稿へ機械的に当てはめる
   → 1日の全枠をA〜Dで埋めない

```

## 6. 必ず守る制約

```
1  元投稿をコピーしない（`06_パクリ防止.md`）
2  本人の未確認の体験や成果を創作しない
3  読者や夫の変化、願望実現を保証しない
4  「もうすぐ」を使うときも、時期や結果を保証しない
     ⭕ 読者に希望として渡す
     ✕ いつ・どうなるかを約束する
5  「なる」は、★先に叶った自分を選ぶという発信上の考え方として説明する
     → 中身は `07_引き寄せの方針_701.md`。ここには書かない
     → 用語をそのまま出さず、読者の言葉に直す
6  現実をスルーする＝必要な対応を無視する、とは書かない
     話し合い・生活の問題・安全の確保を、しなくていいと勧めない
7  元の投稿型・型番号・字数帯・検証条件を勝手に変えない
8  目の前の現実を、引き寄せの成功・失敗の判定材料にしない
9  ネガティブな感情を、失敗の条件にしない
```
