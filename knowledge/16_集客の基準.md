## 3. ★★★ 集客投稿の基本構造

```
① 読者が欲しい未来・結果を、先に見せる
② 「え、本当に?」「そんなことあるの?」と期待を持たせる
③ 必要に応じて、簡単な行動や考え方を見せる
④ 読者が試したくなる／続きを読みたくなる形で終える
```

### ★ 不十分な終わり方（ここが今までいちばん外していたところ）

```
✕ 専門的な説明や精神論だけで終わる
✕ 「想像すると楽しいよ」だけ
✕ 「わたしはこの考え方が好き」だけ

→ どれも、★読者が欲しい結果を示せていない
→ 「自分にも何か起きるかも」が残らない
```

**①が抜けると、集客ではなく独り言になる。**
**出す前に「この投稿で、読者が欲しい未来は何か」を1行で言えるか確かめる。**

## ★★★ 4-2. 毎日必須の2グループ（2026-10-15 運用者から・新しい運用ルール）

> **★ 記号がぶつかるので先に。**
> **4章のA〜Dは「入口の作り方」の4種類。ここのA・Bは「毎日必ず入れる2グループ」。**
> **別物なので、設計表に書くときは「グループA」「グループB」と書く。**
>
> ```
> グループA ＝ 4章の A もうすぐ型 / B 大丈夫型・おめでとう型 / C 宇宙との会話型
> グループB ＝ 4章の D 小さな行動 → 思いがけない展開型
> ```

### グループA｜高反応・未来提示型

```
参照元  2026/9/22〜9/25の本人の投稿スクショ群
        運用者の報告では、この時期にフォロワーが約100人増加（1章）

構造    ・「もうすぐね」「大丈夫」「おめでとう」などの短いフック
        ・夫婦仲が良くなった後の、読者が望む具体的な日常
        ・短く、分かりやすく、希望と余韻を残す
        ・宇宙との会話型もこのグループに含む

読者に起こしたい反応
        「こんな未来が来たら嬉しい」「私もこんな夫婦になりたい」
```

```
⚠ フォロワー増加と投稿構造の因果関係は未確定
⚠ 夫婦仲が必ず改善する、いつ改善する、といった保証はしない
⚠ 本人の過去投稿をそのまま再利用・コピーしない
```

### グループB｜ミラクル・実践誘導型

```
参照元  運用者が共有した参考Threads投稿スクショ群
        （玄関の塩・掃除・パワースポット・水拭き など）
        ★詳しい禁止事項は analysis/実測/参考構造_入口の作り方_2026-10-15.md
```

**最重要ターゲットは2章と同じ。** 701式や「なる」の知識が無い、半信半疑の人。

#### ★ 必須の文章構造（順番を変えない）

```
【冒頭】      「嘘みたいな話だけど」など、意外性と期待を作る
【具体的な行動】 初見の人でも理解でき、その場で試せそうなことを示す
【簡単さ】     「これだけ」など、難しくないことを伝える
【未来への引き】 思いがけない展開や、具体的な望ましい結果への期待を作る
```

#### ★ 連投の続き（この順番を勝手に変えない）

```
1  具体的な変化・結果
2  なぜそんなことが起きるのか
3  方法の核心
4  読者が試してみたくなる締め
```

#### ★★★ 1の「結果」で、いちばん外しやすいところ

```
✕ 結果を「想像すると楽しい」「自分の見方が変わる」などの抽象的な話に置き換える
⭕ 読者が知りたいのは、どんな嬉しい未来や具体的な出来事があるのか

★ ただし同時に守る
  ・未確認の体験談や成果を創作しない
  ・方法と夫の行動変化に、証明されていない因果関係を作らない
  ・結果の保証や、起こると決まっているかのような誤認を避ける
  ・元の参考投稿の文章はコピーせず、構造を活かす
```

> **★ 「具体的に書く」と「保証する」は別。**
> **具体的な場面を描くのは良い。「そうなります」と約束しないだけ。**

### 1日の設計への組み込み

```
★ 最初にグループA・Bの配置を決めてから、他の投稿枠を設計する

グループA  毎日1投稿
グループB  毎日1投稿
✕ 両方を同じ投稿で兼用しない
★ Bが連投のときは、連投全体を1組として管理し、実際の投稿本文数は正しく数える
  （例：2連投なら、グループBは1組だが本文は2本）
```

```
★ 既存の時刻・型・検証条件・投稿禁止枠を勝手に変更しない
   → 13_検証中.md / 03_投稿の型.md / 21:00の投稿禁止 が優先
★ 枠の条件と衝突したら、無理に当てはめず報告する
```

### 投稿目的との関係

```
★ A・Bは「文章構造・訴求の分類」であって、教材の新しい投稿目的ではない
   投稿目的は 集客 / ファン化 / 収益 の3つのまま。基本配分 4：4：2 も変えない

★ 他の投稿でファン化と収益を確保し、1日全体を集客だけに偏らせない
   → グループA・Bを入れた結果、集客ばかりになっていないかを工程9-3で見る
```

## 6. 必ず守る制約

```
1  元投稿をコピーしない（`06_パクリ防止.md`）
2  本人の未確認の体験や成果を創作しない
3  読者や夫の変化、願望実現を保証しない
4  「もうすぐ」を使うときも、時期や結果を保証しない
     ⭕ 読者に希望として渡す
     ✕ いつ・どうなるかを約束する
5  「なる」は、★先に叶った自分を選ぶという発信上の考え方として説明する
     → 中身は `07_引き寄せの方針_701.md`。ここには書かない
     → 用語をそのまま出さず、読者の言葉に直す
6  現実をスルーする＝必要な対応を無視する、とは書かない
     話し合い・生活の問題・安全の確保を、しなくていいと勧めない
7  元の投稿型・型番号・字数帯・検証条件を勝手に変えない
8  目の前の現実を、引き寄せの成功・失敗の判定材料にしない
9  ネガティブな感情を、失敗の条件にしない
```
