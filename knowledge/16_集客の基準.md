## 3. ★★★ 集客投稿の基本構造

```
① 読者が欲しい未来・結果を、先に見せる
② 「え、本当に?」「そんなことあるの?」と期待を持たせる
③ 必要に応じて、簡単な行動や考え方を見せる
④ 読者が試したくなる／続きを読みたくなる形で終える
```

### ★ 不十分な終わり方（ここが今までいちばん外していたところ）

```
✕ 専門的な説明や精神論だけで終わる
✕ 「想像すると楽しいよ」だけ
✕ 「わたしはこの考え方が好き」だけ

→ どれも、★読者が欲しい結果を示せていない
→ 「自分にも何か起きるかも」が残らない
```

**①が抜けると、集客ではなく独り言になる。**
**出す前に「この投稿で、読者が欲しい未来は何か」を1行で言えるか確かめる。**

### グループA｜高反応・未来提示型

> **★ 2026-10-16 更新。運用者がスクショを共有したので、実物から構造を取り直した。**
> **出典：なまけろ子本人の 2026/09/22〜09/25 の投稿（運用者が共有）。**
> **★ 文章はコピーしない。この時期は標準語、今は関西弁。借りるのは構造だけ。**

#### A-1 もうすぐ型 ── ★いちばん伸びる

```
【1行目】 もうすぐ、／ もうすぐね、
【2行目】 ★読者が将来言うセリフ、または読者が望む場面
【3行目】 〜よ〜✨ で閉じる

2〜3行。説明をしない。余韻で終わる。
実測  ♡280 / ♡110 / ♡34 / ♡7
```

#### A-2 大丈夫型

```
【1行目】 大丈夫〜! ／ 大丈夫、大丈夫。
【2行目】 ★そのあとに、読者が欲しい結果そのものを置く
          （「〜でなくていい」という解除にしない。ここを外しやすい）

実測  ♡69 / ♡30 / ♡7
```

#### A-3 決めるんだよ〜型

```
【1行目】 決めるんだよ〜。
【2〜3行目】 ★夫婦の日常を2〜3つ並べる（具体的な場面）
【4行目】 〜って決めるの。
【5行目】 そしたら、そうなっていくからね🌿

★日常を並べてから「決める」に着地する。順番が逆にならない
実測  ♡24 / ♡1
```

#### A-4 設定型

```
【1行目】 そろそろ、
【2行目】 「　もう〜　」に
【3行目】 設定してもいいんだよ〜✨

★未来形を使わないので、結果の保証にならない
実測  ♡18
```

#### A-5 宇宙との会話型

```
🦥 読者の願いを、ふわっとした形で言う
宇宙 ★それでええの? と掘り返す（「〜だけでええの?」「〜したら変わるん?」）
🦥 「…」 ← 詰まる1行を入れる
宇宙 「で、ほんまはどうなりたいん?」
🦥 ★具体的な望みを言う
宇宙 ★短く落とす（「おけ。用意するわ」「ほな、ほっとき」「はやいわ」）

実測  ♡16 / ♡12 / ♡12 / ♡8 / ♡7
★落としは必ず短い。説明しない
★型6（対話）の枠がある日に使う。型4の字数帯には入らない
```

#### ★ A型を使うときの注意

```
✕ 「あとは待つだけ」「必ず終わる」「ちゃんと良くなっていく」
   → 現行の 05_NGリスト では結果保証に当たる。実物にはあるが、そのまま使わない
✕ 本人の過去投稿をそのまま再利用・コピーする
✕ 毎日同じパターンを使う（A-1〜A-5から日替わりで選ぶ）
⚠ フォロワー増加と投稿構造の因果関係は未確定（1章）
```

### グループB｜ミラクル・実践誘導型

```
参照元  運用者が共有した参考Threads投稿スクショ群
        （玄関の塩・掃除・パワースポット・水拭き など）
        ★詳しい禁止事項は analysis/実測/参考構造_入口の作り方_2026-10-15.md
```

**最重要ターゲットは2章と同じ。** 701式や「なる」の知識が無い、半信半疑の人。

#### ★ 必須の文章構造（順番を変えない）

> **★ 2026-10-16 更新。運用者がスクショを共有したので、実物から構造を取り直した。**
> **出典：参考アカウント4件（塩・掃き掃除・雑巾がけ／水拭き／トイレ掃除）。**
> **★ 文章はコピーしない。借りるのは構造だけ。**

**いちばん伸びた1本（表示45万・♡4,539／続き♡1,740）の形を基準にする。**

```
1本目
【1行目】気軽さ     「時々でええよ、」      ★義務にしない。毎日やれと言わない
【2〜3行目】行動     ★手が動くことを2〜3個、順番に
                    考え方ではなく、今日その場でできること
【最終行】引き       「不思議やねんけど、、」
                    ★結果を言わずに切る。ここで「これだけ」と言い切ってもよい
```

```
2本目
1 結果    ★「・」で2〜3つ並べる。1項目は短く
2 なぜ    2〜3行。言い切る。長く説明しない
          ★★1本目で挙げた行動を、そのまま受ける。別の話にしない
3 核心    「理由は分からんでもええよ。」★難しくしない、が核心そのもの
4 提案    「しんどい日ほど、思い出してやってみてな」
5 余韻    短く閉じる
```

#### ★★ 2の「なぜ」は、1本目の行動を受ける(2026-10-17 運用者から)

> **「グループB 1本目 はいいけど2本目が1本目に繋がってない」**

**1本目は行動を2〜3個出して、結果を言わずに切る。**
**2本目の「なぜ」は、その行動がなぜ結果になるのかを言う場所。**
**だから1本目に出した行動の言葉を、そのまま2本目の「なぜ」に入れる。**

```
✕ 1本目  ・寝る前に浮かべる  ・「お、きた」て言う
  2本目  なぜ: 夫を動かそうとするのをやめただけ   ← 1本目と関係ない別の話

⭕ 1本目  ・寝る前に浮かべる  ・「お、きた」て言う
  2本目  なぜ: 寝る前に浮かべて、もう仲がいいって決めたままにしといた。
               「お、きた」で拾うたぶん、目についてくるねん。
                 ↑ 1本目の行動が、そのまま出てくる
```

**★ 連投は1組。1本目と2本目を別々に作らない。**
**行動を決めたら、その言葉を2本目の「なぜ」に先に置いてから、結果と余韻を書く。**

#### ★ 行動に選ぶもの（なまけろ子の場合）

```
教材の中で「手が動く」もの
  ステップ6  ふっと出た気持ちに、心の中で「お、きた」と言う  ← ★セリフがある
  ステップ3  今日ええなと思ったことを1個数える
  ステップ2  寝る前に、場面をひとつ思い浮かべる

★読者は「夫に拒否されるのが怖い」人。夫に何かする行動を選ばない
✕ 掃除・塩・方位など、開運の行動を持ち込まない（教材に無い）
```

#### ★★★ 実物から、使わないもの

```
✕ 「〜した人。」で結果を並べる          → 他人の成果になる
✕ 金額の列挙（30万・200万・月7万UPなど）  → 成果の創作になる
✕ 「3か月で50万以上を引き寄せた」        → 同じ
✕ 読者側の報告をそのまま載せる形         → 購入者・読者の声を創作しない
✕ 開運・浄化・エネルギー・神社の儀式の説明 → 教材に無い説明を足さない

⭕ 代わりに
   結果  →  本人の確認済みの日常（4章「使える体験」）
   因果  →  「大きな仲直りがあったわけちゃうねん」で外す
            （公開中の無料部分と同じ言い方）
   なぜ  →  教材の中の理屈に置き換える
```

#### ★★★ 1の「結果」で、いちばん外しやすいところ

```
✕ 結果を「想像すると楽しい」「自分の見方が変わる」などの抽象的な話に置き換える
⭕ 読者が知りたいのは、どんな嬉しい未来や具体的な出来事があるのか

★ ただし同時に守る
  ・未確認の体験談や成果を創作しない
  ・方法と夫の行動変化に、証明されていない因果関係を作らない
  ・結果の保証や、起こると決まっているかのような誤認を避ける
  ・元の参考投稿の文章はコピーせず、構造を活かす
```

> **★ 「具体的に書く」と「保証する」は別。**
> **具体的な場面を描くのは良い。「そうなります」と約束しないだけ。**

## 6. 必ず守る制約

```
1  元投稿をコピーしない（`06_パクリ防止.md`）
2  本人の未確認の体験や成果を創作しない
3  読者や夫の変化、願望実現を保証しない
4  「もうすぐ」を使うときも、時期や結果を保証しない
     ⭕ 読者に希望として渡す
     ✕ いつ・どうなるかを約束する
5  「なる」は、★先に叶った自分を選ぶという発信上の考え方として説明する
     → 中身は `07_引き寄せの方針_701.md`。ここには書かない
     → 用語をそのまま出さず、読者の言葉に直す
6  現実をスルーする＝必要な対応を無視する、とは書かない
     話し合い・生活の問題・安全の確保を、しなくていいと勧めない
7  元の投稿型・型番号・字数帯・検証条件を勝手に変えない
8  目の前の現実を、引き寄せの成功・失敗の判定材料にしない
9  ネガティブな感情を、失敗の条件にしない
```
