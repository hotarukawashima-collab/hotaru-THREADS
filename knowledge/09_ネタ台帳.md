## ★ 使い方のルール(2026-10-02 訂正)

> **【訂正】当初「1つのネタは1回しか使わない」としていたが、これは誤り。**
> **コアラは31本とも骨が同じ**(もう叶ってる)で、**言い方だけ変えている。**
> 「大丈夫」も3回出てくる。**骨は繰り返していい。**

1. **骨は何回でも使う。** 使い切るものではない
2. **変えるのは言い方と入口。** 同じ骨を、別の言葉で言う
3. **同じ言い方を、3日以内に繰り返さない**(`tools/inspect.py` 検査8・9が見る)
4. **「決める」を核にしない。** コアラは31本中3本(10%)
5. **原文の語り手を見る。** 701は片思い→結婚、愛に浸るは片思い・復縁。
   **読者の立場は夫婦**なので、メカニズムだけ取って、立場は翻訳する

# 愛に浸る から取った骨(2026-10-02 追加)

**当初「持ってこられるのは2つだけ」と書いたが、取りこぼしていた。**
原文の立場(片思い・復縁)と、メカニズムを分けて読めば、もっと取れる。

## ★★★ A. 条件付けを外す(最大の未使用)

> **原文:**「コツはね、条件付けを外すの。
> **新しい彼彼女だから何。ひどい別れ方だっただから何。連絡くれないだから何。**
> そんなこと知らないよ。**本来の彼が好きなの**って」

**「〜だから何」というリズムが独特で、強い。**

```
夫婦に翻訳
  冷たいから何。優しくないから何。
  そんなん関係なしに、うちの夫が好きやねん。
```

## ★★★ B. イラつくけど、好き(ネガティブと好きが同居していい)

> **原文:**「**イラつくても好き。許せない、絶対許せない。はー、でもやっぱり好き。**
> そんなこんなしてるうちに、自分がいかに相手のことを思ってるか見えてくる」

**「許せない」を否定していない。** 両方持っていていい、と言っている。
**読者がいちばん抱えている状態そのもの。**

```
夫婦に翻訳
  腹立つけど好き。もう無理、絶対無理。…でもやっぱり好き。
  それでええねん。
```

## ⚠ N・O の「振り子の法則」は、別の法則の名前

**「似たもの同士が惹かれあう」は、振り子の法則ではない。**

| 法則 | 中身 |
|---|---|
| **振り子の法則**(ゼランド『トランサーフィン』) | **大勢の思考が集まってできた構造体のこと。**引き込まれるとエネルギーを吸われるので、**「振り子から降りろ」が教えの中心。**「惹かれあう」とは逆の話 |
| **類友の法則 / 波動の法則** | **同じ波動のものが引き合う** ← **運用者が言いたいのはこっち** |
| 鏡の法則 | 周りは自分の鏡 |

**引き寄せを勉強している読者には、まあまあ知られている言葉。**
**間違って使うと「この人分かってない」と見られる。**

> **K・Lが「波動」の話なので、「波動の法則」で統一するのが自然。**
> **「波動の法則って知ってる?」で始めれば、K〜Oが1本の線でつながる。**

## ⚠ L「周りの人間を整理しよう」は、このアカウントでは危ない

**理由は2つ。**

| | |
|---|---|
| ① | **夫婦仲修復のアカウントで「周りの人を整理」と言うと、「夫も?」と読まれる。** 離れろと言っているように取られる |
| ② | **「整理しよう」は行動指示。**`knowledge/03` の大原則①に触れる |

**使うなら、こう変える。**

```
✕  周りにいる人間を整理しよう
○  しんどくなる話を聞いたあとは、戻してから寝たらええよ
○  夫婦の愚痴で盛り上がる場所から、ちょっと離れてええんやで
```

**「人を切れ」ではなく「その場から離れてええ」にする。**
**「スレッズも」は、そのまま使える**(見るものを選ぶのは、人を切ることではない)。

## M「自分に嘘をつくこと」── このアカウントの芯と合う

**「うちはもう仲がいい」と決めることは、嘘をつくことではない。**
**嘘をつくというのは、しんどいのに平気なふりをすること。**

**この区別を書けると、7ステップの誤解を1本で潰せる。**
**型3(常識破壊)の「ふつう」として、本当に言われていることでもある。**

```
ふつうは「仲がいいって決めるんは、自分に嘘つくことちゃうん?」と思うけど、
```

**→ `knowledge/03` の「まだ使っていない、本当に言われていること」に追加した。**
