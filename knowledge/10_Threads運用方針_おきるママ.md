## 1. 投稿には3つの目的がある(STEP5-2)

| | 目的 | 意識すること |
|---|---|---|
| ① | **集客投稿** | **バズるかどうか。これのみ** |
| ② | **自己PR投稿(ファン化)** | 自分の色を出す |
| ③ | **セールス投稿** | 買うと何が手に入るかを分かりやすく |

**バランスの実例:集客 : ファン化 : 収益 = 4 : 4 : 2**

> 偏ると「フォローは簡単に外される」。
> 自分のフォロワー数や商品の有無で、ベストバランスを探る。

## 2. 投稿の基本の型(STEP5-3)

```
①フック  冒頭で心をつかむ。YouTubeのサムネ、TikTokの0.5秒にあたる
②本文    価値ある情報や体験談。具体的な体験や数字を入れる
③締め    読者の行動を促す。リプが残しやすいもの
```

| | ✕ | ○ |
|---|---|---|
| フック | マッチングアプリを使っても、理想の男性と出会えない方は… | **1年で150人とマッチングした私が言う。**理想の男性と出会いたいなら… |
| 本文 | プロフィール写真を見直してみましょう | プロフィール写真は**3つにするべき。①正面②全身③友人が撮った素の自分** |
| 締め | ぜひ自分の写真を見直してみてね! | **150人とマッチングできた私のプロフィールは、プロフから見てみてね!** |

**最後の一文は、リプが残しやすいものがいい。**
読んだ後に「何か行動したい」と思わせる終わり方か、**突っ込みたくなるもの。**

### ★★★ 見られるのにフォローが増えない人の特徴(2025.8追記)

>
> ほとんどの人が、投稿を見てもプロフィールまで見てくれない。
> **「この人どんな人だろう?」と思ってもらえない限り、いいねを押して終わり。**
>
> **✔ なぜそれをして欲しいのか + して欲しいアクション**

## 3. 目的別テンプレート(STEP5-4)

### ①集客投稿

```
(共感できる状況)(悩みや問題)(理想の未来)(具体的な体験談)
(小さな成功体験)(学んだこと)(読者への問いかけ)(次のステップを示唆)(心に残る一言)
```

**実例(短い):**
```
まじで恋愛チートになったかもしれない。        ←理想の未来
既読無視の放置プレーだった彼氏が、
最近わたしのこと好きすぎてやばい。            ←成功体験
LINEの送り方一つで、こんなに変わるなら
もっと早く知りたかった。
どんなふうに変えたか知りたい人いる?          ←問いかけ
```

**ポイント:** 共感できる / トレンドを押さえる / わかりやすい実績を出す
**集客投稿は、これぐらい短くていい。**

### ②自己PR投稿

```
(興味を引く事実)(なぜ重要か)(読者のメリット)(方法①②③)(体験談)(応用)(励まし)
```

**ポイント:** 自分の体験や失敗談も混ぜる / コミュニケーションを大事に /
**自分のキャラ設定を固めて守る**

### ③セールス投稿

```
(悩み)(その影響や痛み)(解決の可能性)(商品紹介)(メリット)
(他の人の成功事例)(行動への誘導)(特典や期間限定)(背中を押す一言)
```

**ポイント:** 出せる数字は明確に / 口コミがあれば出す / **残り〇〇件など希少性**

## 4. Threadsならではの注意(STEP5-5)

### ① 「勉強になります」より「わかるー!」

> **Threadsは「共感7 : 有益3」が黄金比率。**
> 専門的な話より「私もそうだよ〜!」と思ってもらえる内容が圧倒的に伸びる。

### ② 辛辣な切り口、ネガティブ発信は危険

Threadsはインスタと連携していて「自分の顔が見えてる感」がある。
**ネガティブ発信でウケるのは、旦那の悪口だけ。**
辛口で通用するのは、他にすでにファンがいる人だけ。
**どうしても言いたいなら、笑いに変える。**

### ③ Xとキャラを分ける

| | ウケるキャラ |
|---|---|
| X | 「できる旦那」「シゴデキ有益発信キャラ」 |
| **Threads** | **「尽くす旦那」「頼れるお兄さん」** |

### ④ Threadsは主婦、Xはサラリーマン

> **結論ファーストより、共感ファースト。**
> すでに家事育児で脳内マルチタスク状態なので、難しい話は聞きたくない。

### ⑤ エンタメ性 > 有益性

> ちょっと笑える要素や、感情の起伏があるエンタメ型のほうが圧倒的に反応がいい。
> インスタとセットで開くので「勉強しよう」という脳の人は少数派。

### ⑥ ポスト量の重要性は異常

> **Threadsの露出は投稿単位。アカウントパワーはほぼ関係ない。**
> フォロワー0でも急にバズる。1日のポスト数が少なければ「打席に立つ回数」が減る。
> **1日5〜10投稿が目標。その中で1つでもバズれば大成功。**
> **自分のポストの再投稿もインプレッションが伸びる**ので、
> バズった投稿が多いほど資産として積み上がる。

## ★★★ 7. コアラと矛盾する点(採用前に判断が要る)

**コアラ357本を実測した結果。**

| | コアラ | おきるママの方針 |
|---|---|---|
| CTAを含む投稿 | **10本 / 357本(2.8%)** | **必須** |
| **上位10本(♡681〜3,153)** | **CTAは1本も無い** | |

```
♡3,153  おめでとう✨ 今日を境に、通帳のお金が増え続けるよ。     ← CTA無し
♡2,202  あらら、また臨時収入だね。明日もあさってもあるよ。       ← CTA無し
♡1,184  人生は思ったより短いよ。…今、決めていいんだよ✨        ← CTA無し
```

**コアラはCTA無しで♡3,153を取り、フォロワー1,015人。**

### どう読むか

**いいねは、CTA無しでも取れる。** これはコアラの実測で確定している。
**フォローについては、コアラのデータからは分からない。**
(どの投稿からフォローされたかの記録が無い)

**つまり、両立しうる。**

```
いいねを取る投稿   コアラの型(CTA無し)
フォローを取る投稿  CTAを入れる
```

**おきるママ自身が「3つの目的のバランス」と言っているのも、これと同じ構造。**
**全部にCTAを入れるのではなく、役割を分ける。**

### 他の矛盾

| | コアラ | おきるママ |
|---|---|---|
| エンタメ性 | **ほぼ無い**(断言と安心づけが中心) | **有益性より上** |
| 投稿数 | 1日6〜11本 | 5〜10本 |
| 共感 vs 有益 | 断言型が中心。共感型は少ない | 共感7 : 有益3 |

**エンタメ性の差がいちばん大きい。** ただしコアラは♡3,153を出しているので、
**「エンタメが無いと伸びない」はコアラの実測で否定されている。**
