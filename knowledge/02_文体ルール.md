# 02 文体ルール

投稿を書くときの、言葉づかいの決めごと。
`analysis/accounts/koara/analysis.md`・`analysis/accounts/yukipi/analysis.md` の実データから確定。

| 項目 | 決定 | 根拠 |
|---|---|---|
| 一人称 | 断定文は主語を省略するのが基本。実務エピソードを語る文だけ「わたし」を使う | コアラ analysis.md 5章:「私」使用は7件/326のみ、96%超が主語省略。ゆきぴー analysis.md 5章:「わたし/私」使用29件/159(18.2%)、自己開示の場面に集中して使われている |
| 読者の呼び方 | 「あなた」を主にしつつ、呼びかけの一文だけ「みんな」を使う | コアラ analysis.md 5章:あなた58件・みんな45件のバランス型。ゆきぴー analysis.md 5章:あなた47件(29.6%) vs みんな4件(2.5%)で「あなた」が圧倒的優位。個別相談的な響きを出すため、新アカウントは「あなた」寄りに寄せる |
| 語尾 | 「〜だよ」「〜だよね」「〜てね」中心のタメ口 | コアラ analysis.md 5章・ゆきぴー analysis.md 5章とも敬語(です・ます)で終わる投稿は**0件**(合計485件中0件) |
| 敬語/タメ口 | タメ口100%。ただし専門性を出す一文だけ「〜してるよ」「〜してても」という実務トーンに寄せる(下記「専門家としての温度調整」) | 同上。両アカウントとも敬語0%だが、そのままでは専門家としての裏付けが消えるため、02既存セクションの調整ルールを維持 |
| 絵文字 | 1投稿0〜1個。アイコン(ナマケモノ)と揃えた署名絵文字🦥を使う。多用しない | コアラ analysis.md 6章:75.2%の投稿が絵文字を使用、上位5種(✨🐨🌿🍀🌱)で全体の85.5%を占める寡占状態。ゆきぴー analysis.md 6章:絵文字使用**0/159件**で、文章のみで押し切るのが明確な差別化になっている。→ 2つの正解が両立するため、新アカウントは「使うが最小限」の中間を取り、乱用しない |
| 1投稿の文字数 | 30〜80字程度の短文を基本。スレッドで2本目を出す場合のみ150字程度まで許容 | コアラ analysis.md 4章:0〜30字が平均160.6いいねで最高、151字以上は平均4.3に急落。ゆきぴー analysis.md 4章:151〜250字が平均37.2と好成績だが、これはスレッド2本目(具体的な回収パート)に集中している。短い投稿は短いまま、長くする場合はスレッドの2本目に隔離する |
| 改行 | 短文でも1文ごとに改行し、縦長レイアウトにする | コアラ analysis.md 4章:line_count中央値3行。CLAUDE.mdの既存ルール(「改行を細かく入れ、スマホで読みやすい縦長レイアウトにする」)とも整合 |
| 断定の強さ | 「〜するだけだよ」という行動提案型の言い切りは使うが、結果を保証する断言(「絶対」「必ず」)は使わない | コアラ analysis.md 3章:「手順・一手型」(「決めるだけ」「〜するだけ」)が平均190.0で最高反応。ただし `05_NGリスト.md` が優先され、結果保証の断言はそのまま夫婦仲には移植しない |

## 専門家としての温度調整(このアカウント固有)

参考2アカウントは「元どん底の一般人」の立場で語っている。
こちらは**専門家**なので、そのままコピーすると2つの問題が出る。

1. 「わたしも元どん底でした」だけだと、専門家としての強みが消える
2. 逆に専門家然としすぎると、引き寄せ層のゆるい空気から浮いて読まれない

**解き方:** 語り口は「脱力」路線のやわらかさに合わせ、
**根拠を出すところだけ専門家に戻る**。

- ×「夫婦関係の修復には段階的なアプローチが不可欠です」(硬い・止まる)
- ×「信じてれば絶対に戻ってくるよ🐨」(専門性ゼロ・05_NGリストに抵触)
- ○「追いかけるほど逃げるの、性格の問題じゃないよ。
   相談を受けててもいちばん多いパターンだから、安心して。」

やわらかい語尾 + 「相談を受けてても」という一言だけで専門性が立つ。
**この一言の置き方が、このアカウントの再現性のある武器です。**

### 型として使う場面

- コアラの「常識破壊・逆張り型」(analysis.md 2章、平均186.1)は「実は〜しなくていい」という
  構文だが、専門家が言う場合は根拠なしの逆張りにならないよう、
  「相談を受けてて分かったこと」を一言添えて温度を上げる。
- ゆきぴーの「権威引用型」(analysis.md 2〜3章、実在の著者名を出す型)は、
  新アカウントでは**運用者自身の実務・相談件数**が権威の代わりになる。
  他人の名前を借りる必要がなく、これは2アカウントにない強みとしてそのまま使える。
