## 時間を指す語を本文に入れない(実測)

**「今日」を含む投稿は、コアラ326件中22件で平均42.3いいね。含まない303件は平均111.1。
約1/2.6に落ちる。**

| | 件数 | 平均いいね |
|---|---|---|
| 「今日」あり | 22 | **42.3** |
| 「今日」なし | 303 | **111.1** |

- 「今日」「明日」「今夜」「朝」など、**特定の日・時間帯を指す語を本文に置かない。**
  読者がその投稿を見るのが朝とは限らず、悩んでいる期間が今日だけとも限らないため、
  時間を限定した瞬間に自分ごとから外れる。
- 代わりに使うのは**「今」**。koara_097(♡1184・全体1位)「今、決めていいんだよ✨」、
  koara_202「今この瞬間、選ぶもの」のように、コアラの高反応投稿は
  日付ではなく「今」という一点だけを指す。
- **「今日やること」型の指示も置かない。** `05_NGリスト.md` の
  「拘束を生まない」原則(有料本文で「今日やること」を全て「持っておくだけでいいよ」に
  差し替えた経緯)と同じ理由で、Threads本文にも適用する。

**このルールの適用範囲はThreads投稿本文のみ。** note本文では、読者の内なる声の引用
(「今日は機嫌いいかな」)や、毎日くり返すことの描写(「あ、今日もあった」)として
必要な「今日」があるため、一律には削らない。

## 断定の中身(このアカウント固有)

このアカウントは「夫婦仲コーチング」ではなく**引き寄せアカウント**であり、
コアラと同じ「叶ってる前提を断定する」語り口をそのまま使う。専門家としての権威づけ
(「相談を受けてても」等)や、コミュニケーション指導(言い方・伝え方)は行わない。
**コアラがやっていないことはやらない**が唯一の判断基準になる。

どの断定が使えて、どの断定が使えないか(主語が読者で「決める・設定する・許可する」なら使える、
主語が相手・未来で「戻ってくる・変わる」なら使えない、という線引きと語彙変換表)は
`04_ネタ地図.md`の「【最重要】使える断定と、使えない断定」「語彙の変換表」「扱わないもの」を
参照。

## ★★★ 便利ワードを使わない ── これが「AI臭さ」の正体(2026-10-09 運用者から)

> **「叶う側に戻るのに効いたんは、← これAI臭い」**

### 何が起きていたか

**`inspect.py` の CORE_WORDS(決め/決ま/叶/宇宙/世界/設定/許可/前提)を通すために、**
**「叶」や「世界」を含む便利な言い回しを作って、使い回していた。**

```
10-02 07:00  もう良くなる側で決まったで
10-06 21:00  ちゃんと叶う側やで✨              ← 0.00%
10-07 15:01  もう叶う側に乗ってるで
10-07 18:00  ちゃんと叶う側に向かってるからな
10-08 15:00  叶う側に戻るのに効いたんは、
10-09 15:00  叶う側に戻るのに効いたんは、      ← 2日連続で同じ
```

**6本。同じ日に別の便利ワードも使っていた。**

```
本音でおれる世界におるで
世界ごとそっちに寄るからな
どっちも忘れてる世界におるからな
```

### なぜ臭うのか

**「叶う側」「〜世界におる」は、場所の名前のようでいて、どこでもない。**
**口から出る言葉ではない。概念をそのまま置いただけ。**

**運用者の書き換えには、概念語が1つも無い。**

```
「なんか知らんけど」で片付けるのが最強やからな
ポテナゲ特大が異常に食べたい
夫が帰ってくる音で、体がこわばる
```

**全部、場面か、実際に言う言葉。**

### 使わない / 使う

| ✕ 便利ワード(概念をそのまま置いた) | ⭕ 場面に置き換える |
|---|---|
| 叶う側に戻る / 叶う側に乗ってる | **家の中が軽なる** |
| 本音でおれる世界におる | **夜ごはんの味までちゃんと分かる** |
| 世界ごとそっちに寄る | **家の中から変わってくる** |
| 良くなる側で決まった | **どうでもええLINEが来る** |

### 見分け方

```
□ その言葉、口から出るか
□ 場面が見えるか（どこでもない「側」「世界」になっていないか）
□ CORE_WORDSを通すために作った言い回しではないか
```

> **CORE_WORDSは「引き寄せの話をしているか」を見る検査であって、**
> **「叶」という字を入れれば通る、という意味ではない。**
> **字を入れるために言い回しを作った時点で、検査の目的から外れている。**
